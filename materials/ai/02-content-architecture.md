# HTML 온라인 교재 콘텐츠 구조

이 문서는 구현 코드가 아니라, 각 주차 내용을 웹 학습 단위로 옮기기 위한 정보 구조다.

## 권장 경로

```text
materials/ai/
├─ index                         # 과정 홈(향후 HTML로 구현)
├─ lessons/
│  ├─ 01-ai-literacy/
│  ├─ 02-better-prompts/
│  ├─ ...
│  └─ 24-showcase/
├─ teacher/                     # 인증 또는 별도 배포가 필요한 교사용 콘텐츠
├─ shared/                      # 공통 용어, 안전 수칙, 도움말
└─ assets/                      # 이미지·샘플 데이터·다운로드 자료
```

현재 설계 단계에서는 위 디렉터리와 HTML 파일을 생성하지 않는다. 구현 시 URL은 `/materials/ai/lessons/01-ai-literacy/`처럼 의미가 드러나는 형식을 권장한다.

## 과정 홈

- 과정 소개, 대상, 준비물, 무료 도구 선택지
- 24주 로드맵과 단계별 진행률
- 최근 학습, 이어서 학습, 완료 주차
- 개인정보·API 키·저작권·AI 검증 안전 수칙
- 도구 설치가 어려운 학생을 위한 브라우저 기반 대체 경로
- 최종 프로젝트 안내와 전체 체크리스트

## 주차별 학생 페이지 표준 순서

1. 주차 표지: 제목, 한 줄 목표, 예상 시간, 준비물, 선행 학습
2. 오늘 만들 것: 완성 예시와 성공 기준
3. 📖 학습 내용: 짧은 개념 블록과 그림·비유
4. 💡 핵심 정리: 반드시 기억할 3–5개 문장
5. 교사 시연 따라보기: 관찰 포인트와 예상 화면
6. 🧪 실습: 번호가 있는 단계, 각 단계의 실행·확인 방법
7. 📋 프롬프트: 복사 버튼 대상 문구, 바꿀 자리 표시, 사용 시점
8. 오류 연구소: 흔한 증상, 확인할 증거, 해결 순서
9. 🚀 미션: 요구사항, 제한 조건, 완료 기준
10. 🧠 생각해보기: 정확성·편향·안전·설계 선택 질문
11. ✅ 체크리스트: 완료 상태를 학생이 직접 표시
12. 🏆 확장 미션: 경험자용 기능·품질·탐구 과제
13. 결과물 제출: 파일 또는 링크, 테스트 증거, 한 줄 설명
14. 📝 회고: 배운 점, 막힌 점, AI 제안 중 거절한 것, 다음 시도
15. 다음 주 예고: 이번 결과물이 다음 학습에 쓰이는 방식

## 각 활동 블록의 콘텐츠 필드

| 블록 | 필수 필드 |
|---|---|
| 학습 내용 | 제목, 2–4분 분량 설명, 예시, 오개념 경고 |
| 핵심 정리 | 핵심 문장, 용어, 스스로 확인할 질문 |
| 실습 | 예상 시간, 시작 상태, 단계, 실행 명령, 기대 결과, 막혔을 때 |
| 프롬프트 | 목적, 복사 본문, 학생이 바꿀 부분, 보내기 전 점검, 결과 검증 |
| 미션 | 상황, 필수 조건, 선택 조건, 완료 기준, 제출 증거 |
| 생각해보기 | 열린 질문, 근거 요구, 짝 토론 안내 |
| 체크리스트 | 행동 기준의 짧은 문장, 로컬 진행 상태 키 |
| 확장 미션 | 선수 조건, 추가 목표, 힌트, 기본 과정 복귀 지점 |
| 회고 | 자유 서술 3문항, 자기 평가, 다음 행동 |

## 학생용과 교사용 콘텐츠 분리

### 학생에게 공개

- 학습 목표와 완성 예시
- 짧은 개념 설명과 핵심 정리
- 단계별 실습과 복사 가능한 프롬프트
- 힌트 1·2단계와 오류 확인 순서
- 미션, 완료 기준, 체크리스트, 확장 미션
- 회고와 다음 주 연결

### 교사 전용

- 수업 의도와 핵심 오개념
- 120분 운영표, 중간 점검 시각, 축소 운영안
- 시연 대본과 시연 실패 시 대체 화면
- 질문 유도 문장과 학생 수준별 개입 기준
- 정답·예시 결과, 평가 포인트, 관찰 기록
- API·계정·네트워크 문제의 대체 활동
- 기초 학생용 발판과 경험자용 확장 지도
- 민감 정보, 저작권, 부적절한 생성 결과 대응 지침

교사용 정답이 학생 페이지의 소스나 정적 자산에 그대로 노출되지 않도록 배포 구조 또는 접근 권한을 분리해야 한다.

## 수준별 학습 경로

- 기본 경로: 안내된 코드를 실행하고 한 요소씩 바꾸며 결과를 설명한다.
- 지원 경로: 시작 파일, 부분 완성 코드, 단계별 힌트, 로컬 데이터가 제공된다.
- 확장 경로: 기능 추가보다 테스트, 접근성, 구조 개선, 새로운 데이터 적용을 우선한다.
- 빠른 학생은 다른 학생의 코드를 대신 작성하지 않고 테스트 사용자나 검토자 역할을 맡는다.

## 페이지 상호작용 요구사항

- 프롬프트·코드 복사 버튼과 복사 성공 안내
- 단계별 체크리스트와 주차 진행률의 브라우저 로컬 저장
- 힌트의 단계적 공개, 정답은 즉시 노출하지 않음
- 코드 블록의 언어 표시, 긴 줄 처리, 키보드 접근
- 실행 전·후 예상 결과 탭 또는 비교 영역
- 오류 메시지 복사 영역과 디버깅 기록 양식
- 학생 미션 제출 항목 및 회고 저장·내보내기
- 모바일 화면, 키보드 탐색, 충분한 색 대비, 애니메이션 감소 설정 지원
- 외부 서비스가 없어도 핵심 학습이 가능한 대체 자료 제공

## 전체 과정 공통 진행 데이터

로그인 연동 여부와 무관하게 다음 상태 모델을 기준으로 UI를 설계한다.

- 과정 진행률: 완료한 주차 수 / 24
- 주차 상태: 시작 전, 학습 중, 실습 완료, 미션 완료
- 체크리스트 상태: 항목별 완료 여부
- 회고: 주차별 학생 입력
- 프로젝트 상태: 제안, 설계, 알파, 베타, 출시 후보, 발표 완료

브라우저 로컬 저장을 먼저 지원하고, 서버 계정 저장은 사이트 정책이 정해진 뒤 별도 단계로 확장한다.
