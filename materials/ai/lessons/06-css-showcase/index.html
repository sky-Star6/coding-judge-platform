6강 — 판타지 감성 입히기: CSS 스타일링 & 시즌 1 완성 쇼케이스

흑백 글자뿐이던 HTML 뼈대에 마법 같은 색채와 빛나는 버튼 효과를 입힙니다. 세계관 맞춤형 CSS를 완성하고, 짝꿍과 함께 서로의 인터랙티브 웹 비주얼 노벨을 플레이하는 시즌 1 대망의 최종 완성 쇼케이스를 진행합니다!

이번 강의에서 배우는 것

  • 웹 페이지의 시각적 디자인을 담당하는 CSS(Cascading Style Sheets)의 기본 문법을 익힙니다.
  • 배경색(background-color), 글자색(color), 여백(padding), 테두리(border-radius)를 조절할 수 있습니다.
  • 마우스를 올렸을 때 버튼이 커지고 빛나는 가상 클래스(:hover) 인터랙션을 구현합니다.
  • AI에게 내 세계관(중세 판타지, 사이버펑크, 숲속 어드벤처 등)에 어울리는 감성 CSS 코드를 요청하고 통합합니다.
  • 「시즌 1 쇼케이스」에서 내 비주얼 노벨 완성작(v1.0)을 친구들과 플레이하고 상호 피드백을 나눕니다.

마법의 페인트와 조명: CSS의 세계

지난 5강에서 만든 웹 화면을 기억하시나요? 하얀 바탕에 검은 글자, 밋밋한 회색 버튼... 마치 뼈대만 앙상한 마네킹 같았습니다.

CSS의 역할:
어두운 밤하늘색 조명을 켜고, 대사창에 유리 질감의 반투명 테두리를 두르고, 버튼에 마우스를 대면 황금빛 네온이 번쩍이게 만드는 ‘웹의 인테리어이자 마법 의상’입니다!

CSS 기본 문법 구조

/* 누구를 꾸밀까? { 무엇을 어떻게 꾸밀까: 값; } */
button {
  background-color: #2563eb;  /* 버튼 배경을 파란색으로! */
  color: #ffffff;            /* 글자색을 하얀색으로! */
  border-radius: 8px;        /* 모서리를 둥글게! */
  padding: 10px 20px;        /* 안쪽 여백을 넉넉하게! */
}

/* 마우스를 올렸을 때(:hover)의 마법 효과 */
button:hover {
  background-color: #38bdf8; /* 밝은 하늘색으로 변신! */
  transform: scale(1.05);    /* 크기가 1.05배 쑥 커짐! */
}

판타지 감성을 살리는 CSS 4대 핵심 속성

1. 색상과 배경 (Color & Background)

background-color: #0f172a; (어두운 미드나잇 블루)
color: #f8fafc; (읽기 편한 밝은 백색)

👉 게임 배경을 어둡게 하면 신비로운 모험 분위기가 300% 상승합니다!

2. 박스 여백과 둥근 모서리 (Padding & Radius)

padding: 1.5rem; (대사창 내부의 넉넉한 숨 쉴 공간)
border-radius: 12px; (부드러운 곡선 모서리)

👉 딱딱한 직사각형이 세련된 게임 UI 상자로 변합니다.

3. 테두리와 발광 효과 (Border & Box-Shadow)

border: 2px solid #38bdf8; (청록색 마법 테두리)
box-shadow: 0 0 15px rgba(56, 189, 248, 0.4); (은은한 발광)

👉 대사창 주변에 마법 룬 결계가 쳐진 것 같은 시각 효과를 줍니다.

4. 호버 인터랙션 (:hover & Transition)

transition: all 0.3s ease; (부드러운 전환 애니메이션)
cursor: pointer; (손가락 모양 마우스 커서)

👉 "내가 누를 수 있는 선택지구나!" 하고 플레이어가 바로 알 수 있습니다.

단계별 실습: 내 게임에 CSS 옷 입히기

1단계: 5강의 `game.html` 파일 열기

텍스트 에디터나 메모장으로 5강에서 만든 나만의 HTML 파일을 엽니다.

2단계: `<head>` 안에 `<style>` 태그 만들기

CSS 코드는 HTML 파일 상단의 <head>와 </head> 사이에 들어갑니다: 

<head>
  <meta charset="UTF-8">
  <title>내 비주얼 노벨</title>
  <style>
    /* 여기에 멋진 CSS 마법 코드를 붙여넣습니다! */
  </style>
</head>

[내 게임 세계관 정보]
- 게임 분위기: [예: 안개 낀 신비로운 마법 숲 / 폐허가 된 사이버펑크 도시 / 으스스한 유령의 성]

[필수 요청 사항]
1. 전체 배경색과 글자색이 높은 명도 대비를 이루어 눈이 피로하지 않고 글자가 아주 잘 읽히게 해줘.
