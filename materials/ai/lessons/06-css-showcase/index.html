2단계 · 스타일링 공식

CSS 문법의 황금 공식: "누구에게 { 무엇을: 어떻게; }"

CSS는 영어가 아니라 **단순한 주문서(레시피)**예요. 딱 3단어의 순서만 기억하면 브라우저의 모든 것을 내 마음대로 꾸밀 수 있습니다.

📜 3단계 주문 공식과 세미콜론(;) 마침표 규칙

# CSS의 3단계 기본 공식
선택자 (누구에게) { 속성 (무엇을) : 값 (어떻게) ; }
button {
background-color: #4f46e5; /* 버튼 배경을 남색으로! */
color: white; /* 글자색은 하얗게! */
}
💡 주문이 끝날 때마다 반드시 세미콜론(`;`) 마침표를 찍어주어야 다음 주문을 알아듣습니다!

🎨 판타지 감성을 살리는 4대 핵심 속성

background-color 배경색 마법

`#0f172a`(깊은 밤하늘색)나 `#1e1b4b`(마법사 연구실색)로 전체 배경 분위기를 순식간에 바꿉니다.

color 글자색 조명

대사와 제목 글자의 색상이에요. `#fde68a`(황금빛)나 `#38bdf8`(시원한 푸른빛)으로 시선을 끕니다.

border-radius 모서리 둥글리기

뾰족한 직사각형 모서리를 둥글게 깎아 부드러운 게임 대사창과 알약 모양 버튼으로 만듭니다 (`12px`, `20px`).

:hover 마법 마우스 반응 효과

`button:hover` 주문을 걸면 플레이어가 마우스를 버튼 위에 올렸을 때 버튼이 커지거나 불빛이 켜집니다!

1. 캐스케이딩 스타일 시트 영문: Cascading Style Sheets (CSS)
CSS
🧸 어린이 비유: "회색 시멘트 레고 성벽에 알록달록 무지개 페인트를 칠하고 네온 조명을 켜는 마법 분장 기술입니다."

🎓 개발자 공식 정의: HTML로 작성된 웹 문서의 레이아웃, 색상, 글꼴, 시각적 효과 등 프레젠테이션(표현) 계층을 구조와 분리하여 제어하는 스타일시트 표준 언어입니다.

2. 선택자 영문: CSS Selector
Selector
🧸 어린이 비유: "빨간 모자를 쓴 사람 나와라!" 하고 콕 집어 마법을 걸 대상을 지목하는 타겟팅 지팡이입니다.

🎓 개발자 공식 정의: 스타일 규칙을 적용할 특정 HTML 요소(태그명, 클래스, 아이디 등)를 지정하는 패턴 식별자입니다.

3. 박스 모델 영문: CSS Box Model
BoxModel
🧸 어린이 비유: "선물 상자의 푹신한 뽁뽁이 안쪽 포장(패딩)과 상자 겉면의 단단한 상자벽(테두리), 상자 밖의 안전거리(마진)입니다."

🎓 개발자 공식 정의: 웹 요소가 콘텐츠(Content), 안쪽 여백(Padding), 테두리(Border), 바깥 여백(Margin)의 4중 사각형 레이어로 공간을 차지하는 레이아웃 기본 모델입니다.

4. 가상 클래스 영문: Pseudo-class (:hover)
State
🧸 어린이 비유: "버튼이 얌전히 있다가 마우스 손가락이 다가오면 반짝! 눈을 뜨며 색깔이 바뀌는 카멜레온 변신 마법입니다."

🎓 개발자 공식 정의: 요소의 특별한 상태(마우스 오버 `:hover`, 포커스 `:focus`, 방문 기록 `:visited` 등)에 따라 동적으로 스타일을 적용하는 선택자 확장 키워드입니다.

5. 반응형 웹 영문: Responsive Web Design
Responsive
🧸 어린이 비유: "물을 담는 그릇의 크기(스마트폰, 태블릿, 대형 모니터)에 따라 스스로 모습을 찰떡같이 바꾸는 슬라임 화면입니다."

🎓 개발자 공식 정의: 다양한 기기의 화면 크기와 해상도를 감지하여 미디어 쿼리(Media Query) 등을 통해 최적의 레이아웃으로 유연하게 재배치되는 웹 디자인 기법입니다.

6. 디자인 시스템 영문: Design System & Tokens
Tokens
🧸 어린이 비유: "레고 세트의 공식 색상 팔레트처럼, 게임 전체의 버튼과 글자 모양을 통일감 있게 맞추어 주는 약속 상자입니다."

🎓 개발자 공식 정의: 일관된 사용자 경험(UX)과 브랜드 아이덴티티를 유지하기 위해 색상, 폰트, 간격, 컴포넌트 규칙을 체계적으로 표준화한 디자인 자산 규격입니다.
