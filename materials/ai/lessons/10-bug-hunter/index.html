미션 브리핑: 빨간색 에러 메시지는 컴퓨터가 보낸 비밀 보물지도!

코딩을 하다가 화면에 아무것도 안 뜨거나 게임이 멈추면 가슴이 철렁 내려앉나요?
걱정하지 마세요! 컴퓨터는 절대로 우리를 골탕 먹이려고 멈추지 않습니다. 대신 키보드의 [F12] 버튼을 누르면 열리는 개발자 도구 콘솔(Console) 창에 "몇 번째 줄에 어떤 글자가 잘못되었는지" 아주 정확하게 적힌 비밀 편지를 남겨둡니다.

💡 주니어 명탐정의 돋보기: "에러 메시지를 읽으면 답이 보인다!"

초보자는 화면이 멈추면 "어? 왜 안 되지?" 하고 코드를 아무 데나 무작정 지우지만, 진짜 멋진 개발자는 콘솔 창을 열어 에러 이름과 줄 번호(Line Number)를 먼저 확인합니다. 빨간 에러 메시지는 오류를 치료해달라는 컴퓨터의 친절한 보물지도입니다!

평가 영역 기본 수준 (Lv.1) 우수 수준 (Lv.2) 명탐정 수준 (Lv.3)
콘솔 에러 독해력 에러가 난 줄 번호(Line)를 찾아냄 3대 에러(Reference/Type/Syntax)의 원인을 구별 호출 스택 역추적
AI 디버깅 프롬프트 "고쳐줘" 대신 에러 글자를 복사해 질문 에러 발생 코드 5~10줄을 함께 전달 Given-When-Then 형식 질문
핫픽스 안전 검증 수정 코드를 붙여넣어 에러 빨간 줄 제거 console.log로 변수 상태값 직접 검증 무결점 버그 체포 완료

핵심 개념: 자바스크립트 3대 단골 에러 해부

개발자들이 매일 만나는 에러의 90%는 딱 3가지 가족입니다. 이 3총사의 얼굴만 익혀두면 어떤 버그도 무섭지 않습니다!

1. ReferenceError (참조)

"그런 이름의 상자는 태어난 적이 없어요!" 변수 이름에 오타가 났거나(예: socre), 만들기 전에 먼저 불렀을 때 발생합니다.

socre is not defined
2. TypeError (타입/자료형)

"빈 껍데기(null)에게 일을 시켰어요!" HTML 아이디를 틀려서 요소를 못 찾았거나, 숫자를 함수처럼 score()로 불렀을 때 터집니다.

Cannot read properties of null
3. SyntaxError (문법 구문)

"자바스크립트 문법 철자가 틀렸어요!" 닫는 중괄호(}), 따옴표("), 쉼표(,)를 빠뜨려서 컴퓨터가 읽기를 멈춘 상태입니다.

Unexpected token '}'
3

단계별 조립 실습: Given-When-Then 3단계 마법 주문

AI 코딩 도구에게 "게임이 안 돼요 고쳐주세요"라고만 하면 AI도 눈뜬장님이 되어 엉뚱한 코드를 지어냅니다(할루시네이션).
대신 상황(Given) - 행동(When) - 결과(Then) 3단계로 정리해서 에러 메시지와 함께 전달하면 단 3초 만에 완벽한 정답 코드를 얻을 수 있습니다!

Given (상황)

"어떤 상태에서?" ➔ 별똥별 피하기 게임 시작 화면에서 우주선이 대기 중일 때

When (행동)

"무슨 버튼을 눌렀을 때?" ➔ 키보드 오른쪽 화살표 키를 3번 연속 꾹 눌렀을 때

Then (결과)

"어떤 에러가 터졌는가?" ➔ F12 콘솔에 TypeError: Cannot read properties of null (game.js:24)가 뜨면서 우주선이 멈춤

원클릭 AI 디버깅 프롬프트 (복사해서 AI 도우미에게 질문해보세요!)

프롬프트 1 : 오타 참조 에러 체포

"아래 자바스크립트 코드에서 'ReferenceError: socre is not defined'가 발생합니다. 오타가 난 변수 위치를 찾아서 올바르게 수정한 코드 블록을 작성해줘."

프롬프트 2 : null 객체 접근 에러 치료

"버튼 클릭 시 'TypeError: Cannot read properties of null' 에러가 납니다. document.getElementById의 아이디가 HTML과 일치하는지 점검하고 안전한 핫픽스를 제공해줘."

4

버그 연구소: "가짜 수정"의 함정에 빠지지 않는 법 & 자가 회고

버그를 고칠 때 가장 위험한 실수는 무엇일까요? 바로 에러 빨간 줄만 없애려고 필요한 코드 자체를 통째로 지워버리는 가짜 수정입니다!

함정 1: 무작정 코드 삭제하기

에러가 난 줄을 그냥 지워버리면 빨간 글씨는 사라지지만, 게임의 점수 계산이나 이동 기능 자체가 영원히 멈춰버립니다!

💡 정답: 왜 컴퓨터가 못 찾았는지(오타, ID 불일치) 원인을 밝혀서 글자를 고쳐야 합니다.
함정 2: 고친 후 테스트 건너뛰기

하나를 고치다가 다른 쪽 코드를 건드려 새로운 버그(사이드 이펙트)가 생길 수 있습니다.

💡 정답: 수정 후 다시 버튼을 누르고 게임을 10초간 플레이하며 정상 작동을 확인합니다.

🔍 주니어 개발자를 위한 전문 용어 돋보기

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 시니어 엔지니어들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 디버깅 영문: Debugging (Bug Fixing)
소프트웨어 공학
🧸 어린이 비유: "프로그램 속에 몰래 숨어든 벌레(Bug)를 명탐정 돋보기로 찾아내어 안전하게 고치는 과정!"

🎓 개발자 공식 정의: 소프트웨어 소스 코드의 오류나 결함(Bug)을 찾아내고, 그 원인을 분석하여 시스템이 올바르게 동작하도록 수정하는 일련의 문제 해결 프로세스입니다.

2. 개발자 도구 콘솔 영문: Browser DevTools Console (F12)
진단/도구
🧸 어린이 비유: "컴퓨터가 아플 때 어디가 어떻게 아픈지 의사 선생님께 일러바치는 청진기 화면!"

🎓 개발자 공식 정의: 브라우저에서 실행 중인 웹 애플리케이션의 상태, 로그 출력(console.log), 자바스크립트 런타임 에러를 실시간으로 모니터링하고 코드를 즉석에서 평가할 수 있는 진단 터미널입니다.

3. 참조 에러 영문: ReferenceError
런타임 에러
🧸 어린이 비유: "이름표를 만들어준 적 없는 유령 친구를 심부름 보내려고 할 때 '그런 친구 없어요!' 하고 깜짝 놀라는 에러!"

🎓 개발자 공식 정의: 현재 스코프(Scope)에 선언되지 않았거나 유효하지 않은 식별자(변수나 함수 이름)를 참조하려고 시도할 때 자바스크립트 엔진이 던지는 표준 런타임 오류입니다.

4. 타입 에러 영문: TypeError
런타임 에러
🧸 어린이 비유: "텅 빈 깡통(null)에게 '안에 든 사탕 꺼내줘!' 하고 불가능한 명령을 내렸을 때 당황하는 에러!"

🎓 개발자 공식 정의: 값이 기대하는 데이터 타입이 아니거나, null 또는 undefined와 같은 비객체 속성에 접근·호출하려 할 때 발생하는 데이터 타입 불일치 런타임 오류입니다.

5. 콜 스택 외래어·영문: 콜 스택 (Call Stack / Stack Trace)
실행 엔진
🧸 어린이 비유: "명탐정이 사건 현장까지 어떤 골목길을 거쳐 왔는지 적혀 있는 비밀 지도 메모장!"

🎓 개발자 공식 정의: 프로그램이 어떤 함수들을 순서대로 호출하여 현재 지점(또는 에러 지점)에 도달했는지를 후입선출(LIFO) 스택 구조로 추적하여 보여주는 호출 실행 기록입니다.

6. 핫픽스 외래어·영문: 핫픽스 (Hotfix / Quick Patch)
배포/유지보수
🧸 어린이 비유: "경기 중에 펑크 난 자전거 바퀴를 번개처럼 빠르게 때워 다시 달리게 만드는 긴급 치료 반창고!"

🎓 개발자 공식 정의: 소프트웨어에서 치명적인 버그가 발견되었을 때, 긴급하게 버그만을 안전하게 수정하여 즉시 배포하는 패치 작업입니다.

1
빨간 에러를 두려워하지 말 것 에러는 프로그램이 친절하게 건네는 수리 안내장이자 버그 지도예요.
2
