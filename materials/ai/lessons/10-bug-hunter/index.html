10강 — AI 코딩 도구와 버그 사냥꾼: 콘솔 에러 분석 & AI 디버깅 배틀

훌륭한 프로그래머와 초보자의 진짜 차이는 "오류를 만났을 때 당황하지 않는 힘"에서 결정됩니다! 브라우저 개발자 도구(F12)의 붉은 콘솔 오류를 독해하고, "안 돼요 고쳐줘" 대신 Given-When-Then 재현 조건과 에러 스택을 제공하여 AI 파트너와 함께 버그를 체포하는 전문가형 디버깅 워크플로우를 배웁니다.

예상 시간
120분 집중 실습
핵심 역량
개발자 도구 콘솔, 3대 JS 에러 독해, Given-When-Then

오늘 완성할 결과물과 성공 기준

이번 10강에서는 감이나 운에 맡기는 수정을 버리고, 컴퓨터가 보낸 에러 메시지를 증거 삼아 원인을 논리적으로 추적하는 체계적인 디버깅 기술을 마스터합니다.

  • 브라우저 개발자 도구의 Console(콘솔) 창을 열어 빨간색 에러 메시지와 발생 파일 및 줄 번호(Line Number)를 확인합니다.
  • JavaScript 3대 단골 에러인 ReferenceError, TypeError, SyntaxError의 뜻과 발생 상황을 구분합니다.
  • 오류 상황을 명확히 정의하는 Given(준비) - When(행동) - Then(결과) 버그 리포트를 작성할 수 있습니다.
  • AI 코딩 도구에 에러 전문과 맥락 코드를 함께 전달하여 단 한 번에 완벽한 핫픽스(수정 코드)를 도출합니다.
  • 수정 후 기존 다른 기능이 고장 나지 않았는지 기본 검증 테스트를 수행합니다.
평가 영역 기본 수준 (Lv.1) 우수 수준 (Lv.2) 도전 과제 (Lv.3)
콘솔 독해력 에러가 발생한 줄 번호(Line)를 찾아냄 3대 에러(Reference/Type/Syntax)의 원인을 설명 비동기 함수 및 이벤트 리스너 내부의 호출 스택 역추적
AI 디버깅 프롬프트 에러 메시지를 복사해서 AI에게 질문 발생 코드 블록과 에러 메시지를 함께 제공 Given-When-Then 형식으로 재현 단계와 기대 결과를 명시
핫픽스 검증 수정 코드를 붙여넣어 에러 빨간 줄 제거 콘솔 로그(console.log)로 변수 상태값 직접 검증 버그 재현 시나리오를 다시 실행해 정상 동작 확인

핵심 개념: 자바스크립트 3대 단골 에러 해부

컴퓨터가 내뱉는 빨간 에러 메시지는 비난이 아니라, "여기서 이 부품이 고장 났어요!"라고 정확히 가리키는 보물지도입니다.

1. ReferenceError (참조 에러)

"그런 이름의 상자는 태어난 적이 없어요!" 변수 이름의 철자를 틀렸거나(오타), let score를 만들기 전에 먼저 호출했을 때 발생합니다.

// 오타 예시: socre = 100;
// Uncaught ReferenceError: socre is not defined

2. TypeError (자료형/객체 에러)

"빈 껍데기(null/undefined)에게 일을 시켰어요!" HTML 아이디를 잘못 적어 요소를 못 찾았거나, 숫자를 함수처럼 score()로 불렀을 때 발생합니다.

// Uncaught TypeError: Cannot read properties of null

3. SyntaxError (문법 구문 에러)

"자바스크립트 문법 철자가 어긋났어요!" 중괄호(}), 따옴표("), 또는 쉼표(,)를 닫지 않아 컴퓨터가 해석을 멈춘 상태입니다.

// Uncaught SyntaxError: Unexpected token '}'

핵심 요약: 버그 사냥 4단계 공식 (CAPTURE)

① 콘솔 증거 확보 (Evidence) F12 콘솔창의 빨간 에러 메시지와 오른쪽에 적힌 발생 파일/줄 번호를 복사합니다.
② 재현 절차 기록 (Given-When) "어떤 화면에서(Given) 어떤 버튼을 눌렀을 때(When) 버그가 터지는지" 한 줄로 정리합니다.
③ 정밀 프롬프트 투입 (Prompt) 에러 메시지 + 해당 코드 10줄 + 기대 결과를 AI에게 한 묶음으로 질문합니다.
④ 핫픽스 검증 (Verify) 수정 후 똑같은 행동을 다시 수행하여 빨간 글씨가 완전히 사라졌는지 확인합니다.
http://localhost:8000/arcade/game.html (Console F12)
> 콘솔 준비 완료. [버그 유발 실행] 버튼을 눌러보세요.
사냥할 버그 시나리오 선택:
사건 1: 우주선 점수 미반영 사건 체포: 0마리

점수를 100점 올려야 하는데 화면에 아무 변화가 없습니다. 콘솔 에러를 확인하고 올바른 수정 코드를 처방하세요!

// 고장 난 코드 위치: line 42
socre = score + 100; // 버그 발생줄
올바른 핫픽스 처방을 선택하세요:

Given-When-Then 버그 요소 조립

조립된 AI 디버깅 주문서 

              

              

                💡 이 주문서를 AI에게 그대로 붙여넣으면 정확한 문제 원인과 1줄 핫픽스 코드를 한 번에 얻을 수 있습니다.
              

            


          

        


      

    


    
    

      

        
        단계별 실습 가이드: 4단계 실전 버그 사냥
      

      

        콘솔 오류를 발견하고 AI와 협업하여 안전하게 고치는 실전 디버깅 프로세스입니다.
      


      

        
        
        

          
1단계: F12 개발자 도구 콘솔 열기

          

            크롬 또는 브라우저에서 F12 키를 누르거나 마우스 우클릭 후 [검사] → [Console] 탭을 선택합니다. 빨간 에러 메시지를 찾습니다.
          

          
// 콘솔에 찍힌 에러 형태:
// app.js:42 Uncaught ReferenceError: socre is not defined
// ↑ 파일명과 42번째 줄 번호가 가장 중요한 단서!

        


        
        

          
2단계: 코드 에디터에서 해당 줄 번호 찾아가기

          

            코드 에디터에서 오류가 지목한 42번째 줄로 이동하여 오타나 선언 누락이 있는지 전후 맥락 5줄을 관찰합니다.
          

          
let score = 0; // 올바른 선언
...
socre += 10;   // 42번째 줄: 'score'에 오타가 났음을 확인!

        


        
        

          
3단계: AI에게 Given-When-Then 에러 보고서 전달

          

            혼자 해결하기 어려운 복잡한 에러는 AI에게 재현 상황과 발생 줄 코드를 복사해 전달합니다.
          

          
질문 템플릿:
"아래 코드 실행 중 [에러 메시지]가 발생했어.
원인과 수정한 코드를 초보자 눈높이에서 1줄로 설명해 줘.
[발생 코드 블록]"

        


        
        

          
4단계: 핫픽스 적용 및 재현 테스트 완료

          

            코드를 수정하고 페이지를 새로고침(F5)한 뒤, 아까와 동일한 조작을 수행하여 콘솔이 깨끗한지 확인합니다.
          

          
// 콘솔에 빨간 글씨가 사라지고 정상 로그만 출력되면 체포 완료!
console.log("점수 정상 갱신 완료:", score);

        


      

    


    
    

      

        
        실습용 프롬프트 마법 주문서
      

      

        AI 코딩 파트너에게 복사해서 붙여넣을 수 있는 고품질 프롬프트 템플릿입니다. [복사] 버튼을 눌러 활용해 보세요.
      


      

        
        
        

          

            주문서 ①: 콘솔 에러 전문 기반 정밀 핫픽스 요청
            
          

          
다음 자바스크립트 코드에서 브라우저 콘솔 오류가 발생했어.
에러 메시지: [Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')]
발생 코드:
```javascript
const btn = document.getElementById("start-button");
btn.addEventListener("click", startGame);
```
요구사항:
1. 에러가 발생한 원인을 초보자가 이해하기 쉽게 2줄 이내로 설명해 줘.
2. HTML 요소가 아직 로드되지 않았거나 ID가 틀렸을 때를 대비한 안전한 수정 코드를 제시해 줘.

        


        
        

          

            주문서 ②: 요구사항 및 Given-When-Then 검증 조건 변환
            
          

          
내 아이디어를 테스트 가능한 Given-When-Then 완료 조건으로 바꿔 줘.
내 아이디어: "플레이어가 장애물에 부딪히면 화면이 깜빡이면서 하트가 1개 깎여야 해."
요구사항:
1. 상황(Given), 행동(When), 기대 결과(Then)로 명확히 분리해 줘.
2. 체력이 0이 되었을 때의 예외 처리(Game Over) 조건도 함께 포함해 줘.

        


      

    


    
    

      

        
        오류 연구소: 디버깅 시 자주 하는 3대 실수
      

      

        버그를 고치려다 오히려 더 큰 버그를 만드는 흔한 함정과 탈출법입니다.
      


      

        
        
        

          
❌ 함정 1: 에러 메시지 안 읽고 코드 무작정 고치기

          

            빨간 글씨가 무서워서 콘솔을 닫아버리고 멀쩡한 다른 코드를 고치다가 프로젝트 전체가 망가집니다.
          

          

            // 탈출법: 에러 메시지의 마지막 줄 번호부터 확인!
          

        


        
        

          
❌ 함정 2: AI에게 "안 돼요 고쳐줘"만 말하기

          

            에러 내용 없이 "게임이 안 움직여요"라고만 질문하면 AI도 엉뚱한 상상의 코드를 만들어 냅니다.
          

          

            // 탈출법: 콘솔 에러 전문 + 관련 코드 10줄 복사
          

        


        
        

          
❌ 함정 3: 고친 뒤 테스트 안 하고 넘어가기

          

            AI가 준 코드를 붙여넣기만 하고 직접 조작해보지 않으면 잠복 버그가 남아 쇼케이스 때 터집니다.
          

          

            // 탈출법: 수정 즉시 새로고침하고 조작 1회 필수
          

        


      

    


    
    

      

        
        학생 핵심 미션: 무결점 아케이드 버그 사냥
      

      

        다음 3개 미션을 완수하여 내 아케이드 게임을 버그 없는 완전 무결점 코드로 완성해 보세요.
      


      

        

          [미션 1] F12 콘솔 열고 1개 고의 에러 발생시켜 분석하기
          

            내 코드의 변수 이름 하나를 고의로 틀리게 바꾼 뒤 콘솔에 뜨는 빨간 에러 메시지와 줄 번호를 찾아 읽어봅니다.
          

        


        

          [미션 2] Given-When-Then 버그 리포트 1건 작성
          

            친구나 내가 겪었던 게임 버그 1가지를 정해 체험관 2의 빌더를 이용해 완벽한 AI 질문 주문서로 완성합니다.
          

        


        

          [미션 3] 100% 무결점 클린 콘솔 완성
          

            게임을 시작하고 끝날 때까지 F12 콘솔에 단 하나의 붉은 에러도 뜨지 않도록 깨끗이 정돈합니다.

        레벨업 심화 과제: 예외 처리와 디버거 중단점
      

      

        

          심화 ①: try-catch 예외 방어막 설치
          위험한 코드 블록을 try { ... } catch (err) { ... }로 감싸 예기치 않은 오류가 터져도 게임 화면이 멈추지 않게 보호해 보세요.
        

        

          심화 ②: debugger 키워드로 시간 정지
          코드 중간에 debugger;를 작성하여 충돌 순간에 브라우저 실행을 일시정지시키고 변수 값을 직접 돋보기로 관찰해 보세요.

AI·코딩 교육과정 (시즌 2: 7강 ~ 12강)
