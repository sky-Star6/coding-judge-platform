🛡️ QUEST 01. "기존 코드는 100% 보존해 줘!" 도미노 방지 프롬프트

기능 확장(Feature Extension) & 부작용(Side Effect) 원천 차단
[Goal]: 별똥별 피하기 웹 게임에 '30초마다 피버 타임(Fever Time)' 기능을 추가하려고 해. 기존에 완성된 우주선 이동, 충돌 감지, 점수 계산 로직이 망가지지 않도록 안전한 수정 코드를 작성해 줘. [Condition]: 1. [기존 코드 절대 보존 원칙]: 기존의 requestAnimationFrame 루프, 충돌 판정 함수, HP 차감 로직은 단 한 줄도 임의로 수정하거나 삭제하지 마. 2. [변경 범위 최소화]: 피버 타임과 관련된 새로운 변수와 함수만 깔끔하게 추가해 줘. 3. [Diff 형식 출력]: 어느 줄 사이에 새 코드를 끼워 넣어야 하는지 Git Diff 형식(+ 초록 줄 표시)으로 명확히 보여줘.
최신 AI의 소환 마법

"기존 코드를 건드리지 말라"는 제약 조건을 걸면, 전체 코드를 제멋대로 덮어써서 기존 기능을 날려먹는 도미노 사고를 원천 방지합니다.

빨간 줄 하나가 빠졌을 때 발생하는 잠재적 재앙을 정확히 경고하며, 벽 경계를 지키는 안전한 코드를 즉시 복원합니다.

컴퓨터 과학 비밀

💨 QUEST 03. 4대 스모크 테스트(Smoke Test) 시나리오 작성 요청하기

스모크 테스트(Smoke Testing) & 최소 필수 검증 슈트
[Goal]: 웹 아케이드 게임을 업데이트한 후, 전체 기능이 마비되지 않았는지 1분 안에 빠르게 확인하는 [4대 핵심 스모크 테스트(Smoke Test)] 시나리오를 표 형식으로 작성해 줘. [Target Features]: 우주선 좌우 이동, 별똥별 낙하 및 충돌, HP 감소 및 하트 UI 갱신, 게임오버 창 팝업 [Condition]: 1. 각 테스트마다 [테스트 번호], [검증할 핵심 기능], [사용자 행동(Action)], [기대 결과(Expected Output)], [실패 시 위험도] 5개 열로 구성해 줘. 2. 배포 직전 빠르게 손으로 테스트할 수 있도록 직관적이고 간단한 절차로 서술해 줘.
최신 AI의 소환 마법

1분 만에 게임의 핵심 생명줄을 검증할 수 있는 초고속 스모크 테스트 체크리스트를 일목요연하게 정리해 줍니다.

컴퓨터 과학 비밀

'스모크 테스트'는 하드웨어를 수리한 뒤 전원을 켰을 때 "연기가 나는가?"를 보듯, 핵심 기능의 작동 여부만 최단 시간에 확인하는 QA 기법입니다.

⚡ QUEST 04. Jest / 브라우저 자동 단언(assert) 테스트 함수 소환하기

자동화 단위 테스트(Unit Test) & 단언문(assert)
[Goal]: 플레이어의 HP 차감 로직과 레벨업 계산 함수가 의도대로 작동하는지 자동으로 검증해 주는 순수 자바스크립트 assert 테스트 함수를 작성해 줘. [Target Function]: function calculateSpeed(level) { return 3.0 + (level - 1) * 0.8; } [Condition]: 1. 외부 테스팅 라이브러리(Jest, Mocha 등) 없이 순수 브라우저 콘솔에서 바로 실행할 수 있는 간단한 `assertEquals(actual, expected, testName)` 함수를 구현해 줘. 2. 레벨 1일 때 3.0, 레벨 3일 때 4.6이 나오는지 검증하는 2가지 자동 테스트 케이스를 포함해 줘. 3. 테스트가 통과하면 콘솔에 초록색 `[PASS]`, 실패하면 빨간색 `[FAIL]` 로그를 출력해 줘.
최신 AI의 소환 마법
