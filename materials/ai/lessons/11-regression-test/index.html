핵심 개념: 안전한 AI 코드 변경 3대 원칙

소프트웨어는 벽돌집과 같아서, 지붕을 하나 고치다가 기둥을 건드리면 전체가 와르르 무너질 수 있습니다.

1. 회귀 테스트 (Regression Test)

'회귀(Regression)'는 프로그램이 과거의 고장 난 상태로 되돌아가는 현상입니다. 새 기능을 넣은 직후 기존 기능이 그대로 살아있는지 점검하는 것이 회귀 테스트입니다.

// "스피드업 추가했는데 왜 좌우 이동이 안 되지?" 방지!

2. 코드 차이점 독해 (Diff)

Git이나 전문 개발 도구에서는 빨간색(삭제: -)과 초록색(추가: +)으로 변경된 줄만 짚어줍니다. 전체를 다 바꿀 필요 없이 바뀐 2~3줄만 확인하세요!

- let meteorSpeed = 3;
+ let meteorSpeed = 3 + (gameLevel * 0.8);

3. 점진적 난이도 밸런싱

처음부터 너무 빠르면 초보자가 포기하고, 계속 느리면 지루해집니다. 시간(초)에 따라 부드러운 계단식 곡선을 그리며 레벨이 올라가도록 설계합니다.

const currentLevel = Math.floor(elapsedSeconds / 10) + 1;

핵심 요약: 안전한 코드 배포 4대 수칙 (SAFE)

① 범위 한정 (Scope) AI에게 질문할 때 "이 함수 하나만 수정해 줘"처럼 작업 범위를 엄격히 좁혀서 요청합니다.
② 차이점 대조 (Analyze Diff) 붙여넣기 전에 내가 건드리지 말라고 했던 기존 변수나 함수가 삭제되지 않았는지 확인합니다.
③ 즉시 회귀 테스트 (Fast Verify) 저장 후 30초 안에 이동, 점수, 피격의 3대 핵심 루프가 정상인지 직접 테스트합니다.
④ 원본 백업 보존 (Emergency Rollback) 잘 되던 직전 코드는 항상 복사본이나 Git 커밋으로 남겨 언제든 되돌릴 수 있게 준비합니다.

단계별 실습 가이드: 회귀 없는 난이도 패치 4단계

기능을 확장하면서도 기존 완성도를 100% 지키는 실전 개발 4단계 가이드입니다.

1단계: 변경 전 정상 작동 상태를 스냅샷으로 보존

새 코드를 넣기 전에 현재 잘 돌아가는 index.html을 복사하여 index_v1_backup.html로 안전하게 백업합니다. 

// 안전한 개발의 제1철칙: 언제든 1초 만에 롤백할 수 있는 백업 확보!

2단계: 10초 타이머와 레벨 계산 변수 추가

생존 시간(초)을 누적하는 gameSeconds 변수를 만들고, 10초마다 gameLevel을 1씩 올립니다. 

let gameSeconds = 0;
let gameLevel = 1;

// 1초마다 실행되는 생존 타이머
setInterval(() => {
  if (!isGameRunning) return;
  gameSeconds++;
  gameLevel = Math.floor(gameSeconds / 10) + 1;
  document.getElementById("level-display").textContent = "Lv." + gameLevel;
}, 1000);

3단계: 운석 속도 공식에 레벨 계수 반영

운석이 생성될 때 baseSpeed + (gameLevel * 0.7)을 적용하여 후반부로 갈수록 빠른 속도로 비 오듯 쏟아지게 만듭니다. 

function spawnMeteor() {
  const speedBonus = (gameLevel - 1) * 0.8;
  meteors.push({
    x: Math.random() * (canvas.width - 30),
    y: -20,
    speed: 3 + Math.random() * 2 + speedBonus // 레벨에 따라 점진 가속!
  });
}

4단계: 4대 핵심 회귀 시나리오 스모크 테스트

난이도 로직을 넣은 후, 좌우 벽 충돌, 하트 감소, 보너스 별 획득이 여전히 완벽하게 작동하는지 30초간 직접 검증합니다. 

console.assert(hp >= 0, "체력이 음수가 되지 않아야 함");
console.log("모든 회귀 검증 통과 완료!");

1. 전체 코드를 다시 작성하지 말고, 추가되거나 수정되는 줄만 Diff 형태(이전 줄 vs 바뀐 줄)로 짚어 줘.
