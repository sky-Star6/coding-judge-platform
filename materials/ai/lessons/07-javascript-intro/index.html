시즌 2 오프닝: 드디어 웹 화면에 심장이 뜁니다!

시즌 1에서 우리는 멋진 이야기 대사창을 만들고 예쁜 CSS 옷을 입혔습니다. 하지만 아직은 아무리 버튼을 눌러도 대사가 바뀌거나 점수가 올라가지 않는 '움직이지 않는 로봇 조각상'이었어요.
오늘 만나는 자바스크립트(JavaScript)는 이 로봇에게 심장과 두뇌, 그리고 모터를 달아주는 마법의 프로그래밍 언어입니다!

1. HTML (뼈대)

건물의 벽돌과 기둥! 쿠키 버튼과 점수 글자가 들어갈 자리를 마련해줍니다.

2. CSS (화려한 옷)

알록달록 예쁜 색깔과 조약돌 모양 둥근 테두리, 그리고 마우스를 올렸을 때 빛나는 효과를 줍니다.

3. JavaScript (심장 & 두뇌!)

버튼 클릭 신호를 감지하고, 숫자를 기억하며, 점수를 1개씩 팡팡 올려주는 진짜 살아있는 생명력입니다!

자바스크립트 3총사 마법: 기억하고, 신호받고, 행동하라!

자바스크립트가 화면을 움직이는 원리는 아주 간단합니다. 딱 3가지만 기억하면 세상의 모든 게임을 만들 수 있어요!

1. 변수 (기억 상자)
let cookies = 0;

"여기에 쿠키 개수를 적어두자!" 하고 컴퓨터 기억장치에 이름표를 붙여둔 투명 보물상자입니다. 숫자가 올라갈 때마다 새 숫자로 갈아 끼웁니다.

2. 이벤트 (초인종 신호)
onclick="bakeCookie()"

"손님이 마우스를 쿡 눌렀다!" 하고 알려주는 감시 센서 레이더입니다. 사용자의 클릭이나 터치 신호를 즉각 포착합니다.

3. 함수 (행동 레시피)
function bakeCookie() { }

"신호가 오면 이 순서대로 일해라!" 하고 적어둔 행동 지시서입니다. 숫자를 1개 늘리고 화면 글자를 바꾸는 일련의 동작을 묶어줍니다.

✨ 자바스크립트가 일하는 4단계 흐름도 신호 ➔ 처리 ➔ 저장 ➔ 출력
① 클릭 신호 손가락으로 쿡!
② 함수 호출 bakeCookie 실행
③ 변수 갱신 cookies = cookies + 1
④ 화면 출력 DOM 글자 바꾸기
도전! 즉석 1초 퀴즈

자바스크립트에서 구운 쿠키의 개수처럼 계속 변하는 숫자를 기억해두는 '투명 이름표 상자'의 공식 이름은 무엇일까요?

3

쿠키클리커 실전 제작: 코드 4단계 마법 조립

이제 우측 실습 콘솔에서 실제로 작동하는 쿠키클리커의 자바스크립트 코드를 단계별로 살펴봅시다. 복잡해 보이지만 딱 4단계뿐입니다!

1단계: 쿠키 개수와 클릭 파워를 기억할 상자 만들기 
let cookieCount = 0;  // 현재 구운 쿠키 개수
let clickPower = 1;   // 한 번 누를 때 얻는 쿠키 개수
2단계: 쿠키를 쿡 누를 때 실행할 마법 레시피(함수) 
function bakeCookie() {
  cookieCount = cookieCount + clickPower; // 파워만큼 쿠키 추가!
  updateDisplay(); // 화면에 새 숫자를 보여주기
}
3단계: 화면에 숫자를 실제로 갈아 끼우는 기술 (DOM 조작) 
function updateDisplay() {
  const display = document.getElementById('cookie-display');
  display.innerText = cookieCount; // 글자를 상자 속 숫자로 변경!
}
4단계: 황금 오븐 업그레이드 상점 로직 
function upgradeOven() {
  if (cookieCount >= 10) { // 쿠키가 10개 이상이면?
    cookieCount = cookieCount - 10; // 가격 10개 지불!
    clickPower = clickPower + 1;    // 이제 1클릭당 2개씩 획득!
    updateDisplay();
  }
}

우측 패널의 [🍪 쿠키클리커 게임기]에서 직접 쿠키를 쿡쿡 누르며 이 코드가 어떻게 실시간으로 동작하는지 눈으로 확인해보세요!

4

명탐정 오류 연구소: 초보자가 꼭 빠지는 2대 함정!

자바스크립트를 처음 배울 때 화면이 먹통이 되는 원인은 90%가 이 두 가지 실수 때문입니다. 미리 알아두면 버그를 만났을 때 바로 해결할 수 있어요!

함정 1: 글자 vs 숫자 덧셈 함정!

따옴표로 둘러싸인 "1"은 글자이고, 따옴표가 없는 1은 숫자입니다!
• "1" + 1 ➔ "11" (글자 이어붙이기 대참사!)
• 1 + 1 ➔ 2 (진짜 수학 덧셈!)

함정 2: id 이름 오타 및 대소문자

HTML 태그에 id="cookie-btn"이라고 지어두고 JS에서 getElementById('cookieBtn')처럼 부르면 컴퓨터는 대소문자를 엄격히 따지기 때문에 찾지 못하고 멍때립니다 (null 오류).

🔍 주니어 개발자를 위한 전문 용어 돋보기

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 프론트엔드 개발자들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 자바스크립트 영문: JavaScript (JS)
언어/실행엔진
🧸 어린이 비유: "정지된 로봇 화면에 심장을 달아주고, 버튼을 누르면 춤추게 만드는 마법의 생명 주문!"

🎓 개발자 공식 정의: 웹 브라우저에서 동적인 상호작용, 데이터 처리, 애니메이션 등을 제어할 수 있도록 해주는 객체 기반의 고수준 스크립트 언어(High-Level Scripting Language)입니다.

2. 변수 영문: Variable (let / const)
메모리/데이터
🧸 어린이 비유: "게임 속 점수나 플레이어 이름을 적어두고 필요할 때마다 꺼내보는 이름표 달린 보물 상자!"

🎓 개발자 공식 정의: 컴퓨터 메모리에 특정 데이터 값을 저장하고 필요에 따라 읽거나 재할당(Reassignment)하기 위해 이름을 부여한 기억 공간입니다.

3. 함수 영문: Function
동작/모듈
🧸 어린이 비유: "'쿠키 개수 늘리고 화면에 보여줘!'처럼 복잡한 일련의 주문을 버튼 하나에 모아둔 마법 도구함!"

🎓 개발자 공식 정의: 특정 작업을 수행하기 위해 독립적으로 설계된 코드 블록으로, 입력값(매개변수)을 받아 처리 후 결과값(반환값)을 돌려주는 재사용 가능한 모듈입니다.

4. 이벤트 리스너 영문: Event Listener & Handler
인터랙션/이벤트
🧸 어린이 비유: "'손님이 마우스를 쿡 찌르는지 잘 지켜봐!' 하고 문 앞에서 기다리는 눈썰미 좋은 안내원!"

🎓 개발자 공식 정의: 사용자의 마우스 클릭, 키보드 입력, 터치 등 브라우저 환경에서 발생하는 특정 이벤트(Event)를 감지하여 등록된 콜백 함수를 실행시키는 메커니즘입니다.

5. 문서 객체 모델 외래어·영문: 돔 (Document Object Model, DOM)
웹/트리구조
🧸 어린이 비유: "자바스크립트가 웹 페이지 속 글자나 상자를 마음대로 조종할 수 있게 도와주는 거대한 장난감 조종 지도!"

🎓 개발자 공식 정의: HTML 문서를 계층적 트리 구조의 객체(노드)로 표현하여, 프로그래밍 언어가 웹 문서의 내용, 스타일, 구조를 동적으로 제어할 수 있도록 한 표준 인터페이스입니다.

6. 상태 영문: State
데이터/라이프사이클
🧸 어린이 비유: "현재 내가 모은 쿠키 개수나 레벨처럼, 지금 이 순간 게임이 기억하고 있는 살아있는 정보들!"

🎓 개발자 공식 정의: 애플리케이션의 특정 시점에 메모리에 저장되어 있는 데이터 값들의 집합으로, UI 렌더링과 비즈니스 로직 결정의 기준이 됩니다.

① 황금 쿠키 돌발 보너스 이벤트 만들기
초보자용 JavaScript 쿠키클리커 게임을 제작 중이야. 10초마다 화면 구석에 5초 동안 반짝이며 나타났다가 사라지는 '황금 쿠키' 이벤트를 만들어줘. 플레이어가 황금 쿠키를 클릭하면 즉시 쿠키 10개를 보너스로 얻고 멋진 축하 메시지가 뜨게 해줘. 초등학생도 이해할 수 있게 한 줄씩 한국어로 주석을 달아줘.

10초마다 깜짝 출현하는 황금 쿠키 보너스 이벤트 코드를 AI에게 주문합니다.

② 초당 자동 쿠키 생성기(CPS) 기능
자바스크립트 setInterval 타이머 함수를 사용해서, 1초마다 자동으로 쿠키가 1개씩 구워지는 '자동 베이킹 오븐' 기능을 만들고 싶어. 게임이 켜지면 자동으로 작동하고 화면 점수판도 실시간으로 갱신되는 쉬운 코드를 작성해줘.

손으로 누르지 않아도 저절로 쿠키가 올라가는 타이머 마법 주문서입니다.

③ 100점 달성 축하 폭죽 효과
쿠키클리커 게임에서 cookieCount가 100점에 도달하는 순간, 화면 전체에 알록달록 꽃가루 폭죽(Confetti)이 팡 터지며 '전설의 쿠키 명장 등극!' 팝업창이 뜨는 자바스크립트 효과를 만들어줘. 초보자용으로 가장 가볍고 쉬운 방식으로 구현해줘.

100개 목표를 달성했을 때 짜릿한 성취감을 주는 폭죽 효과 주문서입니다.
