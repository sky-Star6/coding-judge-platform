화면을 클릭하면 살아 움직인다! 자바스크립트 쿠키클리커를 만들어봅시다!

5강(HTML 뼈대)과 6강(CSS 스타일링)을 통해 예쁜 화면을 완성했습니다. 하지만 아직 버튼을 눌러도 화면 숫자가 올라가거나 점수가 저장되지 않습니다. 오늘 웹의 두뇌와 심장인 JavaScript를 배우면, 마우스 클릭을 감지하여 점수를 올리고, 오븐을 업그레이드하고, 요정 셰프를 고용하는 진짜 살아 숨 쉬는 웹 아케이드 게임을 내 손으로 직접 만들 수 있습니다!

1. JS 3총사 마법

변수(기억 상자), 함수(마법 주문), 이벤트 리스너(클릭 감지)의 역할을 정복합니다.

2. 쿠키클리커 구현

클릭 시 점수 증가, 조건문 상점(오븐 구매), 자동 타이머(요정 셰프)를 직접 조작합니다.

3. AI 게임 로직 소환

피버 타임 2배 보너스, 오류 방어막 등 완성도 높은 게임 스크립트를 AI에게 주문합니다.

💡 주니어 개발자를 위한 핵심 개념 3가지

버튼을 누를 때 컴퓨터 브라우저 내부에서 어떤 일이 일어나는지 직관적으로 살펴봅시다.

🧠 1. 자바스크립트를 움직이는 3총사: 변수, 함수, 이벤트

게임이 플레이어의 조작에 반응하려면 다음 3가지 핵심 요소가 톱니바퀴처럼 맞물려 돌아가야 합니다:

let cookies = 0;

변수 (기억 상자): 현재 구운 쿠키 개수나 플레이어의 점수를 잊지 않고 담아두는 상자입니다.

function bake() { ... }

함수 (마법 주문): "쿠키를 1개 더하고 화면에 표시해!"라는 일련의 명령들을 묶어둔 레시피입니다.

btn.onclick = bake;

이벤트 (감각 기관): 마우스 클릭을 감지하여 마법 주문(함수)을 자동으로 실행시키는 방아쇠입니다.

🔄 2. DOM 조작: 기억 상자의 숫자를 화면에 실시간으로 반영하기

자바스크립트 변수 속 숫자가 100개가 되어도, 화면의 글자를 바꿔주지 않으면 플레이어는 알 수 없습니다. 이때 브라우저 화면의 글자를 실시간으로 갈아 끼우는 기술을 DOM(문서 객체 모델) 조작이라고 부릅니다:

// 1. HTML에서 id가 'cookie-count'인 글자 요소를 찾아온다
const display = document.getElementById('cookie-count');

// 2. 그 요소의 글자(innerText)를 변수값으로 쏙 교체한다!
display.innerText = cookies;

⚡ 3. 주니어 개발자가 절대 헷갈리지 말아야 할 자바스크립트 2대 원칙

원칙 1: 등호(=)는 '같다'가 아니라 '상자에 쏙 넣기(대입)'다!
수학에서 x = x + 1은 말이 안 되지만, 프로그래밍에서는 "기존 x 상자의 값에 1을 더해서 다시 x 상자에 넣어라!"라는 가장 중요한 대입 명령입니다.

원칙 2: 대소문자를 틀리면 컴퓨터는 다른 사람으로 안다!
자바스크립트는 대소문자를 아주 엄격하게 구분합니다. cookieCount와 cookiecount는 컴퓨터에게 완전히 다른 별개의 상자이므로 카멜케이스(camelCase) 표기법을 정확히 지켜야 합니다.

1. 쿠키클리커 3대 필수 로직(변수+클릭+DOM) 소환 퀘스트

약점: 자바스크립트의 변수, 이벤트 리스너, DOM 조작 연결
[Goal]: 웹 브라우저에서 버튼을 누를 때마다 점수가 1씩 올라가 화면에 실시간으로 표시되는 '가장 심플한 쿠키클리커 자바스크립트' 코드를 작성해줘. [Actor]: 초보자에게 코딩을 가르치는 친절한 주니어 웹 게임 튜터 [Condition]: - 세 가지 핵심 요소가 반드시 들어갈 것: 1) 점수를 기억하는 변수 let score = 0; 2) 점수를 1 증가시키고 화면을 갱신하는 함수 function handleClick() 3) 버튼에 연결된 클릭 이벤트 addEventListener('click', handleClick) - 화면의 <span id="score"> 요소를 innerText로 갱신할 것. - 초보자도 1초 만에 이해할 수 있도록 매 줄마다 쉬운 한국어 주석을 달아줘. [Output Format]: - HTML + JS가 포함된 순수 코드 블록 - 변수, 함수, 이벤트의 역할을 어린이 눈높이로 1줄씩 요약
🤖 AI의 놀라운 코드 생성 마법:

변수 선언부터 DOM 탐색, 이벤트 리스너 부착까지 단 10줄 이내의 가장 완벽하고 군더더기 없는 초보자용 표준 스크립트를 즉시 완성해 줍니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

자바스크립트의 이벤트 기반 프로그래밍(Event-driven Programming) 모델은 사용자의 동작(Input)➔연산(Process)➔화면 갱신(Output)의 표준 3단 구조를 따르기 때문입니다.

2. Undefined와 NaN 버그 탐정 QA 검사관 퀘스트

약점: 문자열과 숫자의 덧셈 혼동("1" + 1 = "11") 및 미선언 변수 참조 버그
[Goal]: 내가 작성한 자바스크립트 코드에서 숫자가 이상하게 더해지거나 오류가 터지는 '치명적 버그 3가지'를 찾아 교정해줘. [Actor]: 구글 크롬 개발자 도구 디버깅 전문 시니어 QA 엔지니어 [Condition]: - 검사할 버그 코드: let cookieCount = "0"; function clickCookie() { cookieCount = cookieCount + 1; document.getElementById("count").innerText = cookieCount; if (cookiecount >= 10) { alert("황금 오븐 열림!"); } } - 문제점: 1) 1을 더했더니 1이 아니라 "01", "011", "0111"로 늘어남! 2) 오븐 열림 알림이 영원히 뜨지 않음! - 원인을 어린이 눈높이로 진단하고 완벽한 정답 코드를 제시해줘. [Output Format]: 1. 왜 "0111"로 늘어났는지 '문자열과 숫자 덧셈의 차이' 해설 2. 왜 알림창이 안 떴는지 '대소문자 오타(cookiecount)' 지적 3. 말끔하게 버그가 고쳐진 올바른 자바스크립트 코드
🤖 AI의 놀라운 코드 생성 마법:

초보자가 가장 많이 울음을 터뜨리는 '문자열 이어붙이기 버그'와 '카멜케이스 오타'를 1초 만에 족집게처럼 잡아내어 속 시원한 해설을 선사합니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

자바스크립트의 동적 타입 변환(Type Coercion) 규칙상 따옴표가 붙은 문자열과 숫자를 더하면 수학 덧셈이 아닌 글자 붙이기가 실행되기 때문입니다.

3. 잔액 부족 방어막! 조건문(if/else) 상점 업그레이드 퀘스트

약점: 조건문 if (cookies >= cost) 검증 없이 마이너스 통장이 되는 로직 결함 방지
[Goal]: 쿠키클리커 게임에서 쿠키가 부족할 때는 구매를 거절하고, 충분할 때만 점수를 깎고 능력을 올려주는 '조건문(if/else) 상점 시스템'을 만들어줘. [Actor]: 게임 경제 밸런스 및 부정 결제 방지 전문 게임 서버 개발자 [Condition]: - 업그레이드 아이템: '황금 오븐' (가격: 쿠키 10개, 효과: 클릭당 쿠키 +1 영구 증가) - 구매 함수 buyOven() 규칙: 1) 현재 쿠키가 10개 이상인지 if (cookies >= 10) 조건으로 검사할 것. 2) 충분하다면: 쿠키 10개를 차감하고(cookies -= 10), 클릭 파워를 1 올리고(clickPower += 1), 화면을 갱신. 3) 부족하다면: alert('쿠키가 부족합니다! 10개를 모아오세요!') 경고창을 띄우고 점수를 깎지 말 것. [Output Format]: - 완벽하게 검증된 자바스크립트 코드 함수 - if와 else가 어떻게 문지기 역할을 하는지 주니어 개발자를 위한 해설
🤖 AI의 놀라운 코드 생성 마법:

쿠키가 0개인데도 버튼을 눌러 점수가 마이너스(-10개)로 떨어지는 엉터리 버그를 철통같이 막아내는 조건문 가드(Guard) 로직을 설계해 줍니다.

💡 왜 그럴까요? (컴퓨터 과학 비밀):

컴퓨터 프로그램의 모든 지능은 조건 분기(Branching)에서 출발합니다. 참(true)과 거짓(false)을 판단하는 if문이 게임의 법칙과 경제를 수호합니다.

⏰

4. 잠자는 동안에도 구워진다! 요정 셰프 자동 타이머(setInterval) 퀘스트

약점: 비동기 타이머 setInterval과 중복 실행 방지 플래그 관리
[Goal]: 플레이어가 손가락 하나 까딱하지 않아도 1초마다 자동으로 쿠키가 1개씩 쑥쑥 늘어나는 '요정 셰프 자동 생산 타이머' 코드를 만들어줘. [Actor]: 방치형(Idle) 모바일 게임 전문 프로그래머 [Condition]: - 자바스크립트 내장 타이머 setInterval() 함수를 활용할 것. - 요정 셰프 고용 함수 hireFairy() 규칙: 1) 가격: 쿠키 30개 (쿠키가 부족하면 구매 불가) 2) 이미 요정을 고용했다면 타이머가 2개, 3개 겹쳐서 폭주하지 않도록 중복 고용 방지 플래그(isFairyHired)를 둘 것. 3) 고용 성공 시 1초(1000밀리초)마다 cookies를 1씩 올리고 화면을 실시간 업데이트할 것. [Output Format]: - 요정 셰프 고용 및 setInterval 자동 실행 자바스크립트 코드 - 타이머가 겹쳐서 미친 듯이 숫자가 폭주하는 버그를 막는 비결 2줄 요약
🤖 AI의 놀라운 코드 생성 마법:

버튼을 연타해서 타이머가 여러 개 중첩되어 초당 수백 개씩 올라가는 악명 높은 '타이머 폭주 버그'를 불리언 플래그로 완벽하게 차단합니다.

💡 왜 그럴까요? (컴퓨터 과학 비밀):

자바스크립트 이벤트 루프(Event Loop)의 타이머 API는 백그라운드 큐에서 주기적으로 실행되므로, 이전 타이머 상태를 철저히 추적 관리해야 합니다.

5. 10콤보 달성 시 피버 타임(Fever Time) 2배 보너스 퀘스트

약점: 콤보 카운터와 타임아웃을 결합한 동적 게임 상태 머신 설계
[Goal]: 쿠키를 빠르게 10번 연속으로 클릭하면 화면이 황금빛으로 물들며 5초간 점수가 2배로 폭발하는 '피버 타임(Fever Time)' 시스템을 자바스크립트로 구현해줘. [Actor]: 오락실 아케이드 게임 타격감 & 보너스 연출 전문 기획자 [Condition]: - 요구사항: 1) 1.5초 이내에 연속으로 쿠키를 누를 때마다 combo 수가 1씩 누적됨. 2) combo가 10에 도달하면 즉시 5초간 '피버 모드' 가동 (isFever = true, 클릭당 +2 쿠키). 3) 피버 모드가 시작되면 화면 상단에 '🔥 FEVER TIME! 5초간 쿠키 2배!' 배너 노출. 4) setTimeout()을 이용해 정확히 5초 뒤 피버 모드가 해제되고 콤보가 0으로 초기화될 것. [Output Format]: - 콤보 계산과 setTimeout 타이머가 결합된 완벽한 게임 스크립트 - 플레이어가 지루하지 않게 긴장감을 주는 콤보 타임아웃 원리 해설
🤖 AI의 놀라운 코드 생성 마법:

단순한 클릭 노가다 게임을 손에 땀을 쥐게 만드는 아케이드 명작 게임으로 변신시키는 '콤보-피버 상태 머신' 코드를 환상적으로 직조해 냅니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

게임 루프에서 '상태(State)'와 '시간 제약(Timeout)'을 결합하면 플레이어의 뇌에 도파민을 분비시키는 즉각적인 인터랙티브 보상 체계가 완성됩니다.
