7강 — 반응하는 마법 상자: JavaScript 기초와 버튼 인터랙션

지금까지 배운 웹 페이지에 드디어 진짜 뇌와 심장을 선물할 시간입니다! 사용자의 마우스 클릭 신호(이벤트)를 감지하고, 숫자를 기억(변수)하며, 화면을 실시간으로 바꾸는 JavaScript의 핵심 3총사를 배우고 중독성 넘치는 클리커 게임을 제작합니다.

이번 강의에서 배우는 것

  • 웹 페이지에 생동감 넘치는 반응을 불어넣는 JavaScript의 역할과 실행 원리를 이해합니다.
  • 데이터를 기억하는 상자인 변수(let, const)의 개념을 익힙니다.
  • 행동을 묶어서 이름 붙이는 함수(function)를 만들고 호출할 수 있습니다.
  • 사용자가 버튼을 클릭하는 순간을 감지하는 이벤트(onclick, addEventListener)를 연결합니다.
  • 자바스크립트로 HTML 화면의 글자와 숫자를 실시간으로 바꾸는 DOM(문서 객체 모델) 조작의 기초를 완성합니다.

웹 페이지에 '뇌'를 넣어주는 JavaScript 3총사

HTML이 뼈대이고 CSS가 옷이라면, JavaScript는 생각을 하고 움직이게 만드는 '두뇌와 근육'입니다. 자바스크립트가 작동하는 원리는 딱 3가지만 기억하면 끝납니다!

1. 변수 (기억하기)

"지금 플레이어의 점수는 100점이야!", "모은 마나는 5개야!" 하고 숫자를 상자에 넣어 기억해 둡니다.
let score = 0;

2. 함수 (행동 묶기)

"점수를 1 올리고, 화면의 글씨를 바꾸자!"라는 여러 개의 명령을 하나의 마법 주문처럼 묶어둡니다.
function addScore() { ... }

3. 이벤트 (신호 받기)

"사용자가 마우스로 버튼을 딸깍 눌렀다!"라는 현실 세계의 신호를 컴퓨터가 알아채는 순간입니다.
onclick="addScore()"

마법 공식: [사용자가 클릭(이벤트)] ➔ [함수 실행] ➔ [변수 값 변경 및 화면 업데이트]

화면의 글자를 쏙 바꿔치기하는 DOM 마법

자바스크립트가 HTML 화면에 있는 글자를 바꿀 때 사용하는 비밀 주문 2가지가 있습니다.

1. 이름표(id)로 원하는 부품 찾기

// HTML에서 id="score-text"라는 이름표를 가진 요소를 딱 집어오기!
const scoreDisplay = document.getElementById("score-text");

2. 내용물(textContent)을 새로운 값으로 갈아끼우기

// 그 상자 안의 글씨를 실시간으로 바꾸기!
scoreDisplay.textContent = "현재 점수: 50점!";

👉 이 두 줄만 알면 클릭할 때마다 골드가 올라가고 대사가 바뀌는 모든 게임 로직을 만들 수 있습니다!

인터랙티브 체험관: 마법 보석 클리커 & 실시간 JS 컨트롤러

왼쪽의 마법 보석(💎)을 클릭해 보세요! 마나가 모이고 레벨업 대사가 바뀝니다. 오른쪽의 JavaScript 코드가 실제로 어떻게 변수와 함수를 실행하는지 관찰해 보세요!

실시간 미니 클리커 아케이드
클릭당 마나: +1
현재 축적된 마나
0 마나
(보석을 마우스로 클릭해 보세요!)
🧙‍♂️ 루카: "보석을 클릭해서 고대 마나를 모아봐!"
실행 중인 JavaScript 핵심 코드 ● 실시간 동기화 
// 1. 변수 선언 (데이터 기억하기)
let mana = 0;
let clickPower = 1;

// 2. 보석 클릭 함수 (행동 묶음)
function handleGemClick() {
  // 마나 상자에 파워만큼 더하기!
  mana = mana + clickPower;

  // 화면의 글자를 새로운 마나 값으로 교체!
  document.getElementById("mana-count").textContent = mana + " 마나";
}

// 3. 마나 증폭 함수
function upgradeClickPower() {
  if (mana >= 20) {
    mana = mana - 20;
    clickPower = clickPower + 5;
  }
}
관찰 포인트: 보석을 누를 때마다 오른쪽 코드의 mana 값이 실시간으로 증가하는 것이 보이나요? 이것이 바로 자바스크립트 상태(State)의 변화입니다!

단계별 실습: 내 손으로 직접 만드는 클릭 카운터

1단계: HTML에 숫자 표시창과 버튼 만들기

글자가 들어갈 <h2 id="counter">0</h2>와 클릭할 <button id="btn-click">클릭!</button>을 준비합니다.

2단계: `<script>` 태그 안에 변수 만들기

숫자를 기억할 변수 let count = 0;을 선언합니다.

3단계: 클릭할 때 실행될 함수 조립하기

숫자를 1 올리고 화면을 갱신하는 함수를 작성합니다: 

function increaseCount() {
  count = count + 1; // 1씩 증가
  document.getElementById("counter").textContent = count;
}

4단계: 버튼에 `onclick` 마법 연결하기

HTML 버튼에 <button onclick="increaseCount()">를 적어주면 완성입니다!

실습용 프롬프트 마법 주문서

주문서 1: 초보자용 클리커 게임 JS 로직 생성기 
너는 중학생에게 친절하게 자바스크립트를 가르쳐주는 코딩 선생님이야.
초보자용 웹 클리커 게임 코드를 만들고 싶어.

[게임 아이디어]
- 테마: [예: 고양이 쓰다듬기 클리커 / 골드 모으기 / 몬스터 공격하기]
- 클릭할 버튼 이름: [예: 🐾 고양이 쓰다듬기]
- 표시할 점수 단위: [예: 하트 0개]

[필수 요청 사항]
1. HTML과 JavaScript가 함께 들어있는 단일 파일 구조로 작성해 줘.
2. 1) 점수를 기억하는 변수(let), 2) 클릭할 때 점수가 1 오르는 함수, 3) 0점으로 되돌리는 리셋 함수를 포함해 줘.
3. 초보자가 한 줄씩 이해할 수 있도록 아주 상세한 한국어 주석(// 주석)을 달아줘.
주문서 2: 자바스크립트 오류 버그 헌터 
내가 작성한 자바스크립트 버튼이 클릭해도 아무 반응이 없어.
F12 개발자 도구 콘솔에 빨간 오류가 뜨는데 원인이 뭔지 쉽게 설명해 주고 고쳐줘:

[오류 메시지]
[예: Uncaught TypeError: Cannot set properties of null (setting 'textContent')]

[내 코드]
[여기에 내 코드를 붙여넣으세요]

버그 헌터 코너: 자바스크립트 단골 오류 3선

1. ID 이름 불일치 (Cannot set properties of null)

원인: HTML에는 id="score"라고 썼는데, JS에서는 getElementById("scoreText")라고 다른 이름을 부름.

👉 해결: HTML의 id와 JS의 괄호 안 철자가 대소문자까지 100% 똑같은지 확인합니다!

2. 문자열 덧셈의 함정 (1 + 1 = "11"?)

원인: 숫자가 아니라 따옴표로 감싼 글자 "1"에 1을 더하면 2가 아니라 "11"이 됨.

👉 해결: 숫자를 다룰 때는 따옴표 없이 let score = 0;으로 선언해야 합니다.

3. 스크립트 실행 타이밍 오류

원인: HTML 버튼이 화면에 생기기도 전에 <script>가 먼저 실행되어 버튼을 못 찾음.

👉 해결: <script> 태그를 문서의 맨 아래인 </body> 바로 위에 두면 안전합니다!

오늘의 핵심 미션: 나만의 미니 클리커 아케이드 제작

🎯 미션 목표: 버튼을 누르면 숫자가 올라가고, 특정 점수를 달성하면 캐릭터의 대사가 바뀌는 나만의 클리커 게임을 완성하세요!

미션 진행 3단계

  1. 테마 정하기: 보석 모으기, 몬스터 체력 깎기, 쿠키 굽기 등 내 취향의 테마를 정합니다.
  2. AI와 함께 기본 코드 조립: 주문서 1을 이용해 점수 증가 버튼과 리셋 버튼을 만듭니다.
  3. 보너스 레벨업 조건 추가: 점수가 10점을 넘으면 "초보 탈출!", 50점을 넘으면 "마스터 모험가!"로 대사가 바뀌도록 업그레이드합니다.
