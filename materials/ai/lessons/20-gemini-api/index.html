오류 연구소 & 보안: 401, 403, 429 빨간 딱지 해결사

코딩을 하다 보면 구글 서버가 친절하게 빨간 숫자 딱지(HTTP 상태 코드)를 붙여줄 때가 있어요. 겁먹지 말고 딱지에 적힌 숫자를 보면 무엇이 잘못되었는지 바로 고칠 수 있답니다!

401
Unauthorized (열쇠가 엉뚱해요!) 비밀 열쇠를 복사할 때 앞뒤에 공백(띄어쓰기)이 들어갔거나 끝 글자가 잘렸을 때 발생해요. AI Studio에서 다시 깔끔하게 복사해 보세요.
403
Forbidden (출입 금지 권한 없음) 선택한 모델 이름에 오타가 있거나, 구글 계정에서 Generative Language API 기능이 켜져 있지 않을 때 나타나요.
429
Too Many Requests (주문이 너무 빨라요! 🏃) 무료 티어는 1분에 15번까지만 질문할 수 있어요. 연타로 버튼을 눌렀다면 5초 정도 숨을 고르고 다시 요청해 보세요!
오늘 당장 구글 계정이 없어도 걱정 마세요! (모의 모드 지원)

우측 실습 창에는 실제 구글 API Key 없이도 통신 과정을 100% 동일하게 체험할 수 있는 '안전 모의(Mock) 모드'가 탑재되어 있어요. 학교나 공용 PC에서도 안심하고 실습을 완료할 수 있답니다!

// 1. 구글 Gemini API 엔드포인트와 비밀 열쇠
const API_KEY = "AIzaSy..."; // Google AI Studio에서 발급받은 비밀 열쇠
const URL = `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${API_KEY}`;

// 2. 비동기 통신 함수 정의
async function askGemini(userQuestion) {
  try {
    const response = await fetch(URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        system_instruction: {
          parts: [{ text: "너는 요리사 햄스터 셰프야. 말끝마다 '~찍!'을 붙여줘." }]
        },
        contents: [
          { parts: [{ text: userQuestion }] }
        ]
      })
    });

    if (!response.ok) {
      throw new Error(`HTTP 에러 발생! 상태 코드: ${response.status}`);
    }

    const data = await response.json();
    const answer = data.candidates[0].content.parts[0].text;
    console.log("AI의 답변:", answer);
    return answer;
  } catch (error) {
    console.error("통신 실패:", error);
  }
}
