QUEST 01 URL 해시 상태 직렬화 파서
웹 아키텍처 ★☆☆

URL Hash 기반 클라이언트 상태 직렬화(Serialize) 및 자동 복원(Deserialize) 함수 작성

서버 DB 없이도 도구 종류, 테마, 닉네임, 메시지를 URL 뒤에 인코딩하고, 페이지 로드 시 이를 파싱해 앱 화면을 온전히 복원하는 코드를 요청합니다.

실전 AI 복사 프롬프트
[역할] 너는 웹 프론트엔드 아키텍처와 URL 상태 관리를 전문으로 하는 시니어 개발자이자 코딩 멘토야. [목표] 서버 데이터베이스를 사용하지 않고도, 사용자의 설정 상태를 브라우저 주소창의 해시(#hash) 문자열로 인코딩하고 복원하는 serializeStateToHash(state) 및 parseHashToState() 함수를 자바스크립트로 작성해 줘. [세부 요구사항] 1. state 객체는 { tool: 'weather', theme: 'emerald', name: '은우의비서', msg: '안녕!' } 형태야. 2. 한글이나 특수문자가 깨지지 않도록 encodeURIComponent / decodeURIComponent 처리를 철저히 해 줘. 3. window.location.hash를 파싱할 때 '#' 기호를 안전하게 제거하고 URLSearchParams를 활용하는 최신 표준 방식을 적용해 줘. 4. 왜 URL 해시(#) 뒤의 문자열은 서버로 전송되지 않고 브라우저 클라이언트에서만 소비되는지 그 이유와 장점을 설명해 줘. 5. 초등학생도 쉽게 읽을 수 있도록 각 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: HTTP 스펙(RFC 3986)에 따르면 URL의 해시 프래그먼트(#)는 브라우저 내부 앵커용으로 정의되어 있어 서버 요청 헤더에 절대 실리지 않습니다. 따라서 서버 트래픽 비용 없이 100% 무료로 클라이언트 상태를 공유할 수 있습니다.

QUEST 02 Web Share & 클립보드 하이브리드
모바일 웹 ★★☆

Web Share API 지원 기기에서는 네이티브 공유 시트를, 미지원 기기에서는 1-Click 클립보드 복사를 실행하는 하이브리드 공유 모듈

스마트폰에서는 카카오톡·문자 다이얼로그를 띄우고, PC에서는 클립보드 복사와 토스트 알림을 띄우는 크로스 브라우징 함수를 작성합니다.

실전 AI 복사 프롬프트
[역할] 너는 크로스 플랫폼 모바일 웹 앱과 네이티브 인터페이스 연동 전문가야. [목표] 사용자가 [공유하기] 버튼을 눌렀을 때 모바일과 PC 환경에 맞추어 최적의 동작을 제공하는 shareCustomTool(toolTitle, toolText, shareUrl) 함수를 자바스크립트로 구현해 줘. [세부 요구사항] 1. navigator.share가 존재하는지 확인하여, 모바일 환경에서는 navigator.share({ title, text, url })을 실행해 줘. 2. 사용자가 공유 창을 열었다가 취소(AbortError)했을 때 브라우저 콘솔에 빨간 에러가 터지지 않도록 안전하게 try-catch로 감싸줘. 3. navigator.share가 없는 PC 환경에서는 navigator.clipboard.writeText(shareUrl)을 호출해 주소를 복사하고 '복사 완료!' 안내창을 띄워줘. 4. 초보자도 쉽게 따라 할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: Web Share API는 브라우저가 사용자 상호작용(사용자가 버튼을 클릭한 순간)에 한해서만 네이티브 시스템 시트를 호출할 수 있도록 엄격한 보안 권한(User Activation)을 요구합니다. 스팸 방지를 위한 웹 보안 표준 규격입니다.

QUEST 03 다중 테마 CSS 토큰 스위처
디자인 시스템 ★★☆

CSS 커스텀 프로퍼티(변수)를 활용한 4대 감성 테마(Sky, Emerald, Rose, Purple) 동적 스위칭 엔진

버튼 클릭 하나로 전체 애플리케이션의 배경 그라데이션, 포인트 뱃지, 폰트 컬러를 리렌더링 없이 GPU 가속으로 0.3초 부드럽게 전환하는 테마 시스템을 구축합니다.

실전 AI 복사 프롬프트
[역할] 너는 글로벌 디자인 시스템과 테마 토큰(Theme Tokens)을 설계하는 UI 엔지니어이자 프론트엔드 개발자야. [목표] 사용자가 선택한 테마에 따라 전체 웹 앱의 비주얼을 실시간으로 바꾸어주는 CSS 변수 기반 다중 테마 시스템을 만들어 줘. [세부 요구사항] 1. 4가지 테마(sky: 시원한 바다 파랑, emerald: 싱그러운 민트 초록, rose: 따뜻한 벚꽃 핑크, purple: 신비로운 우주 보라)의 CSS 커스텀 변수(--theme-primary, --theme-from, --theme-to, --theme-bg)를 정의해 줘. 2. 자바스크립트 함수 applyTheme(themeKey)를 작성해, document.documentElement 또는 컨테이너에 data-theme="emerald" 속성을 주입하게 해 줘. 3. 테마가 전환될 때 눈이 아프지 않도록 transition: all 0.3s ease-in-out을 적용하는 팁을 제공해 줘. 4. 모든 코드에 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: CSS 커스텀 프로퍼티(변수)를 변경하면 브라우저의 레이아웃(Reflow) 단계 없이 페인트(Repaint) 및 컴포지팅(Compositing) 단계만 거치므로, 수백 개 요소의 색상을 변경해도 60FPS의 매끄러운 화면 전환이 가능합니다.

로컬스토리지(localStorage)와 실시간 렌더링을 결합한 "나만의 즐겨찾기 도구" 영구 저장 매니저 구현

브라우저를 종료하거나 새로고침하더라도 내가 꾸민 설정값(도구 타입, 이름, 테마, 메시지)이 지워지지 않고 즉시 복원되는 스토리지 관리 클래스를 생성합니다.

실전 AI 복사 프롬프트
[역할] 너는 클라이언트 사이드 데이터 저장소와 웹 지속성(Persistence)을 전담하는 프론트엔드 엔지니어이자 교육자야. [목표] 사용자가 스마트 도구 빌더에서 조립한 설정을 localStorage에 안전하게 영구 저장하고, 다음 방문 시 자동으로 불러오는 ToolStorageManager 객체를 자바스크립트로 구현해 줘. [세부 요구사항] 1. saveConfig(config), loadConfig(), clearConfig() 3개의 메서드를 작성해 줘. 2. JSON.stringify()와 JSON.parse()를 안전하게 try-catch로 감싸, 로컬 스토리지가 손상되었을 때도 기본값(defaultConfig)을 반환하게 해 줘. 3. 브라우저의 시크릿 모드나 용량 초과(QuotaExceededError) 상황에서도 프로그램이 다운되지 않는 예외 처리 방패를 달아줘. 4. 초보자도 쉽게 따라 할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 쿠키(Cookie)는 모든 HTTP 통신마다 서버로 전송되어 네트워크 속도를 갉아먹지만, localStorage는 오직 클라이언트 브라우저 로컬에만 머물며 5MB라는 대용량을 무료로 제공합니다.

QUEST 05 메신저 풍선 미리보기(OG) 태그
소셜 최적화 ★★★

카카오톡이나 문자 메신저에 링크를 붙여넣었을 때 예쁜 카드 미리보기를 띄우는 Open Graph(OG) 메타 태그 설계

그냥 까만 글씨 주소만 덩그러니 가는 것이 아니라, 매력적인 도구 제목, 대표 썸네일 이미지, 설명이 카드 박스로 뿅 나타나게 만드는 소셜 메타데이터 기술을 배웁니다.

실전 AI 복사 프롬프트
[역할] 너는 소셜 미디어 메타데이터 최적화(SMO)와 웹 검색 엔진 최적화(SEO)를 담당하는 전문가야. [목표] 학생이 만든 나만의 스마트 도구 웹 링크를 카카오톡이나 디스코드, 인스타그램 DM에 전송했을 때 매력적인 미리보기 리치 카드(Rich Snippet)가 뜨도록 HTML 메타 태그 템플릿을 작성해 줘.
