QUEST 01. 1초에 60번 뛰는 게임 루프 소환하기

requestAnimationFrame 심장 박동 템플릿
[Goal]: HTML5 캔버스(Canvas) 기반 미니 아케이드 게임을 만들기 위해, 1초에 60번 화면을 부드럽게 다시 그리는 requestAnimationFrame 게임 루프 자바스크립트 템플릿을 작성해 줘. [Condition]: 1. update() 함수에서는 게임 오브젝트의 위치를 계산하고, render() 함수에서는 캔버스를 지우고 다시 그리도록 역할을 분리해 줘. 2. 게임이 일시정지(pause)되거나 게임오버(gameOver)되었을 때 루프를 멈추는 cancelAnimationFrame 처리도 포함해 줘. 3. 초보 학생도 이해할 수 있게 각 코드 줄마다 친절한 한국어 주석을 달아줘.
최신 AI의 소환 마법

화면이 깜빡거리지 않고 60 FPS로 물 흐르듯 작동하는 완벽한 게임 루프 뼈대 코드를 즉시 소환해 냅니다.

컴퓨터 과학 비밀

setInterval 대신 requestAnimationFrame을 쓰면 브라우저가 모니터 주사율과 완벽히 동기화되어 끊김 현상을 방지합니다.

💥

QUEST 02. 우주선과 별똥별의 거리를 재는 충돌 판정

AABB 박스 충돌 & 피타고라스 거리 계산
[Goal]: 웹 캔버스 게임에서 우주선(Player)과 하늘에서 떨어지는 별똥별(Meteor)이 서로 부딪혔는지 감지하는 충돌 판정(Collision Detection) 함수를 작성해 줘. [Condition]: 1. 사각형 바운딩 박스(AABB) 방식과 원형 중심 거리(Math.hypot) 방식 중 게임에 가장 적합한 방식을 제안해 줘. 2. 충돌이 감지되면 true를 반환하고, 플레이어의 HP를 1 깎고 별똥별을 배열에서 제거(splice)하는 로직을 보여줘. 3. 중학생 눈높이에서 x, y 좌표 차이와 크기 비교 원리를 주석으로 설명해 줘.
최신 AI의 소환 마법

복잡한 수학 계산 없이도 컴퓨터가 "앗! 부딪혔다!"를 1초에 60번 정확하게 판정하는 감각 함수를 제공합니다.

컴퓨터 과학 비밀

게임 속 모든 물리적 상호작용은 눈에 보이지 않는 좌표 간의 덧셈·뺄셈 수학 계산으로 구현됩니다.

🚀

QUEST 03. 얼음판 위를 미끄러지듯 부드러운 관성 조작

가속도와 마찰력(Friction) 물리 엔진
[Goal]: 우주선 조작감을 업그레이드하기 위해, 방향키를 누르면 딱딱하게 끊기지 않고 부드럽게 가속도가 붙으며 미끄러지는 관성(Inertia) 이동 코드를 작성해 줘. [Condition]: 1. 속도 변수(vx)와 마찰력 계수(friction = 0.92)를 적용해 키를 뗐을 때 자연스럽게 감속되게 해줘. 2. 캔버스 화면 왼쪽/오른쪽 벽에 부딪혔을 때 화면 밖으로 탈출하지 못하도록 멈추는 경계 제한을 걸어줘. 3. 이벤트 리스너에서 keydown/keyup 플래그를 객체(keys)로 관리하는 표준 방식을 사용해 줘.
최신 AI의 소환 마법

키보드를 살짝만 눌러도 우주선이 스케이트를 타듯 매끄럽게 비행하는 고급 조작감을 완성해 줍니다.

컴퓨터 과학 비밀

현실 세계의 물리 법칙(가속도, 마찰력, 중력)을 수학 변수로 흉내 내는 것을 게임 물리학(Game Physics)이라고 부릅니다.

QUEST 04. 15초마다 터지는 피버 타임 & 황금 별 보너스

타이머 이벤트 & 룰 반전(Bonus Party)
[Goal]: 게임의 긴장감과 재미를 높이기 위해, 15초마다 5초 동안 배경이 네온 핑크로 바뀌며 황금 별이 쏟아지는 '피버 타임(Fever Time)' 시스템을 추가해 줘. [Condition]: 1. 피버 타임 중에는 별똥별을 피하는 대신 '먹으면 점수가 10점씩 오르는' 보너스 모드로 규칙이 반전되게 해줘. 2. 화면 상단에 'FEVER TIME! X2' 네온 텍스트가 깜빡이도록 캔버스 드로잉 효과를 넣어줘. 3. 초보 개발자도 기존 코드에 쉽게 끼워 넣을 수 있도록 feverMode 불리언 플래그 기반으로 작성해 줘.
최신 AI의 소환 마법

피하기만 하던 수동적인 게임이 갑자기 신나는 보너스 파티 타임으로 뒤바뀌는 룰 반전 코드를 제안합니다.

컴퓨터 과학 비밀

게임 디자이너들은 유저가 지루해하지 않도록 일정한 시간 주기나 확률로 규칙이 바뀌는 '변주(Dynamic Event)'를 배치합니다.

QUEST 05. 외계 보스 등장 & 미사일 발사 슈팅 확장

투사체(Projectile) 배열 & 애자일 기능 확장
[Goal]: 별똥별 피하기 아케이드 게임에, 50점을 넘기면 거대한 외계 보스 몬스터가 상단에 등장하고 플레이어가 스페이스바로 미사일을 쏘아 격추하는 보스전 기능을 추가해 줘. [Condition]: 1. 플레이어가 쏘는 미사일 배열(bullets)을 만들고 위쪽으로 날아가는 궤적을 그려줘. 2. 보스의 HP 게이지 바를 상단에 표시하고, 미사일이 보스에게 닿았을 때 보스 HP가 깎이는 충돌 로직을 구현해 줘. 3. 코드가 너무 복잡해지지 않도록 핵심 보스 객체와 발사 로직만 간결하고 명확하게 작성해 줘.
최신 AI의 소환 마법

단순한 피하기 게임이 레트로 오락실의 슈팅 명작 게임(갤러그/인베이더)으로 진화하는 확장 코드를 구현합니다.

컴퓨터 과학 비밀

소프트웨어 개발에서는 가장 단순한 버전(MVP)을 먼저 동작시킨 뒤 새로운 기능을 계단식으로 추가하는 애자일(Agile) 방식을 사용합니다.
