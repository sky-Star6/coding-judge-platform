시즌 2: 미니 웹 아케이드 9강 웹 기초 미니 프로젝트 (MVP)

9강 — 웹 기초 미니 프로젝트: 하늘에서 떨어지는 별똥별 피하기 & MVP 아케이드 완성

지금까지 배운 HTML(뼈대) + CSS(스타일) + JavaScript(로직)의 모든 마법을 하나로 융합할 시간입니다! 키보드 방향키 신호를 감지하고, 초당 60프레임으로 화면을 다시 그리며, 캐릭터와 운석의 충돌을 계산하는 첫 완성형 실시간 웹 아케이드 게임을 완성하고 친구들과 테스트합니다.

오늘 완성할 결과물과 성공 기준

이번 9강에서는 "완벽한 앱을 한 번에 만들겠다"는 욕심 대신, 핵심 기능이 먼저 제대로 동작하는 최소 기능 제품(MVP)을 작게 완성하고 점진적으로 발전시키는 실전 개발 워크플로우를 체득합니다.

  • 소프트웨어 개발의 핵심 철학인 최소 기능 제품(MVP, Minimum Viable Product)의 개념을 이해합니다.
  • 사용자의 키보드 입력(keydown 이벤트)을 감지하여 캐릭터 좌표를 실시간 변경합니다.
  • 프레임마다 물체를 아래로 떨어뜨리고 화면을 갱신하는 게임 루프(Game Loop)를 구성합니다.
  • 두 물체의 좌표(X, Y) 거리를 계산하여 충돌 여부를 감지하는 기초 충돌 판정(Collision Detection)을 구현합니다.
  • 친구 또는 동료에게 직접 플레이하게 한 뒤 사용자 피드백을 수집하여 1가지 이상의 개선 사항을 패치합니다.
평가 영역 기본 수준 (Lv.1) 우수 수준 (Lv.2) 도전 과제 (Lv.3)
MVP 게임 루프 캐릭터가 좌우로 움직이고 장애물이 아래로 낙하 체력(HP)과 점수 시스템이 연동된 완전한 루프 시간 경과에 따라 난이도(낙하 속도, 개수) 자동 조절
충돌 판정 장애물이 화면 맨 아래에 닿으면 점수 증가 좌표 거리를 비교해 캐릭터 충돌 시 하트 감소 보너스 별 획득 및 피격 시 깜빡임 무적 효과 구현
사용자 피드백 게임 조작법을 화면에 명확히 표기 테스터 의견을 반영해 속도/크기 밸런스 조정 모바일 터치 조작(온스크린 버튼) 지원

핵심 개념: 웹 아케이드를 지탱하는 3대 기둥

움직이는 게임을 만들기 위해서는 정적인 웹사이트와 다른 '동적 루프 사고방식'이 필요합니다.

1. 최소 기능 제품 (MVP)

화려한 그래픽이나 10가지 아이템을 한꺼번에 만들려다 실패하지 마세요! "움직이고, 피하고, 끝난다"라는 핵심 규칙만 담아 빠르게 작동시키는 것이 개발의 비결입니다.

// MVP 규칙: 1개 캐릭터 + 1종류 낙하물 + 점수

2. 키보드 이벤트 (Keydown)

사용자가 누른 키의 이름(e.key === "ArrowLeft")을 판별하여 플레이어의 X좌표(playerX)를 15픽셀씩 이동시킵니다.

window.addEventListener("keydown", (e) => {
  if (e.key === "ArrowLeft") playerX -= 15;
});

3. 거리 기반 충돌 판정

플레이어와 떨어지는 운석 사이의 가로 거리(Math.abs(pX - oX))와 세로 거리가 모두 일정 범위(예: 30px) 안으로 들어오면 "충돌!"로 판정합니다.

if (Math.abs(pX - mX) < 30 && Math.abs(pY - mY) < 30) {
  hp--; // 체력 감소!
}

핵심 요약: 게임 개발 4대 라이프사이클

① 초기화 (Init) 점수 0점, 체력 3개, 플레이어 위치 중앙 배치, 장애물 배열 비우기를 실행합니다.
② 입력 수신 (Input) 키보드 좌우 화살표나 온스크린 터치 버튼을 감지하여 캐릭터의 목표 이동 방향을 갱신합니다.
③ 상태 갱신 (Update) 매 프레임마다 운석의 Y좌표를 증가시키고, 충돌 여부 및 점수 증가를 계산합니다.
④ 렌더링 (Render) 이전 프레임 잔상을 지우고 최신 좌표에 우주선, 별, 운석을 다시 그립니다.

게임 엔진 4단계 실행 루프 초당 60프레임
1. 키보드 사용자가 누른 좌/우 방향키로 playerX 갱신
2. 장애물 운석 배열을 순회하며 y += speed 아래로 낙하
3. 충돌 검사 우주선과 운석의 가로/세로 거리 30px 이내 감지
4. 재렌더링 캔버스를 지우고 새 좌표에 스프라이트 렌더링
실시간 충돌 판정 엔진 코드
// 충돌 판정 공식 (Collision Check) function checkCollision(pX, pY, mX, mY) { const diffX = Math.abs(pX - mX); const diffY = Math.abs(pY - mY); // 가로 30px & 세로 30px 안쪽이면 피격! return (diffX < 30 && diffY < 30); }

function update() {

단계별 실습 가이드: 나만의 아케이드 완성하기

작은 기능부터 하나씩 만들어 작동을 검증하는 4단계 MVP 구축 실습입니다.

1단계: 플레이어 위치와 키보드 리스너 연결

화면 가로 폭(400px) 중앙에 플레이어 X좌표를 두고, 화살표를 누를 때마다 화면 밖으로 나가지 않게 경계(0 ~ 360)를 제한합니다. 

let playerX = 180;
const playerY = 250;
const speed = 20;

window.addEventListener("keydown", (e) => {
  if (e.key === "ArrowLeft") {
    playerX = Math.max(0, playerX - speed);
  } else if (e.key === "ArrowRight") {
    playerX = Math.min(360, playerX + speed);
  }
});

2단계: 운석(장애물) 배열과 자동 낙하 루프

일정 주기마다 무작위 가로 위치(Math.random() * 370)에서 운석을 생성하고 매 프레임마다 아래로 전진시킵니다. 

let meteors = [];

function spawnMeteor() {
  meteors.push({
    x: Math.random() * 370,
    y: -20,
    speed: 3 + Math.random() * 3
  });
}

function updateMeteors() {
  meteors.forEach(m => m.y += m.speed);
  // 화면 바닥을 무사히 통과한 운석은 제거하고 점수 10점 획득!
  meteors = meteors.filter(m => {
    if (m.y > 300) {
      score += 10;
      return false;
    }
    return true;
  });
}

3단계: 충돌 판정과 체력 감소 처리

우주선 중심과 운석 중심 사이의 거리를 계산해 부딪히면 하트를 깎고 체력이 0이 되면 게임을 종료합니다. 

for (let i = meteors.length - 1; i >= 0; i--) {
  const m = meteors[i];
  if (Math.abs(playerX - m.x) < 28 && Math.abs(playerY - m.y) < 28) {
    hp--;
    meteors.splice(i, 1); // 부딪힌 운석 폭발 제거
    if (hp <= 0) {
      endGame();
    }
    break;
  }
}

4단계: 동료 테스터 피드백 수집 및 밸런스 패치

직접 만든 게임을 친구에게 1분간 플레이하게 하고, "너무 빠르다" 또는 "조작이 뻑뻑하다"는 피드백을 반영해 수치를 수정합니다. 

// 테스터 피드백 반영: 이동 속도를 15 -> 22로 상향하여 조작감 대폭 개선!
const speed = 22;

오류 연구소: 단골 버그 3선과 디버깅 비법

실시간 게임 루프를 만들 때 겪게 되는 3대 대표 버그와 명쾌한 해결책입니다.

❌ 버그 1: 캔버스 잔상 번짐 현상

캐릭터가 이동할 때 이전 위치의 그림이 지워지지 않아 화면 전체에 지렁이처럼 흔적이 남습니다.

// 해결: 매 프레임마다 그리기 직전 캔버스 초기화
ctx.clearRect(0, 0, canvas.width, canvas.height);

❌ 버그 2: 화면 밖으로 탈출하는 우주선

왼쪽 키를 계속 누르고 있으면 우주선이 캔버스 왼쪽 경계를 뚫고 영원히 사라져 버립니다.

// 해결: Math.max와 Math.min으로 이동 범위 클램핑
playerX = Math.max(0, Math.min(360, playerX));

❌ 버그 3: 한 번 스쳤는데 하트 3개 즉사

운석이 캐릭터 몸을 통과하는 10프레임 동안 매 프레임마다 피격 판정이 실행되어 체력이 순식간에 증발합니다.

// 해결: 충돌 즉시 해당 운석 배열에서 삭제(splice)
meteors.splice(i, 1);
