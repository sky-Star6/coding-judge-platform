미션 브리핑: 웹 3총사의 위대한 합체 & MVP 원칙

우리는 지난 5강에서 HTML로 웹페이지의 뼈대를 세우고, 6강에서 CSS로 멋진 스타일 옷을 입혔으며, 7강과 8강에서 자바스크립트의 클릭 이벤트와 무작위 주사위를 다루었습니다.
이제 이 모든 지식을 합쳐 "살아 움직이는 진짜 컴퓨터 게임"을 만들 차례입니다!

💡 주니어 개발자의 특급 무기: MVP (최소 기능 제품) 전략

게임을 처음 만들 때 흔히 하는 실수는 "아이템 상점도 넣고, 100종류 몬스터도 넣어야지!" 하고 욕심을 내다가 지쳐서 포기하는 것입니다.
진짜 멋진 개발자는 가장 핵심적인 재미 1가지(우주선이 별똥별을 피한다!)를 먼저 작고 빠르게 완성한 뒤, 조금씩 살을 붙여나갑니다. 이것을 소프트웨어 세상에서는 MVP(Minimum Viable Product, 최소 기능 제품)라고 부릅니다.

개발 단계 핵심 구현 내용 성공 판정 기준
1단계: 도화지 & 조종사 HTML 캔버스를 깔고 키보드 화살표로 우주선을 좌우로 움직이기 조종 성공
2단계: 쏟아지는 별똥별 무작위 X 위치에서 생성된 별똥별이 중력처럼 아래로 계속 떨어지기 비행 장애물 출현
3단계: 충돌 & 점수판 우주선과 별이 부딪히면 하트(-1) 감소, 끝까지 살아남으면 점수 획득! MVP 완성

핵심 개념: 웹 게임을 움직이는 3대 마법 원리

멈춰 있는 웹페이지가 어떻게 손에 땀을 쥐게 하는 오락실 게임처럼 실시간으로 돌아갈 수 있을까요? 바로 아래 3가지 비밀 무기 덕분입니다.

1. 게임 루프 (Loop)

1초에 60장을 넘기는 초고속 플립북 만화책! 컴퓨터는 1초에 60번씩 도화지를 하얗게 지우고, 별똥별 위치를 살짝 아래로 내린 뒤, 다시 그리는 동작을 번개처럼 반복합니다.

requestAnimationFrame(loop)
2. 조종간 안테나

손가락으로 키보드를 누르고(keydown) 뗄 때(keyup)마다 실시간으로 알아채는 귀마개 안테나입니다. 키를 꾹 누르고 있으면 우주선이 멈추지 않고 미끄러지듯 이동합니다.

addEventListener('keydown')
3. 투명 범퍼카 센서

우주선과 별똥별을 둘러싼 투명한 사각형 상자가 서로 겹쳤는지 판정합니다(AABB 충돌 판정). 가로 좌표와 세로 좌표가 겹치는 순간 번쩍이며 하트가 깎입니다!

if (rect1.x < rect2.x + w ...)

단계별 조립 실습: HTML 도화지 + CSS 우주복 + JS 심장 엔진

컴퓨터 게임은 복잡해 보여도 딱 3단계로 조립하면 누구나 쉽게 만들 수 있습니다. AI 코딩 도우미에게 보낼 수 있는 마법 프롬프트 카드를 활용해보세요!

1단계: HTML 도화지 (<canvas>) 펴기 index.html

웹 브라우저에 가로 400px, 세로 280px 크기의 도화지를 깔고 점수판(HUD)을 올려놓습니다. 

<div class="game-container">
  <div class="hud">점수: <span id="score">0</span> | 생명: <span id="hp">❤️❤️❤️</span></div>
  <canvas id="gameCanvas" width="400" height="280"></canvas>
</div>
2단계: CSS 깊고 푸른 우주 감성 입히기 style.css

캔버스 뒤편에 칠흑 같은 우주와 푸른 네온 테두리, 부드러운 그림자를 더해 오락실 느낌을 살립니다. 

#gameCanvas {
  background: radial-gradient(circle, #1e1b4b 0%, #030712 100%);
  border: 2px solid #38bdf8;
  border-radius: 12px;
  box-shadow: 0 0 15px rgba(56, 189, 248, 0.3);
}
3단계: JS 무한 게임 루프 & 충돌 판정 가동 game.js

우주선의 X 좌표를 키보드로 바꾸고, 별똥별 배열을 순회하며 충돌 여부를 감지합니다. 

function gameLoop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  updateStars();      // 별똥별 아래로 떨어뜨리기
  drawPlayer();       // 우주선 그리기
  checkCollision();   // 부딪혔는지 검사!
  if (!isGameOver) requestAnimationFrame(gameLoop);
}

아케이드 연구소: 흔한 버그 2가지 해결 & 자가 회고

게임을 만들다 보면 누구나 마주치는 황당한 버그들이 있습니다. 주니어 개발자의 날카로운 눈으로 해결해봅시다!

버그 1: 우주선 화면 탈출 버그

왼쪽이나 오른쪽 키를 계속 누르고 있으면 우주선이 캔버스 밖으로 영원히 사라져버립니다!

💡 해결책: 화면 끝을 넘지 못하게 가두는 조건문 추가!
player.x = Math.max(0, Math.min(canvas.width - player.w, player.x));
버그 2: 게임오버 후 렉 유발 버그

게임이 끝났는데도 루프가 멈추지 않아 뒤에서 수천 개의 별똥별이 쌓여 컴퓨터가 버벅거립니다!

💡 해결책: isGameOver = true; 신호로 requestAnimationFrame 호출을 즉시 중단합니다.

🎓 개발자 공식 정의: 초당 60회(60fps) 이상 화면을 지우고, 객체의 위치를 업데이트한 뒤 다시 렌더링하는 실시간 연속 게임 실행 주기(Cycle)입니다.

2. 바운딩 박스 충돌 외래어·영문: 바운딩 박스 충돌 (AABB Collision Detection)
물리/기하
🧸 어린이 비유: "투명한 범퍼카 보호 상자끼리 서로 닿았는지 쾅 부딪혀 확인하는 충돌 센서!"

🎓 개발자 공식 정의: 2D 평면에서 축에 정렬된 사각형(Axis-Aligned Bounding Box)들의 좌표 범위가 서로 겹치는지(Overlap) 수학적으로 판별하는 고속 충돌 감지 기법입니다.

3. 이벤트 리스너 영문: Event Listener (keydown / keyup)
입력/이벤트
🧸 어린이 비유: "손가락으로 키보드를 꾹 누르고 뗄 때마다 빛의 속도로 캐릭터에게 전갈을 보내는 전령사!"

🎓 개발자 공식 정의: DOM 요소 또는 윈도우 창에서 사용자의 입력 사건이 발생했을 때 이를 포착하여 비동기적으로 처리 루틴을 트리거하는 이벤트 구독 모델입니다.

4. 최소 기능 제품 외래어·영문: MVP (Minimum Viable Product)
소프트웨어 공학
🧸 어린이 비유: "처음부터 거대한 로봇을 만들기보다, 딱 걷기만 하는 꼬마 로봇부터 빠르게 만들어 시험해보는 똑똑한 방법!"

🎓 개발자 공식 정의: 사용자에게 가치를 줄 수 있는 최소한의 핵심 기능만을 담아 가장 빠르게 출시하여 시장의 피드백을 검증하는 린(Lean) 개발 원칙입니다.

5. 캔버스 API 영문: HTML5 Canvas API (getContext('2d'))
그래픽/렌더링
🧸 어린이 비유: "자바스크립트 마법 붓으로 마음대로 그림을 그리고 지우는 디지털 스케치북!"

🎓 개발자 공식 정의: 스크립트(주로 JavaScript)를 사용하여 동적으로 비트맵 그래픽과 애니메이션을 2D 픽셀 단위로 직접 제어하고 렌더링하는 웹 그래픽 표준 인터페이스입니다.

6. 상태 기계 영문: State Machine (Ready / Playing / GameOver)
아키텍처/상태
🧸 어린이 비유: "시작 전(대기), 비행 중(플레이), 부딪힌 뒤(게임오버)처럼 딱 정해진 규칙에 따라서만 변신하는 로봇 두뇌!"

🎓 개발자 공식 정의: 시스템이 가질 수 있는 유한한 상태(State)들과 이들 간의 전이(Transition) 규칙을 정의하여 복잡한 로직을 안정적으로 제어하는 유한 상태 기계(FSM) 모델입니다.

1. 무한 렌더링 루프: requestAnimationFrame(gameLoop);
2. 사각형 AABB 충돌 판정: if (p.x < s.x + s.w && p.x + p.w > s.x && p.y < s.y + s.h && p.y + p.h > s.y)
3. 캔버스 벽 가두기 공식: player.x = Math.max(0, Math.min(canvas.width - player.w, player.x));
