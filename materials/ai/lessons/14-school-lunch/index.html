Stage 1: 미션 브리핑 (점심시간 10분 전! 🔔)

배에서 꼬르륵 소리가 날 때, 친구들이 가장 먼저 켜보는 특급 웹앱
"오늘 급식 메뉴는 과연 돈가스일까, 카레라이스일까?"

매일 아침 복도 게시판까지 걸어갈 필요 없이, 내가 직접 만든 웹앱에 접속해 우리 학교 이름과 오늘 날짜만 고르면 김이 모락모락 나는 급식 식판이 화면에 짠 나타나는 알리미를 구현합니다.

이번 퀘스트의 4대 성공 루브릭 (성공 판정 기준)

1. 공공 데이터(NEIS) 연동

교육청 나이스 급식 API의 공식 엔드포인트에 성공적으로 접속하여 원격 JSON 패킷을 수신합니다.

2. 물음표 쪽지(Query) 전달

교육청 코드, 학교 표준 코드, 날짜 파라미터를 물음표(?) 뒤에 조합하여 원하는 학교의 식단만 정확히 배달받습니다.

3. 중첩 도시락통(JSON) 파싱

복잡하게 겹쳐진 배열과 객체 계층(mealServiceDietInfo[1].row[0])을 뚫고 진짜 식단 텍스트를 꺼냅니다.

4. 껍질 정제 & 예외 방어

알레르기 유발 번호와 HTML 태그 찌꺼기를 정규표현식으로 정제하고, 주말/방학 시 친절한 안내 화면을 띄웁니다.

Stage 2: 핵심 원리 (물음표 쪽지와 중첩 도시락통)

배달부에게 자세한 주문서 쪽지를 건네고, 포장을 벗겨내는 기술

1. 물음표 뒤의 보물 지도: 쿼리 파라미터 (Query Parameter)

비밀 배달부에게 그냥 "교육청 다녀와!"라고만 하면 전국 어느 학교의 몇 월 며칠 급식을 가져와야 할지 알 수 없어요. 그래서 주소 뒤에 물음표(?)를 붙이고 주문 쪽지를 꽂아 보냅니다!

// 배달부 주소와 물음표(?) 쪽지
https://open.neis.go.kr/hub/mealServiceDietInfo?
  Type=json&
  ATPT_OFCDC_SC_CODE=B10& // 서울특별시교육청
  SD_SCHUL_CODE=7010578& // 우리 학교 고유 번호
  MLSV_YMD=20261101 // 2026년 11월 1일 급식
? (물음표) "여기서부터 주문 쪽지 시작입니다!"
& (앰퍼샌드) "다음 주문 항목으로 넘어가세요!"

2. 러시아 마트료시카 같은 중첩 도시락통 (Nested JSON)

나이스 교육청 서버에서 배달된 택배 상자를 열어보면, 상자 속에 작은 상자가 있고 그 속에 편지 봉투가 들어있는 것처럼 여러 겹으로 포장되어 있습니다. 이 포장을 차례대로 벗겨야 진짜 요리 이름이 나와요!

1단계 data.mealServiceDietInfo ➔ 거대한 나이스 급식 보물상자
2단계 [1].row ➔ 0번째 헤더 상자를 지나 진짜 식단 목록 서랍
3단계 [0].DDISH_NM ➔ 드디어 나타난 오늘의 따끈따끈한 메뉴 문자열!

3. 요리용 체로 껍질 거르기: 정규표현식 데이터 정제 (Regex)

원문 메뉴를 열어보면 돈육불고기(10)<br/>배추김치(9)처럼 괄호 속 알레르기 번호와 줄바꿈 HTML 태그가 덕지덕지 붙어 있습니다. 요리용 체(정규식)로 찌꺼기를 걸러내야 식판에 깨끗하게 담을 수 있어요.

// 알레르기 번호 괄호 (1.2.5.6) 깔끔히 지우기
const cleanMenu = rawMenu.replace(/\([0-9.]+\)/g, '');
// 줄바꿈 태그 <br/> 기준으로 반찬별 쪼개기
const menuList = cleanMenu.split('<br/>');

Stage 4: 오류 연구소 (주말·방학 예외 방어 & 배움 회고)

데이터가 없어도 웹앱이 멈추지 않도록 지켜주는 방패 만들기
방패 1: 토요일·일요일 주말 방어

주말에 나이스 API를 부르면 INFO-200: 데이터가 없습니다 응답이 옵니다. 이때 에러가 터지지 않도록 "오늘은 달콤한 주말이에요! 집밥을 맛있게 드세요 🏖️" 화면을 띄워줍니다.

방패 2: 학교 코드 오타 방어

학교 코드를 잘못 입력하면 서버가 400 에러를 보냅니다. try ... catch 블록으로 오류를 낚아채서 "학교 번호를 다시 확인해주세요" 토스트 창을 띄워줍니다.

🔍 주니어 개발자를 위한 전문 용어 돋보기

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 데이터 엔지니어들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 공공 데이터 영문: Public Open Data
공공/오픈데이터
🧸 어린이 비유: "국민의 세금으로 만든 정부의 거대한 보물 창고! 누구나 신청하면 급식 메뉴, 날씨, 버스 위치를 무료로 열어볼 수 있는 데이터 상자!"

🎓 개발자 공식 정의: 정부와 공공기관이 생성하거나 취득하여 관리하는 디지털 형태의 데이터로, 국민 누구에게나 개방되어 영리적·비영리적 활용이 보장된 공공 정보 자산입니다.

2. 쿼리 파라미터 영문: Query Parameter (URL Search Params)
URL/요청 규격
🧸 어린이 비유: "배달부의 주머니에 넣어주는 물음표(?) 쪽지! '내일 날짜 급식으로, 2학년 3반 메뉴만 골라주세요!' 하고 주문 옵션을 덧붙이는 마법 쪽지!"

🎓 개발자 공식 정의: 웹 주소(URL) 끝에 물음표(?)를 시작으로 '키=값' 쌍 형태로 덧붙여, 서버에 특정 조건(필터링, 페이징, 검색어 등)을 전달하는 HTTP 요청 매개변수입니다.

3. 데이터 정제 영문: Data Cleansing & Sanitization
데이터 가공
🧸 어린이 비유: "밭에서 갓 뽑은 당근에 묻은 흙을 털고 껍질을 깎아 먹기 좋게 씻어내는 주방장 이모의 깔끔 손질법!"

🎓 개발자 공식 정의: 수신한 원천 데이터(Raw Data)에 포함된 불필요한 태그, 특수문자, 결측치(Null), 오탈자를 제거하고 사용자가 읽기 좋은 표준 형식으로 가공하는 데이터 정제 작업입니다.

4. 정규표현식 외래어·영문: 정규표현식 (Regular Expression / Regex)
문자열/패턴매칭
🧸 어린이 비유: "글자 세상의 마법 만능 돋보기! 아무리 복잡한 글 속에서도 괄호 속 글자나 알레르기 번호만 콕콕 집어 쏙 뽑아내거나 지워주는 스캐너!"

🎓 개발자 공식 정의: 문자열 안에서 특정한 규칙이나 패턴(숫자, 기호, 이메일, 괄호 등)을 정의하여, 해당 패턴과 일치하는 텍스트를 검색, 치환, 추출할 수 있도록 지원하는 정형 언어 표현식입니다.

5. 중첩 데이터 구조 영문: Nested Object & Array (Tree Data)
자료구조
🧸 어린이 비유: "큰 상자 속에 서랍이 있고, 그 서랍 속에 작은 봉투가 들어있는 러시아 마트료시카 인형 같은 데이터 정리함!"

🎓 개발자 공식 정의: 객체(Object) 안에 또 다른 객체나 배열(Array)이 계층적으로 포함된 복합 트리 구조로, 복잡한 현실 세계의 연관 관계 정보를 단일 JSON 파일에 체계적으로 담아냅니다.

6. 예외 처리 영문: Exception Handling & Fallback UI
안전성/방어코드
🧸 어린이 비유: "주말에 식당 문이 닫혀 있어도 당황하지 않고 '오늘은 쉬는 날이에요' 안내판을 얌전히 세워두는 안전 센서!"

🎓 개발자 공식 정의: 데이터 부재, 네트워크 단절, 오타 등 예상치 못한 오류(Exception)가 발생했을 때 프로그램이 멈추거나 튕기지 않고 안전한 대체 화면(Fallback)을 제공하는 방어적 프로그래밍 기법입니다.
