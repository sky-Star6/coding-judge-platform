QUEST 01 한국어 텍스트 정제 & 불용어 필터
전처리 엔지니어링 ★★★

사용자의 자연어 문장에서 특수기호, 이모지, 불필요한 조사(은/는/이/가)를 제거하는 JS 정제 함수 작성

사용자가 아무리 오타나 기호를 섞어 보내도 꿋꿋하게 순수 키워드만 쏙쏙 발라내는 자연어 전처리 정규식 엔진을 소환합니다.

실전 AI 복사 프롬프트
[역할] 너는 자연어 처리(NLP) 텍스트 전처리(Preprocessing) 전문 소프트웨어 엔지니어이자 코딩 멘토야. [목표] 웹 브라우저에서 사용자가 입력한 자연어 문장에서 불필요한 기호와 조사를 걸러내고 순수 의미 키워드만 배열(Array)로 추출하는 cleanAndTokenize(sentence) 함수를 자바스크립트로 작성해 줘. [세부 요구사항] 1. 정규표현식(RegEx)을 사용해 특수문자, 이모지, 연속된 공백을 깔끔하게 제거해 줘. 2. 한국어 조사(은, 는, 이, 가, 을, 를, 에, 에서, 으로)를 끝에서 분리하는 간단한 불용어(Stopwords) 필터 로직을 포함해 줘. 3. 빈 문자열이나 1글자짜리 무의미한 자음/모음은 결과 배열에서 제외해 줘. 4. "오늘 급식 메뉴가 뭐야?!"를 넣었을 때 ['오늘', '급식', '메뉴']가 반환되는 실행 예시를 보여줘. 5. 초보자도 쉽게 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 최신 거대 언어 모델(LLM)이라도 전체 학습 및 추론 시간의 70% 이상이 쓰레기 데이터(Garbage Data)를 걸러내고 토큰화하는 데이터 전처리(Data Cleaning)에 투입됩니다. "Garbage In, Garbage Out(쓰레기가 들어가면 쓰레기가 나온다)"는 컴퓨터 공학의 불변 법칙입니다.

QUEST 02 가중치 기반 인텐트 분류기
로컬 추론 알고리즘 ★★★

키워드 사전의 가중치 점수를 합산하여 가장 확률이 높은 의도(Intent)를 판별하는 Scoring 함수 구현

단순히 한 단어만 보고 답하지 않고, 문장 속 여러 키워드의 중요도를 수학적으로 계산하여 1등 의도를 골라내는 지능형 점수 판정 알고리즘을 작성합니다.

실전 AI 복사 프롬프트
[역할] 너는 가벼운 규칙 기반 인공지능(Rule-Based AI)과 분류 알고리즘을 설계하는 머신러닝 엔지니어야. [목표] 추출된 키워드 배열과 의도별 키워드 사전(Intent Dictionary)을 비교하여, 각 의도별 매칭 점수를 계산하고 가장 점수가 높은 Best Intent를 반환하는 classifyIntent(tokens, intentRules) 함수를 작성해 줘. [세부 요구사항] 1. intentRules 객체는 { meal: { keywords: { '급식': 50, '점심': 30, '메뉴': 20 } }, weather: { ... } } 구조로 가중치를 차등 부여해 줘. 2. 토큰 목록을 순회하며 매칭되는 키워드의 점수를 누적 합산(Score Accumulation)해 줘. 3. 1등 의도의 이름, 총점, 신뢰도(Confidence 백분율)를 객체로 반환해 줘. 4. 모든 점수가 0점일 때는 'unknown' 인텐트를 반환하도록 예외 처리를 해 줘. 5. 모든 코드에 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 구글 검색 엔진의 초기 알고리즘과 질의 분류 시스템 역시 단어의 출현 빈도와 희소성을 가중치로 계산하는 TF-IDF 및 벡터 스페이스 모델(Vector Space Model)에서 출발했습니다.

QUEST 03 신뢰도 임계값 & 동적 폴백 핸들러
안전성 아키텍처 ★★★

신뢰도가 기준치 미만일 때 엉뚱한 답변을 차단하고 추천 질문 칩으로 되돌리는 Dynamic Fallback 설계

확신 점수가 낮을 때 아는 척하며 거짓말을 지어내지 않고, 사용자의 문장 길이에 따라 센스 있게 되묻는 스마트 안전망을 구축합니다.

실전 AI 복사 프롬프트
[역할] 너는 대화형 시스템의 안전성(Safety)과 사용자 경험(UX)을 전담하는 대화 설계자(Conversation Designer)야. [목표] 챗봇 엔진의 추론 신뢰도(Confidence Score)가 기준 임계값(예: 40점)보다 낮을 때, 기계적인 에러 대신 사용자가 다시 올바른 질문을 하도록 유도하는 handleFallback(score, rawText) 함수를 작성해 줘. [세부 요구사항] 1. 사용자가 입력한 문장 길이에 따라 다른 3단계 폴백 메시지(너무 짧음, 오타 추정, 범위 외 질문)를 작성해 줘. 2. 챗봇이 알고 있는 대표 질문 3가지(오늘 급식, 아침 날씨, 단어 퀴즈)를 추천 버튼 칩 형태로 함께 반환해 줘. 3. 왜 챗봇이 모르는 것을 아는 척하는 환각(Hallucination)보다 솔직한 폴백이 훨씬 더 우수한 UX인지 설명해 줘. 4. 모든 코드에 초보자를 위한 상세한 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 자율주행 자동차나 의료 인공지능에서도 시스템의 확신도(Confidence)가 기준치 이하로 떨어지면 즉시 인간 운전자에게 제어권을 넘기거나 안전 정지(Fail-Safe)를 실행하도록 안전 규정이 강제되어 있습니다.

QUEST 04 오타 및 유사어 거리 알고리즘
문자열 알고리즘 ★★★

"급식" 대신 "급식ㅇ"이나 "급식은"으로 잘못 쳤을 때도 찰떡같이 알아듣는 레벤슈타인 편집 거리 알고리즘

글자가 완벽히 똑같지 않아도 삽입, 삭제, 교체 횟수를 계산해 유사도를 매기는 컴퓨터 과학의 고전 명작 알고리즘을 장착합니다.

실전 AI 복사 프롬프트
[역할] 너는 텍스트 검색 엔진과 철자 교정(Spell Checker)을 개발하는 컴퓨터 과학 연구원이야. [목표] 사용자가 한두 글자 오타를 내더라도 사전의 정답 키워드와 얼마나 닮았는지 0~1 사이의 유사도로 측정하는 calculateSimilarity(word1, word2) 함수를 자바스크립트로 구현해 줘. [세부 요구사항] 1. 두 문자열 간의 삽입, 삭제, 교체 최소 횟수를 구하는 레벤슈타인 거리(Levenshtein Distance) 알고리즘을 적용해 줘. 2. 계산된 거리를 바탕으로 0(전혀 다름)부터 1(100% 일치) 사이의 정규화된 유사도 점수를 반환해 줘. 3. "급식"과 "급식ㅇ", "메뉴"와 "메유"를 넣었을 때 유사도가 0.6 이상 나와 오타를 자동 보정하는 예시를 보여줘. 4. 알고리즘의 원리를 초등학생도 이해할 수 있는 동적 계획법(DP) 표 비유로 쉽게 설명해 줘. 5. 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 스마트폰 키보드의 오타 자동 완성, 구글 검색창의 "이것을 찾으셨나요?", 그리고 생물학에서 DNA 돌연변이 염기서열 비교 분석 모두 이 레벤슈타인 거리(동적 계획법) 알고리즘을 동일하게 사용합니다.

QUEST 05 로컬스토리지 지식 베이스 확장 모듈
지능형 데이터 관리 ★★★

사용자가 대화 중에 새로운 단어와 질문-답변 규칙을 가르치면 영구 저장되는 Knowledge Base 확장 매니저

개발자가 코드를 고치지 않아도 사용자와 대화하며 스스로 지식을 넓혀가는 지속 학습(Continual Learning) 데이터 매니저를 구현합니다.

실전 AI 복사 프롬프트
[역할] 너는 브라우저 클라이언트 사이드 데이터 영속성(Persistence)과 온디바이스 지식 관리 시스템 전문가야. [목표] 사용자가 "A라고 물어보면 B라고 대답해"라고 새로운 규칙을 가르치면, 이를 기존 키워드 사전에 추가하고 브라우저 localStorage에 영구 보관하는 ChatbotKnowledgeManager 클래스를 작성해 줘. [세부 요구사항] 1. learnNewRule(keyword, intentName, answer, weight) 메서드를 작성해 줘. 2. saveToStorage(), loadFromStorage(), resetToDefault() 메서드로 브라우저 재방문 시에도 학습 데이터가 유지되게 해 줘. 3. 악의적이거나 비정상적인 데이터가 저장되지 않도록 XSS 방어 및 빈 값 검증을 철저히 해 줘. 4. 브라우저 로컬 저장 공간(5MB)만으로도 수천 개의 챗봇 문답 규칙을 충분히 저장할 수 있는 데이터 압축 팁을 설명해 줘. 5. 매 줄마다 상세한 한국어 주석을 달아줘.

💡 컴퓨터 과학 비밀: 인공지능이 새로운 지식을 배울 때 과거 지식을 까먹는 현상을 '파괴적 망각(Catastrophic Forgetting)'이라고 부릅니다. 규칙 기반 지식 베이스는 과거의 소중한 규칙을 100% 안전하게 보존하면서 새 규칙을 끝없이 덧붙일 수 있는 강력한 장점이 있습니다.

🔍 주니어 개발자를 위한 전문 용어 돋보기

본문에서 다룬 재미있는 비유들의 실제 소프트웨어 공학 공식 명칭과 정의를 확인해보세요.

1. 자연어 전처리 Text Preprocessing & Normalization
🧸 어린이 비유: "요리하기 전에 흙 묻은 감자를 깨끗이 씻고 껍질을 깎아 요리하기 좋게 다듬는 일!"

🎓 개발자 공식 정의: 사람의 일상 언어(자연어)를 컴퓨터 알고리즘이 분석하기 쉽도록 특수문자 제거, 대소문자 통일, 불용어 필터링 등을 거쳐 정형화된 데이터로 정제하는 단계입니다.

2. 토큰화 Tokenization
🧸 어린이 비유: "긴 기차를 칸칸이 분리해서 어떤 화물이 실렸는지 하나씩 살펴보는 일!"

🎓 개발자 공식 정의: 연속된 텍스트 문자열을 의미를 가진 최소 단위인 토큰(Token, 단어·형태소·서브워드)으로 분할하여 배열 형태로 구조화하는 자연어 처리의 필수 기초 단계입니다.

3. 의도 분류 Intent Classification
🧸 어린이 비유: "우체부 아저씨가 편지 봉투 주소를 보고 '이건 서울행, 저건 부산행'으로 분류 상자에 착착 나누는 일!"

🎓 개발자 공식 정의: 사용자가 입력한 자연어 문장이 전달하고자 하는 궁극적인 목적이나 요구(급식 조회, 날씨 문의, 잡담 등)를 사전에 정의된 의도 범주(Intent) 중 하나로 매핑하는 분류 기술입니다.

4. 신뢰도 점수 & 임계값 Confidence Score & Threshold
🧸 어린이 비유: "범인을 지목할 때 '이 사람이 90% 확실해요!'라는 확신의 점수와, 50점 미만이면 함부로 말하지 않는 안전선!"

🎓 개발자 공식 정의: 알고리즘이 도출한 예측 결과에 대한 수학적 확신도를 나타내는 지표이며, 임계값(Threshold) 미만일 경우 오류 확산을 막기 위해 안전 대응(Fallback)을 발동시키는 기준선입니다.

5. 규칙 기반 추론 엔진 Rule-Based Inference Engine
🧸 어린이 비유: "신호등의 빨간 불, 노란 불, 초록 불에 따라 차가 어떻게 움직여야 하는지 한 치의 오차도 없이 적어둔 규칙 책!"

🎓 개발자 공식 정의: 사전에 설계된 지식 베이스(IF-THEN 조건, 키워드 가중치, 패턴 매칭)를 바탕으로 입력 데이터를 연역적으로 추론하여 한 치의 오차 없이 투명하고 설명 가능한 응답을 생성하는 시스템입니다.
