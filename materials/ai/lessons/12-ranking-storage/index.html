1단계: 사라진 점수의 비밀 — 새로고침했더니 내 1,200점이 날아갔어요!

열심히 9강, 10강, 11강을 거쳐 완성한 별똥별 피하기 아케이드 게임을 신나게 플레이해서 드디어 1,200점이라는 역대급 최고 점수를 기록했어요! "선생님, 친구들한테 자랑해야지!" 하고 기뻐하며 브라우저 새로고침(F5)을 누르거나 창을 닫았다가 다시 열었더니...

앗! 내 점수가 0점으로 리셋되었어요! 😭

방금 달성한 1,200점이 감쪽같이 증발하고 화면에는 다시 0점만 덩그러니 남아있습니다. 컴퓨터를 껐다 켜거나 브라우저를 닫아도 내 점수를 영원히 기억하게 만들 수는 없을까요?

왜 자바스크립트 변수는 기억을 잃어버릴까요? VOLATILE MEMORY

우리가 코드에서 만든 일반 변수(let score = 0;)는 컴퓨터 뇌(RAM) 속에 잠깐 적어두는 '휘발성 메모리'예요. 칠판에 분필로 쓴 글씨처럼, 브라우저 새로고침이나 창 닫기라는 지우개가 쓱 지나가면 기억이 싹 날아가 버립니다!

💡 우리의 목표: 브라우저 하드디스크에 영구적으로 기록하는 로컬 세이브 상자(localStorage)를 장착하여, 언제 게임을 다시 켜도 내 최고 점수와 랭킹이 살아있게 만듭니다!

2단계: 비밀 세이브 상자 — 컴퓨터를 꺼도 지워지지 않는 localStorage

브라우저 안에는 사용자 몰래 영구적으로 데이터를 보관해 주는 비밀 창고가 있어요. 이를 로컬 스토리지 (localStorage)라고 부릅니다. 오락실 게임기 뒷면에 붙은 세이브 칩처럼 동작해요!

1 보물 넣기 (setItem) 
localStorage.setItem(
  'bestScore',
  1200
);

'bestScore'라는 이름표(Key)가 붙은 상자에 1200(Value)을 쏙 집어넣어요.

2 보물 꺼내기 (getItem) 
let saved = 
  localStorage.getItem(
    'bestScore'
  );

이름표를 찾아 상자를 열고 안에 든 1200을 꺼내와요. 없으면 null이 나와요.

3 상자 비우기 (removeItem) 
localStorage.removeItem(
  'bestScore'
);

더 이상 필요 없는 상자는 깨끗이 비워서 초기화할 수 있어요.

3단계: 데이터 택배 포장술 — 복잡한 목록을 한 줄로 만드는 JSON의 마법

숫자 하나(1200)는 그냥 넣어도 되지만, 우리 반 친구들의 이름과 점수가 담긴 목록([{name:'민우', score:1200}, ...])은 그대로 넣으면 [object Object]라는 외계어로 깨져버려요!

🚨 로컬 스토리지의 철칙: "오직 한 줄의 글자(문자열)만 통과할 수 있다!" 복잡한 객체나 배열을 사물함에 넣으려면 반드시 한 줄의 글자 택배로 포장해야 합니다. 이때 사용하는 것이 바로 JSON입니다!
1. 택배 포장하기 (stringify) OBJECT → STRING

자바스크립트 배열을 테이프로 꽁꽁 감아 한 줄의 텍스트로 압축 포장해요. 

let parcel = JSON.stringify(rankList);
localStorage.setItem('ranks', parcel);
2. 택배 상자 뜯기 (parse) STRING → OBJECT

사물함에서 꺼낸 글자 택배를 뜯어서 원래의 살아있는 자바스크립트 배열로 복원해요! 

let parcel = localStorage.getItem('ranks');
let rankList = JSON.parse(parcel);

JSON 포장을 배웠다면 우측 [명예의 전당]에서 최고 기록을 등록하세요!

객체와 배열을 문자열로 포장하는 JSON 택배술을 익히셨나요? 우측 콘솔의 [명예의 전당] 탭에서 내 닉네임과 최고 점수를 입력하여 로컬 스토리지에 영구 저장하고 실시간 TOP 5 랭킹에 등극해 보세요!

4단계: 명예의 전당 랭킹전 — 우리 반 오락실 스코어보드 완성

오락실 게임기처럼 플레이가 끝났을 때 최고 기록 TOP 5를 실시간으로 줄 세우는 4단계 수학 공식입니다.

1
기존 랭킹 불러오기 let list = JSON.parse(localStorage.getItem('rankings')) || [];
2
새 플레이어 기록 추가 list.push({ name: '민우', score: 1200 });
3
내림차순 정렬 (높은 점수 1등) list.sort((a, b) => b.score - a.score); (b에서 a를 빼면 큰 수가 위로!)
4
TOP 5만 남기고 포장 저장 localStorage.setItem('rankings', JSON.stringify(list.slice(0, 5)));
❌ 위험한 프롬프트 휘발성 
게임 끝나면 랭킹 보여줘.

AI가 localStorage 없이 일반 변수로만 만들어 새로고침하면 랭킹이 전부 사라져요!

2. 키-값 저장소 영문: Key-Value Store
자료구조
🧸 어린이 비유: "사물함마다 이름표(키)를 붙여두고, 이름표를 불러서 안에 든 보물(값)을 꺼내는 정리법!"

🎓 개발자 공식 정의: 고유한 식별자 키(Key)와 실제 데이터 값(Value)의 쌍으로 정보를 관리하고 초고속으로 검색하는 데이터베이스 패러다임입니다.

3. 제이슨 직렬화 외래어·영문: JSON 직렬화 (JSON Serialization / stringify)
데이터 변환
🧸 어린이 비유: "여러 물건이 담긴 장난감 상자를 테이프로 꽁꽁 감아 한 줄의 택배 상자로 압축 포장하기!"

🎓 개발자 공식 정의: 자바스크립트 객체나 배열 같은 메모리 내 복합 데이터 구조를 다른 시스템이나 파일에 저장·전송할 수 있도록 텍스트 문자열(JSON)로 변환하는 작업입니다.

4. 제이슨 역직렬화 외래어·영문: JSON 파싱 (JSON Deserialization / parse)
데이터 변환
🧸 어린이 비유: "배달받은 택배 상자를 칼로 뜯어서 원래의 살아있는 장난감들로 다시 꺼내놓기!"

🎓 개발자 공식 정의: JSON 형식의 텍스트 문자열을 파싱(해석)하여 프로그램이 즉시 조작할 수 있는 자바스크립트 객체나 배열로 다시 복원하는 과정입니다.

5. 배열 정렬 알고리즘 영문: Array Sorting (sort / 내림차순)
알고리즘
🧸 어린이 비유: "키 큰 순서대로 줄을 서듯, 점수가 가장 높은 친구부터 1등으로 차례차례 줄 세우기!"

🎓 개발자 공식 정의: 비교 함수(Comparator)를 기반으로 배열 속 요소들을 특정 기준(점수 내림차순, 알파벳순 등)에 맞추어 재배열하는 알고리즘 연산입니다.

6. 데이터 영속성 영문: Data Persistence (영구 저장)
시스템/스토리지
🧸 어린이 비유: "게임 전원을 끄고 내일 다시 켜도 내 캐릭터 레벨과 보물이 그대로 남아있는 것!"

🎓 개발자 공식 정의: 프로그램을 종료하거나 컴퓨터 프로세스가 중단되어도 저장 매체에 기록되어 데이터가 유실되지 않고 영구히 보존되는 특성입니다.
