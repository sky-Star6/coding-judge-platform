localStorage.getItem & setItem 기초
[Goal]: 별똥별 피하기 웹 게임에서 브라우저를 새로고침하거나 창을 닫았다 다시 열어도 플레이어의 역대 최고 점수가 지워지지 않도록 localStorage를 활용한 최고 점수 저장 및 표시 코드를 작성해 줘. [Condition]: 1. 게임 시작 시 `localStorage.getItem('game_high_score')`를 읽어와 화면의 `#high-score-display` 요소에 표시해 줘 (기존 기록이 없으면 0점). 2. 게임오버 시 현재 달성한 점수가 기존 최고 점수보다 높을 경우에만 `localStorage.setItem`으로 갱신하고, "신기록 달성! 🎉" 축하 애니메이션을 띄우는 함수를 구현해 줘. 3. 각 줄마다 초보 학생을 위한 친절한 한국어 주석을 달아줘.
최신 AI의 소환 마법

localStorage를 읽고 쓸 때 문자열과 숫자 변환(parseInt / Number)의 맹점을 놓치지 않고 완벽한 신기록 갱신 로직을 제공합니다.

컴퓨터 과학 비밀

일반 변수(let, const)는 새로고침하면 RAM 메모리에서 날아가지만, localStorage는 사용자의 하드디스크 브라우저 영역에 반영구적으로 보존됩니다.

📦 QUEST 02. 객체 배열을 한 줄 텍스트로 압축하는 JSON 택배 포장술

JSON.stringify 직렬화(Serialization)
[Goal]: 플레이어 이름과 점수, 달성 일자가 담긴 자바스크립트 객체 배열(Ranking List)을 localStorage에 안전하게 저장하기 위한 JSON 직렬화(Serialization) 코드를 작성해 줘. [Sample Data]: const rankingList = [ { name: "은하수", score: 2400, date: "2026-11-09" }, { name: "혜성", score: 1850, date: "2026-11-08" } ]; [Condition]: 1. `localStorage.setItem('ranks', rankingList)`처럼 배열을 그냥 넣었을 때 왜 `"[object Object]"`라는 대참사 외계어가 저장되는지 이유를 설명해 줘. 2. `JSON.stringify`를 사용해 객체 배열을 온전한 JSON 문자열로 포장하여 저장하는 안전한 함수 `saveRankings(list)`를 작성해 줘.
최신 AI의 소환 마법

초보자들이 가장 많이 겪는 [object Object] 저장 참사의 원인을 명쾌히 짚고, JSON 직렬화의 필수성을 알려줍니다.

컴퓨터 과학 비밀

localStorage는 오직 문자열(String)만 담을 수 있는 보관함이므로, 복잡한 객체나 배열은 반드시 JSON 형식의 텍스트로 직렬화해야 합니다.

🛡️ QUEST 03. 깨진 데이터도 튕기지 않는 방어적 JSON 택배 언박싱(try-catch)

JSON.parse 역직렬화 & try-catch 예외 방어
[Goal]: localStorage에 저장된 랭킹 데이터를 읽어올 때, 데이터가 없거나 깨져 있어도 웹 게임이 절대 다운되지 않는 무적의 안전 복원 함수 `loadRankings()`를 작성해 줘. [Condition]: 1. `localStorage.getItem('ranks')`가 null일 경우 빈 배열 `[]`을 반환하는 기본값 가드 처리를 포함해 줘. 2. 만약 저장소의 JSON 문자열이 오염되어 `JSON.parse()` 도중 SyntaxError가 발생하더라도 게임이 멈추지 않고 안전하게 기본 배열을 반환하도록 `try-catch` 블록으로 방어해 줘. 3. 함수가 반환하는 값은 항상 신뢰할 수 있는 자바스크립트 배열 객체여야 해.
최신 AI의 소환 마법

단순 parse가 아닌 try-catch 예외 방어와 null 병합 가드가 결합된 프로급 안전 로딩 패턴을 완성해 줍니다.

컴퓨터 과학 비밀

인터넷 환경이나 사용자의 로컬 조작으로 인해 스토리지 데이터가 훼손될 수 있으므로, JSON 파싱 시 try-catch 방어막은 전 세계 시니어 개발자들의 필수 수칙입니다.

[Input Example]: 새 도전자: { name: "태양", score: 2100 } [Condition]: 1. `Array.push()`로 새 기록을 넣은 뒤, `sort((a, b) => b.score - a.score)`를 사용해 점수 높은 순(내림차순)으로 자동 정렬하는 원리를 설명해 줘. 2. `slice(0, 5)`를 사용해 6등 이하의 기록은 자동으로 탈락시키고 딱 5개만 유지하는 코드를 작성해 줘. 3. 최종 정렬된 TOP 5 리스트를 다시 `localStorage`에 자동 저장하는 완전한 흐름을 보여줘.
최신 AI의 소환 마법

점수 내림차순 정렬(b.score - a.score)과 slice(0, 5)를 결합하여 군더더기 없는 명예의 전당 알고리즘을 소환합니다.

자바스크립트 기본 sort()는 숫자를 문자열로 비교하여 100이 20보다 작다고 판정하는 함정이 있으므로, 반드시 숫자 비교 함수 (a, b) => b - a를 넘겨야 합니다.
