핵심 개념: 컴퓨터가 생각하고 기억하는 원리

프로그램이 지능을 갖추기 위해 필요한 두 기둥은 바로 ‘상황 판단(조건문)’과 ‘자료 보관(배열)’입니다.

1. 갈림길의 표지판: If-Else

"만약 체력이 0 이하면 게임 오버! 그렇지 않으면 모험을 계속해!"처럼 상황에 따라 전혀 다른 코드를 실행하는 조건 분기문입니다.

if (score >= 100) {
  alert("승리!");
} else {
  alert("도전 중...");
}

2. 순서가 있는 보물함: 배열 (Array)

변수 하나에 여러 아이템을 순서대로 넣는 서랍장입니다. 컴퓨터는 0번 칸부터 번호를 매긴다는 사실(0-based indexing)을 꼭 기억하세요!

const weapons = ["목검", "은장도", "엑스칼리버"];
console.log(weapons[0]); // "목검" 출력!

3. 컴퓨터의 주사위: Math.random()

0.000... 이상 0.999... 미만의 무작위 실수를 생성합니다. Math.random() < 0.05는 정확히 5% 확률을 의미합니다!

const roll = Math.random();
if (roll < 0.05) grade = "전설";
else if (roll < 0.30) grade = "희귀";

핵심 요약: 게임 로직 설계 4대 원칙

① 조건 판단 (If-Else) 위에서 아래로 조건을 검사하며, 처음으로 참(true)이 되는 블록 하나만 실행하고 탈출합니다.
② 엄격 비교 (===) 값과 자료형이 모두 일치하는지 비교합니다. (예: 1 === "1"은 거짓이지만 1 === 1은 참)
③ 배열 추가 (push) 가챠에서 뽑은 새 아이템을 inventory.push(newItem)으로 서랍 맨 뒤에 쏙 집어넣습니다.
④ 인덱스 안전장치 배열의 길이는 array.length이며, 마지막 원소의 번호는 항상 length - 1입니다.

시뮬레이터에서 체험한 원리를 직접 코드로 구현해보는 4단계 실습입니다.

1단계: 아이템 풀(배열)과 인벤토리 준비하기

등급별로 획득 가능한 아이템 목록을 배열로 선언하고, 뽑은 결과를 담을 빈 인벤토리(let inventory = [])를 만듭니다. 

// 등급별 아이템 후보 배열 (Array)
const legendaryItems = ["성검 엑스칼리버", "불사조의 깃털 갑옷", "용의 마법봉"];
const rareItems = ["미스릴 단검", "신비한 마법 수정구", "요정의 날개 신발"];
const commonItems = ["녹슨 철검", "낡은 가죽 조끼", "체력 회복 물약"];

// 플레이어가 소지한 아이템 인벤토리

2단계: Math.random()과 If-Else 확률 분기 구현

Math.random()으로 주사위를 굴리고, 조건문을 통해 5%는 전설, 25%는 희귀, 70%는 일반으로 분기합니다. 

function drawGachaItem() {
  const roll = Math.random(); // 0.0 ~ 0.999...
  let pickedItem = "";

  if (roll < 0.05) {
    // 5% 확률: 전설 아이템 배열 중 무작위 1개 선택
    const idx = Math.floor(Math.random() * legendaryItems.length);
    pickedItem = "🌟 [전설] " + legendaryItems[idx];
  } else if (roll < 0.30) {
    // 25% 확률 (0.05 ~ 0.30): 희귀 아이템
    const idx = Math.floor(Math.random() * rareItems.length);
    pickedItem = "🔮 [희귀] " + rareItems[idx];
  } else {
    // 70% 확률 (0.30 ~ 1.00): 일반 아이템
    const idx = Math.floor(Math.random() * commonItems.length);
    pickedItem = "🗡️ [일반] " + commonItems[idx];
  }

  inventory.push(pickedItem); // 인벤토리에 누적 보관!
  return pickedItem;
}

3단계: 객체 배열로 3문항 퀴즈 데이터 설계

질문(question), 4개 선택지(options), 정답 번호(answer), 설명(explanation)을 하나의 객체로 묶어 배열에 저장합니다. 

const quizData = [
  {
    question: "자바스크립트에서 배열의 첫 번째 원소를 꺼내는 인덱스는?",
    options: ["1번", "0번", "-1번", "first"],
    answerIndex: 1, // 0번 인덱스가 2번째 보기
    explanation: "컴퓨터는 숫자를 0부터 셉니다! 첫 번째 칸은 0번 인덱스예요."
  },
  {
    question: "Math.random()이 생성하는 숫자의 범위는?",
    options: ["1 ~ 100", "0 이상 1 미만", "0 ~ 10", "-1 ~ 1"],
    answerIndex: 1,
    explanation: "0.000...부터 0.999...까지의 실수가 생성됩니다."
  }
];

4단계: 정답 채점과 중복 클릭 방지 처리

사용자가 선택한 인덱스와 answerIndex를 엄격 비교(===)하고, 이미 풀었는지 확인하는 플래그 변수를 둡니다. 

let currentQuizIndex = 0;
let totalScore = 0;
let isAnswered = false; // 중복 클릭 방지 플래그

function selectAnswer(userChoice) {
  if (isAnswered) return; // 이미 답을 눌렀다면 무시!
  isAnswered = true;

  const currentQ = quizData[currentQuizIndex];
  if (userChoice === currentQ.answerIndex) {
    totalScore += 100;
    console.log("정답입니다! 100점 추가");
  } else {
    console.log("아쉬워요, 오답입니다.");
  }
}
