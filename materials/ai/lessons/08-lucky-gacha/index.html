오늘의 3대 도전 미션 브리핑

8강을 완주하면 직접 만들 수 있는 3가지 핵심 기능입니다.

1

100면체 랜덤 주사위

Math.random() * 100으로 0부터 99.99까지 예측할 수 없는 숫자를 뽑아 확률의 기초를 설계합니다.

2

조건문(if/else) 갈림길

굴려 나온 주사위 값에 따라 일반(70%), 희귀(25%), 전설(5%) 등급으로 안내하는 신호등 판정문을 세웁니다.

3

보물 도시락 배열([ ])

보물 목록과 퀴즈 문제를 차곡차곡 담아두고, 컴퓨터의 0번 인덱스 규칙(items[0])으로 쏙쏙 꺼냅니다.

동작 원리 탐구: 3총사로 이해하는 게임 로직의 비밀

어렵게 느껴지는 프로그래밍 개념을 어린이 눈높이의 친숙한 일상 도구로 비유해 봅니다.

Math.random()

컴퓨터 손바닥 안에서 0.00부터 0.99까지 무한히 구르는 투명 주사위입니다. 100을 곱하면 100면체 주사위가 되어 확률 놀이의 마법사가 됩니다!

갈림길 판단 신호등

if / else if / else

"주사위가 95점 이상이면 황금 궁전으로, 70점 이상이면 은빛 성문으로, 나머지는 나무 다리로!" 상황에 맞추어 길을 인도하는 똑똑한 신호등입니다.

🍱

칸칸이 나뉜 찬합 도시락

Array [ 0, 1, 2 ]

0번 칸에는 샌드위치, 1번 칸에는 김밥, 2번 칸에는 과일을 담아두듯, 수십 개의 보물이나 퀴즈 문제를 하나의 이름표 아래 순서대로 묶어두는 마법 상자입니다.

주니어 개발자의 황금률: "컴퓨터는 1이 아니라 0부터 센다!"

사람은 첫 번째 아이템을 1번이라고 부르지만, 컴퓨터는 0번 인덱스(Zero-based Index)부터 카운트합니다. items[0]이 첫 번째 보물이고, items[1]이 두 번째 보물입니다! 또한 상자에 값을 넣는 대입(=)과 양쪽이 똑같은지 비교하는 검사(===)를 절대 헷갈리지 마세요!

// gacha.js - 현재 가챠 머신의 실제 동작 코드
const itemsDB = {
  legendary: ["👑 황금 엑스칼리버", "전설의 드래곤 날개", "영원의 불꽃 건틀릿"],
  rare: ["⚔️ 은빛 기사 방패", "룬 마법 지팡이", "바람의 부츠", "미스릴 투구"],
  common: ["🪵 단단한 나무 몽둥이", "녹슨 철단검", "낡은 가죽 장화", "신선한 사과"]
};

function pullGacha() {
  // 1. 0 ~ 99.99 사이의 100면체 주사위 굴리기
  const dice = Math.random() * 100;
  let grade = "common";

  // 2. 신호등 조건문(if/else)으로 등급 갈림길 판정
  if (dice >= 95) {
    grade = "legendary"; // 5% 확률
  } else if (dice >= 70) {
    grade = "rare";      // 25% 확률
  } else {
    grade = "common";    // 70% 확률
  }

  // 3. 찬합 도시락 배열(Array)에서 0번 인덱스 규칙으로 아이템 무작위 추첨
  const list = itemsDB[grade];
  const randomIndex = Math.floor(Math.random() * list.length);
  return { grade: grade, item: list[randomIndex], dice: dice.toFixed(2) };
}

1. 100면체 주사위와 3단계 가챠 확률(70/25/5) 로직 소환 퀘스트

약점: Math.random() * 100과 if / else if / else 계단식 조건문 분기 설계
[Goal]: 웹 브라우저에서 '보물 상자 열기' 버튼을 누르면 100면체 주사위를 굴려 70%, 25%, 5% 확률로 등급을 나누어 아이템을 추첨하는 자바스크립트 가챠 함수를 작성해줘. [Actor]: 초보자에게 게임 수학과 알고리즘을 친절히 설명하는 주니어 게임 개발 튜터 [Condition]: - 요구사항: 1) Math.random() * 100으로 0 ~ 99.99 난수를 생성할 것. 2) if (dice >= 95) 전설(5%), else if (dice >= 70) 희귀(25%), else 일반(70%) 조건문 구조를 갖출 것. 3) 각 등급별 아이템 목록은 객체 안의 배열(itemsDB = { legendary: [...], ... })로 보관할 것. 4) 배열의 길이(list.length)를 이용해 해당 등급 아이템 중 1개를 무작위 추첨할 것. - 초보자도 바로 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘. [Output Format]: - 바로 실행 가능한 완성형 자바스크립트 코드 블록 - 주사위와 조건문이 어떻게 확률을 나누는지 어린이 눈높이 해설 2줄
🤖 AI의 놀라운 코드 생성 마법:

복잡한 게임 기획서의 확률표를 단 15줄 이내의 간결하고 우아한 자바스크립트 조건문 분기 함수로 즉시 변환해 줍니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

계단식 조건문(Chained if-else)은 위에서부터 순서대로 조건을 검사하므로, 95 이상을 먼저 걸러내면 아래쪽 조건에서는 95 미만임이 자동으로 보장되기 때문입니다.

2. 0번 인덱스 실종 사건과 Off-by-One 버그 탐정 QA 퀘스트

약점: 배열의 첫 번째 원소(items[0])와 array.length 범위 초과(undefined) 결함
[Goal]: 내가 작성한 가챠 코드에서 첫 번째 아이템이 절대 안 나오거나, 가끔 'undefined'라는 유령 아이템이 뽑히는 치명적 인덱스 버그를 찾아 교정해줘. [Actor]: 배열 경계값 검사(Bounds Check) 전문 크롬 디버깅 QA 엔지니어 [Condition]: - 검사할 버그 코드: const weapons = ['황금검', '마법봉', '강철도끼']; // 버그 1: 첫 번째 아이템을 1번으로 착각함 const firstWeapon = weapons[1]; // 버그 2: 1부터 3까지 뽑으려다 범위를 벗어남 const randomWeapon = weapons[Math.floor(Math.random() * 3) + 1]; - 문제점: 1) firstWeapon을 출력했더니 '황금검'이 아니라 '마법봉'이 나옴! 2) randomWeapon을 반복해서 뽑다 보면 가끔 'undefined'가 뜸! - 원인을 어린이 눈높이로 진단하고 완벽한 교정 코드를 제시해줘. [Output Format]: 1. 왜 황금검이 안 나왔는지 '0번 인덱스 규칙' 해설 2. 왜 undefined가 떴는지 '배열 길이와 마지막 인덱스의 차이(Off-by-One)' 해설 3. 안전하게 랜덤 아이템을 꺼내는 올바른 1줄 코드
🤖 AI의 놀라운 코드 생성 마법:

전 세계 초보 프로그래머 99%가 겪는 '하나 차이 오차(Off-by-One)'와 0번 인덱스 함정을 명쾌하게 분석하여 버그 없는 안전한 인덱싱을 코칭합니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

길이가 N인 배열의 유효한 인덱스는 0부터 N-1까지이므로, Math.floor(Math.random() * N)은 정확히 0 이상 N-1 이하의 정수만을 만들어내기 때문입니다.

3. 천장 시스템(Pity System)! 10회 연속 꽝 시 확정 전설 지급 퀘스트

약점: 뽑기 실패 횟수를 기억하는 카운터 변수(pityCount)와 상태 전이 로직
[Goal]: 유저가 10번 연속으로 전설 아이템을 뽑지 못하면 10번째 뽑기에서는 주사위 값과 상관없이 무조건 전설을 선물하는 '천장(Pity) 보호 로직'을 만들어줘. [Actor]: 유저 이탈을 막고 쾌적한 게임 경제를 설계하는 모바일 가챠 게임 시스템 디렉터 [Condition]: - 요구사항: 1) 천장 카운터 변수 let pityCount = 0; 선언. 2) 뽑기를 할 때마다 pityCount를 1 증가시킬 것. 3) if (pityCount >= 10) 조건이 참이면: - 주사위를 굴리지 않고 바로 '전설 등급 확정!' 당첨 처리. - pityCount를 0으로 리셋. 4) 만약 10번이 되기 전에 일반 확률(5%)로 전설이 나왔다면 역시 pityCount를 0으로 리셋할 것. - 화면에 '천장까지 남은 횟수: X회'를 갱신할 수 있는 힌트를 포함해줘. [Output Format]: - 천장 로직이 완벽하게 결합된 pullGachaWithPity() 자바스크립트 함수 - 플레이어에게 신뢰를 주는 천장 시스템의 컴퓨터 상태(State) 관리 원리 해설
🤖 AI의 놀라운 코드 생성 마법:

불운한 유저를 구제하는 상용 게임의 필수 시스템인 '천장 알고리즘'을 변수와 조건문의 환상적인 조화로 즉시 코딩해 줍니다.

💡 왜 그럴까요? (컴퓨터 과학 비밀):

독립 시행(Independent Trial)인 확률에 누적 상태(State) 변수를 결합하여 특정 임계값(Threshold) 도달 시 조건 분기를 강제 전이시키는 기법입니다.

4. 배열과 객체로 엮어낸 3문항 웹 퀴즈 엔진 자동 출제 퀘스트

약점: 문제, 보기, 정답 인덱스, 해설을 객체 배열(quizData)로 구조화하고 렌더링
[Goal]: 자바스크립트 초보자를 위한 '3문항 객관식 퀴즈 게임 엔진'을 배열과 객체 자료구조를 활용해 깔끔하게 구현해줘. [Actor]: 인터랙티브 웹 교육 플랫폼 에듀테크 프론트엔드 개발자 [Condition]: - 데이터 구조: const quizData = [ { question: '...', options: ['...', '...', '...'], answer: 0, explanation: '...' }, ... ]; - 요구 기능: 1) 현재 문제 번호(currentIdx)를 추적하여 화면에 문제와 선택지 버튼 3개를 동적으로 표시. 2) 유저가 버튼을 눌렀을 때 if (userChoice === quizData[currentIdx].answer) 조건으로 정답/오답 판정. 3) 정답이면 초록색, 오답이면 빨간색 피드백 및 친절한 해설 문구 노출. 4) '다음 문제' 버튼을 누르면 currentIdx를 1 올리고 다음 문제로 이동. - 순수 자바스크립트로 동작하게 작성해줘. [Output Format]: - quizData 배열과 퀴즈 처리 함수(renderQuiz, checkAnswer)가 포함된 자바스크립트 코드 - 객체 배열을 사용했을 때 왜 코드가 깨끗해지는지 2줄 설명

문제마다 일일이 변수를 만들지 않고, 배열 안에 객체를 담는 현업 표준 데이터 모델링(Data Modeling) 기법을 한 방에 완성해 줍니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

데이터(퀴즈 목록)와 로직(출제 및 채점 엔진)을 분리하면, 나중에 문제가 100개로 늘어나도 자바스크립트 코드는 단 한 줄도 고칠 필요가 없기 때문입니다.

5. 대입(=) vs 비교(===) 치명적 무한 조건 버그 격퇴 퀘스트

약점: if (grade = '전설') 처럼 실수로 대입 연산자를 써서 무조건 참이 되는 결함 차단
[Goal]: 내가 작성한 가챠 게임에서 주사위 점수가 10점밖에 안 나왔는데도 무조건 '전설 당첨!'이 터져버리는 끔찍한 버그를 찾아 퇴치해줘. [Actor]: 자바스크립트 문법 검사기(ESLint) 규칙 설계 전문가 [Condition]: - 버그가 터진 코드: let dice = 10; let grade = '일반'; if (grade = '전설') { alert('축하합니다! 황금 엑스칼리버 당첨!'); } - 문제점: 1) 주사위도 낮고 분명 '일반' 등급인데 조건문이 무조건 실행됨! 2) 게다가 grade 변수마저 '전설'로 강제 변경되어 버림! - 원인을 어린이 눈높이로 진단하고 왜 = 대신 === 를 써야 하는지 해설해줘. [Output Format]: 1. 왜 if문 안에서 = 을 쓰면 무조건 참(true)이 되는지 알기 쉬운 원리 설명 2. = (대입), == (느슨한 비교), === (엄격한 일치)의 차이점 3줄 정리 3. 버그가 완벽히 박멸된 올바른 자바스크립트 코드
