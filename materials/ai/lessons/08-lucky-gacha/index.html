가챠 오프닝: 매번 똑같은 결과는 심심해! 우연과 행운의 마법

7강 쿠키클리커는 버튼을 누르면 정직하게 1개씩 숫자가 올라갔습니다. 하지만 모바일 게임 속 보물 상자를 열 때처럼 "이번엔 뭐가 나올까?!" 하고 심장이 두근두근 뛰는 재미를 주려면 어떻게 해야 할까요?
컴퓨터가 보이지 않는 주사위를 던져 결과를 무작위로 결정하는 난수(Math.random)와, 그 결과에 따라 다른 보상을 선물하는 조건문(if/else)이 필요합니다!

미션 1: 두근두근 럭키 가챠 상자

황금 열쇠를 돌리면 상자가 흔들리며 아이템이 튀어나옵니다! 일반 아이템(70%), 희귀 아이템(25%), 그리고 단 5% 확률의 전설의 황금검을 뽑아보세요!

미션 2: 3문항 스피드 상식 퀴즈

문제를 하나 풀면 다음 문제로 쏙 넘어가는 배열 퀴즈! 정답을 맞히면 점수가 올라가고 즉시 해설 피드백을 보여줍니다.

핵심 원리: 갈림길 신호등(조건문)과 번호표 서랍장(배열)

컴퓨터에게 상황 판단력과 보관함을 선물해주는 3대 마법 도구를 알아봅시다!

1. if / else (신호등)
if (점수 >= 80) { 합격! }

"만약 비가 오면 우산을 쓰고, 안 오면 모자를 써라!" 처럼 참/거짓에 따라 다른 길로 안내하는 갈림길 신호등입니다.

2. 배열 (번호표 서랍장)
['나무검', '은방패', '황금검']

아이템이나 퀴즈 문제를 차례대로 담아두는 칸칸이 보관함입니다. 대괄호([ ])로 묶어주고 쉼표(,)로 구분합니다.

3. Math.random (주사위)
Math.random() * 100

컴퓨터가 0부터 1 사이의 예측 불가능한 소수를 무작위로 던져주는 마법 주사위입니다. 100을 곱하면 100면체 주사위가 됩니다!

실전 제작: 가챠 뽑기와 퀴즈 진행 코드 들여다보기

우측 실습 콘솔에서 실제로 구동되는 가챠 머신과 퀴즈 아케이드의 핵심 코드를 확인해봅시다!

1. 럭키 가챠 확률 판정 함수 (if/else if 문) 
function openGacha() {
  const dice = Math.random() * 100; // 0 ~ 99.99 사이의 무작위 주사위!
  
  if (dice >= legendThreshold) {
    return '🌟 전설의 황금검 (5% 당첨!)';
  } else if (dice >= 70) {
    return '🛡️ 은빛 기사 방패 (25% 당첨)';
  } else {
    return '🪵 평범한 나무 몽둥이 (70%)';
  }
}

명탐정 오류 연구소: 개발자들을 울리는 2대 마법 함정!

조건문과 배열을 다룰 때 10명 중 9명이 겪는 치명적인 버그 함정입니다.

함정 1: 컴퓨터는 0번부터 셉니다! (Off-by-One)

아이템이 3개 들어있는 배열 ['A', 'B', 'C']에서 마지막 3번째 아이템을 꺼내려고 list[3]을 부르면 컴퓨터는 undefined(텅 빔!)를 뱉어냅니다.
마지막 3번째 아이템의 진짜 번호표는 list[2]입니다!

함정 2: 넣기(=)와 비교하기(===)를 헷갈리면 안 돼요!

• score = 100 ➔ 상자에 100을 집어넣어라! (대입)
• if (score === 100) ➔ 상자 안의 숫자가 진짜 100과 똑같니? (비교)
조건문 안에서 if (score = 100)이라고 쓰면 무조건 참이 되어 게임 규칙이 엉망이 됩니다!

🔍 주니어 개발자를 위한 전문 용어 돋보기

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 게임 개발자들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 조건문 영문: Conditional Statement (if / else)
제어 흐름
🧸 어린이 비유: "비가 오면 우산을 쓰고, 해가 뜨면 모자를 쓰는 갈림길 표지판!"

🎓 개발자 공식 정의: 주어진 불리언(Boolean) 조건식의 참(true) 또는 거짓(false) 결과에 따라 프로그램의 실행 흐름을 여러 갈래로 분기시키는 제어문입니다.

2. 배열 영문: Array ([ ])
자료구조
🧸 어린이 비유: "번호표(0, 1, 2...)가 붙어 여러 개의 보물을 한 줄로 가지런히 넣어둔 기차 칸 서랍장!"

🎓 개발자 공식 정의: 여러 개의 데이터 요소를 순서대로 나열하여 단일 변수에 연속적으로 저장하는 대표적인 선형 자료구조(Linear Data Structure)입니다.

3. 인덱스 영문: Array Index
주소/참조
🧸 어린이 비유: "서랍장의 몇 번째 칸인지 알려주는 번호표입니다. 컴퓨터는 신기하게 0번부터 세어요!"

🎓 개발자 공식 정의: 배열이나 리스트 등의 순차적 컬렉션에서 특정 요소의 위치를 식별하기 위해 부여된 0 기반(Zero-based) 정수 위치 번호입니다.

4. 난수 생성기 영문: Random Number Generator (Math.random)
수학/알고리즘
🧸 어린이 비유: "0부터 1 사이에서 아무도 예측할 수 없는 숫자를 데굴데굴 굴려주는 디지털 요술 주사위!"

🎓 개발자 공식 정의: 0 이상 1 미만의 부동소수점 난수를 균일한 확률 분포(Uniform Distribution)로 무작위 생성하는 알고리즘 함수입니다.

5. 불리언 영문: Boolean (true / false)
데이터 타입
🧸 어린이 비유: "스위치처럼 '켜짐(참)'과 '꺼짐(거짓)' 딱 두 가지만 대답하는 진실의 거울!"

🎓 개발자 공식 정의: 참(true)과 거짓(false) 두 가지 논리적 진리값만을 가질 수 있는 원시 데이터 타입(Primitive Data Type)입니다.

6. 엄격 동등 비교 연산자 영문: Strict Equality Operator (===)
연산자/검증
🧸 어린이 비유: "왼쪽과 오른쪽이 진짜 완벽하게 똑같은지 저울에 올려 꼼꼼하게 따져보는 감별사!"

🎓 개발자 공식 정의: 두 피연산자의 값과 자료형(Data Type)이 모두 일치하는지를 엄격하게 판별하는 일치 비교 연산자입니다.
