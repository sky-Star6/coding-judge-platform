시즌 1: 웹 프론트엔드 빌드 5강 HTML 뼈대 조립

5강 — 게임 화면의 뼈대 만들기: HTML로 대사창과 선택지 조립

지금까지 기획한 판타지 캐릭터와 밸런스 패치된 스토리를 드디어 컴퓨터 웹 브라우저 화면 위에 직접 코딩으로 구현합니다. 웹의 뼈대인 HTML 태그를 배우고 비주얼 노벨의 대사창과 선택지 버튼을 조립해 봅시다!

이번 강의에서 배우는 것

  • 웹 페이지의 뼈대를 만드는 HTML(HyperText Markup Language)의 기본 개념과 태그 문법을 이해합니다.
  • 비주얼 노벨 화면을 만드는 필수 태그 5가지(<h1>, <div>, <p>, <button>, <img>)의 역할을 익힙니다.
  • AI에게 초보자용 깔끔한 HTML 뼈대 코드를 요청하고, 생성된 코드를 내 스토리에 맞게 직접 수정합니다.
  • 태그를 닫지 않거나 한글이 깨지는 초보자 단골 HTML 버그를 브라우저 개발자 도구로 찾아 해결합니다.
  • 브라우저 화면에 실제 클릭할 수 있는 나만의 비주얼 노벨 첫 화면을 완성합니다.

코딩 비유로 쉽게 이해하는 HTML

집을 지을 때를 상상해 보세요. 아무리 예쁜 벽지를 바르고 조명을 달고 싶어도, 가장 먼저 기둥을 세우고, 벽돌을 쌓고, 방과 문의 자리를 잡아야 합니다.

1. HTML (뼈대와 구조) - [오늘 배울 것!]

"여기는 게임 제목 자리, 여기는 캐릭터 일러스트 상자, 여기는 대사창, 여기는 플레이어가 누를 선택지 버튼 2개야!" 하고 웹 브라우저에게 부품들의 위치와 이름을 알려주는 설계도입니다.

2. CSS (인테리어와 스타일) - [다음 6강!]

어두운 던전 분위기의 밤하늘색 배경을 칠하고, 버튼에 마우스를 올리면 황금빛으로 빛나게 글씨와 색상을 꾸며주는 마법의 페인트입니다.

3. JavaScript (생명과 동작) - [시즌 2!]

버튼을 딸깍 클릭하면 대사가 술술 바뀌고, 점수가 올라가고, 배경음악이 흘러나오게 만드는 진짜 뇌(Brain)와 엔진입니다.

핵심 요약: 오늘 우리는 HTML이라는 튼튼한 레고 블록으로 우리 비주얼 노벨의 무대를 완성할 것입니다!

초보자 단골 HTML 버그 TOP 3

1. 닫는 태그 누락 (Missing Closing Tag)

실수: <button>동굴로 들어간다 라고 쓰고 </button>을 안 닫음.

👉 증상: 그 뒤에 나오는 모든 글자가 버튼 안에 들어가거나 화면 배치가 와르르 무너집니다!

2. 한글 글자 깨짐 (Encoding Error)

실수: 문서 상단 <head> 안에 글자 인코딩 설정을 빼먹음.

👉 해결책: <meta charset="UTF-8"> 한 줄을 반드시 넣어주면 외계어처럼 깨지던 한글이 말끔하게 나옵니다.

3. 태그 오타 (Typo)

실수: <buton>(t가 하나 빠짐), <divv> 등 오타 입력.

👉 해결책: 브라우저는 모르는 태그를 무시하므로 버튼 모양이 생기지 않고 그냥 글자만 덜렁 나옵니다.

미션 진행 3단계

  1. 체험관에서 코드 테스트: 위의 실시간 에디터에서 내 대사와 선택지를 먼저 넣어보고 버튼이 잘 나오는지 확인합니다.
  2. 내 컴퓨터 파일로 저장: 메모장이나 텍스트 에디터(VS Code 등)를 열어 코드를 붙여넣고 game.html로 저장합니다.
  3. 더블 클릭하여 브라우저에서 실행: 저장한 game.html 파일을 더블 클릭해 크롬이나 엣지 브라우저에서 내 게임 화면이 예쁘게 뜨는지 확인합니다!
