우리가 매일 보는 네이버, 유튜브, 게임 웹페이지는 모두 3가지 친구가 힘을 합쳐 만듭니다.

🧱 1. HTML
건물의 뼈대 & 레고 블록

"여기는 큰 제목! 여기는 캐릭터 대사 상자! 밑에는 선택지 버튼 2개!"처럼 화면에 무엇이 들어갈지 내용과 뼈대 구조를 세우는 언어입니다.

🎨 2. CSS
예쁜 마법 옷 & 인테리어

"글자 색은 황금빛, 배경은 어두운 밤하늘, 모서리는 둥글게!" 밋밋한 뼈대에 예쁜 색깔과 스타일을 입혀주는 마법 디자이너입니다. (6강에서 배움!)

⚡ 3. JavaScript
살아 숨 쉬는 심장 & 두뇌

"선택지 1번을 누르면 체력 10 회복! 2번을 누르면 다음 챕터로 이동!" 사용자의 행동에 맞춰 화면을 움직이고 살아 숨 쉬게 만드는 두뇌입니다.

게임 대사창을 완성하는 핵심 레고 태그 5총사

<h1> ~ <h3> 제목 간판

게임 타이틀이나 현재 챕터 제목(예: "고대 도서관 3층")처럼 크고 굵은 제목을 만듭니다.

<div> 레고 상자 컨테이너

여러 레고 블록(대사와 버튼들)을 깔끔하게 하나로 묶어주는 투명한 포장 상자입니다.

<span> 작은 이름표

"마법사 루카:", "용사:"처럼 대사를 말하는 캐릭터의 이름표나 뱃지를 표시합니다.

<p> 이야기 문단

Paragraph(문단)의 약자로, 캐릭터의 대사나 장면의 상황 설명 텍스트를 담습니다.

<button onclick="..."> 인터랙티브 선택 버튼

플레이어가 마우스로 클릭할 수 있는 버튼입니다. onclick="alert('내용')"을 넣으면 클릭 즉시 알림창이 뜹니다!

주니어 개발자의 황금률: "상자를 열었으면 반드시 닫아라!"

HTML 태그는 <button>처럼 열고 난 뒤, 반드시 슬래시(/)가 붙은 </button>으로 닫아주어야 브라우저가 헷갈리지 않고 화면을 정확히 그려냅니다.

AI와 함께 만드는 5대 실전 HTML 인터랙티브 실험실

ChatGPT나 Gemini 창을 새 탭으로 띄워두고, 아래 5개 퀘스트 카드의 [프롬프트 복사] 버튼을 눌러 붙여넣어 보세요! AI가 단숨에 살아 숨 쉬는 웹 코드를 짜서 돌려줍니다.

🧱

1. 비주얼 노벨 3단 HTML 뼈대 소환 퀘스트

약점: 시맨틱 태그 구조화와 컨테이너 분리
[Goal]: 웹 브라우저에서 실행 가능한 비주얼 노벨 게임의 'HTML 대사창과 3대 선택지' 뼈대 코드를 만들어줘. [Actor]: 초보 웹 개발자를 가르치는 친절한 시니어 프론트엔드 멘토 [Condition]: - CSS나 JS 파일 없이, 순수 HTML 태그(h1, div, span, p, button)만 사용할 것. - 구조: 1) 최상단 게임 제목(h1) 2) 캐릭터 이름표(span)와 대사 본문(p)을 감싼 대사창 박스(div) 3) 세 가지 선택지 버튼(button 3개)을 감싼 버튼 영역(div) - 각 버튼을 클릭하면 alert() 창이 뜨도록 onclick 속성을 넣어줘. [Output Format]: - 순수 HTML 코드 블록 (초보자용 매 줄 주석 포함) - 사용된 태그(h1, div, span, p, button)의 역할 1줄 요약
🤖 AI의 놀라운 코드 생성 마법:

복잡한 설명 없이 바로 브라우저에 붙여넣으면 버튼 클릭까지 작동하는 완성도 높은 HTML 대사창 템플릿이 단 3초 만에 작성됩니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

AI에게 필요한 태그 목록과 3단 구조(제목➔대사➔선택지)를 명확히 못 박았기 때문에, 군더더기 코드 없이 시맨틱한 규격 코드를 정확히 생성합니다.

🕵️

2. 닫는 태그 실종 사건 QA 검사관 퀘스트

약점: 닫는 태그 누락 및 태그 중첩(Nesting) 오류 탐지
[Goal]: 내가 작성한 HTML 코드에서 닫는 태그 누락이나 중첩 오류 같은 '문법 버그'를 매의 눈으로 찾아내줘. [Actor]: W3C 웹 표준 검사관 출신의 깐깐한 코드 리뷰어 [Condition]: - 검사할 코드: <h1>신비한 숲속의 갈림길 <div class="dialogue-box"> <p>"앞에 늑대가 나타났다! 도망칠까, 싸울까? <button>칼을 뽑아 싸운다<button> <button>나무 위로 올라간다</button> </div> - 닫히지 않은 태그와 잘못된 여는 태그를 정확히 찾아내어 초보자 눈높이로 지적할 것. [Output Format]: 1. 발견된 문법 오류 3가지 (위치 및 원인) 2. 완벽하게 수리된 올바른 HTML 완성본 3. 태그를 올바르게 닫아야 하는 컴퓨터 과학 이유 1줄
🤖 AI의 놀라운 코드 생성 마법:

"<h1>과 <p>의 닫는 태그가 누락되었고, 첫 번째 버튼에 슬래시(/)가 빠져 태그가 꼬였습니다!"라며 초보자가 가장 많이 하는 실수를 정확히 짚어줍니다.

💡 왜 그럴까요? (컴퓨터 과학 비밀):

브라우저의 HTML 파서는 닫는 태그가 없으면 어디까지가 내용인지 알 수 없어 화면이 와르르 깨집니다. AI는 구문 분석 트리(AST)로 이 구조를 즉시 검증합니다.

🏷️

3. 명찰과 옷장(id & class) 이름표 설계 퀘스트

약점: id와 class의 차이점 및 고유 식별자 설계
[Goal]: 비주얼 노벨 화면의 각 태그에 나중에 CSS로 예쁘게 꾸밀 수 있도록 'id'와 'class' 명찰을 체계적으로 달아줘. [Actor]: 10년 차 게임 UI/UX 디자인 시스템 엔지니어 [Condition]: - 대상: 사이버펑크 도시의 해커 대화창 (화면 타이틀, 해커 이름, 시스템 경고 대사, 암호 해독 버튼 2개). - 규칙: 1) 화면에 딱 하나만 존재하는 중요한 요소(타이틀, 대사 상자)에는 id 명찰을 부여할 것. 2) 여러 버튼에 공통으로 적용될 스타일에는 class 명찰을 부여할 것. - 영문 변수명은 초보자도 뜻을 바로 알 수 있는 쉬운 단어로 지어줘. [Output Format]: - id와 class 명찰이 깔끔하게 부여된 HTML 코드 - 각 id와 class 이름이 왜 그렇게 지어졌는지 설명표
🤖 AI의 놀라운 코드 생성 마법:

`id="dialogue-box"`, `class="cyber-choice-btn"` 처럼 직관적이고 표준적인 명명 규칙을 적용하여 6강 CSS 꾸미기가 100배 쉬워지는 명찰 시스템을 완성해 줍니다.

💡 왜 그럴까요? (컴퓨터 과학 비밀):

`id`는 주민등록번호처럼 한 화면에 단 하나만 쓰는 고유 이름이고, `class`는 같은 반 교복처럼 여러 요소에 함께 입히는 그룹 이름입니다.

🎮

4. 판타지 RPG 보스전 인터랙티브 선택지 생성 퀘스트

약점: 속성(Attributes)과 이벤트 핸들러 onclick 결합
[Goal]: 플레이어가 버튼을 눌렀을 때 서로 다른 브라우저 알림창이 뜨는 '드래곤 보스전 3대 선택지' HTML 코드를 작성해줘. [Actor]: 텍스트 어드벤처 웹 게임 전문 프로그래머 [Condition]: - 상황: 분화구 정상에서 화염 드래곤을 마주친 클라이맥스. - 선택지 3개: 1) [방패 방어]: alert('드래곤의 불꽃을 방패로 막아냈습니다! 방패 내구도 -50%') 2) [약점 사격]: alert('눈을 정확히 저격했습니다! 드래곤이 비틀거립니다!') 3) [대화 시도]: alert('드래곤이 코웃음을 치며 화염을 내뿜습니다. 즉사!') - 각 버튼 태그에 onclick 속성을 올바르게 연결할 것. [Output Format]: - 즉시 브라우저에서 실행 가능한 HTML 코드 - onclick 속성이 자바스크립트와 연결되는 원리 2줄 해설
🤖 AI의 놀라운 코드 생성 마법:

버튼마다 클릭 즉시 브라우저 알림창이 펑 터지며 실제 게임을 플레이하는 듯한 몰입감 넘치는 인터랙티브 버튼 코드를 깔끔하게 뽑아줍니다.

💡 왜 그럴까요? (컴퓨터 과학 비밀):

HTML의 `onclick` 속성은 "사용자가 클릭했을 때 자바스크립트 명령어를 실행하라"는 이벤트 리스너(Event Listener) 역할을 수행합니다.

🧩

5. 텍스트 소설을 HTML 대사창으로 변환하는 자동 파서 퀘스트

약점: 일반 텍스트 문서를 웹 구조화 데이터로 파싱 변환
[Goal]: 내가 쓴 평범한 줄글 소설을 웹 브라우저에서 바로 보이는 'HTML 비주얼 노벨 대사창 코드'로 완벽하게 변환해줘. [Actor]: 텍스트-웹 변환 자동화 전문 프론트엔드 아키텍트 [Condition]: - 원본 소설 텍스트: [장소: 달빛 아래 버려진 시계탑] 태엽 수리공 아리아가 떨리는 손으로 황금 렌치를 쥐었다. "이 톱니바퀴만 맞추면 10년 전 과거로 돌아갈 수 있어..." 선택지 1: 톱니바퀴를 오른쪽으로 돌린다. 선택지 2: 톱니바퀴를 멈추고 도망친다. - 위 소설을 분석하여 제목(h1), 대사 상자(div), 이름표(span), 대사(p), 선택지 버튼(button)으로 100% 변환할 것. [Output Format]: - 변환된 시맨틱 HTML 대본 - 웹 브라우저에 표시될 화면 구조 미리보기 다이어그램
🤖 AI의 놀라운 코드 생성 마법:

단순한 줄글 메모를 전달했을 뿐인데, AI가 인물, 대사, 지문, 선택지를 정확히 분리하여 웹 표준 규격의 HTML 구조로 한 번에 재구성해 냅니다!

💡 왜 그럴까요? (컴퓨터 과학 비밀):

비구조화된 텍스트(Unstructured Text)를 구조화된 마크업(Structured Markup)으로 파싱(Parsing)하는 거대 언어 모델의 뛰어난 정보 추출 능력을 활용하는 방법입니다.

SELF-CHECK & GLOSSARY

🔍 주니어 개발자를 위한 전문 용어 돋보기

오늘 배운 HTML 기초의 실제 공식 웹 표준 / 컴퓨터 과학 전문 용어를 확인해 보세요.

🧱 HTML

HyperText Markup Language / 웹 문서 구조 언어

🧸 어린이 비유: 건물을 지을 때 가장 먼저 튼튼하게 세우는 철근 뼈대와 레고 블록!

🎓 개발자 정의: 웹 브라우저가 화면에 제목, 본문, 버튼, 이미지 등의 위치와 구조를 해석하도록 규정한 국제 표준 마크업 언어.

🏷️ 시맨틱 태그

Semantic Tags / 의미를 담은 태그

🧸 어린이 비유: 그냥 빈 상자가 아니라 '냉장고', '보물상자', '우편함'처럼 이름과 용도가 적힌 특수 레고 블록!

🎓 개발자 정의: 브라우저와 검색엔진, 스크린 리더가 콘텐츠의 구조적 의미를 직관적으로 이해할 수 있도록 용도에 맞게 명명된 HTML 태그(<h1>, <p>, <button> 등).

📦 태그와 요소

Tag & Element / 여는 태그와 닫는 태그

🧸 어린이 비유: 뚜껑을 열고 장난감을 넣은 뒤 반드시 뚜껑을 닫아야 쏟아지지 않는 레고 보관함!

🎓 개발자 정의: <tag>(시작)와 </tag>(종료), 그리고 그 사이의 내용(Content)을 모두 합쳐 브라우저가 하나의 단위로 인식하는 HTML 기본 구성 요소.

✨ 속성

Attributes / 태그의 명찰과 부가 설정

🧸 어린이 비유: 인형의 가슴에 단 하나뿐인 '이름표(id)'와 교복 옷장(class), 그리고 스위치(onclick)!
