2단계 · 마크업 문법 탐구

태그(Tag)의 절대 규칙과 게임 화면 5총사 블록

HTML에서 태그(Tag)는 브라우저에게 붙여주는 이름표 스티커입니다. 단 하나의 절대 규칙만 기억하면 어떤 화면이든 쉽게 조립할 수 있습니다!

🏷️ 태그의 절대 규칙: "열었으면 반드시 뚜껑을 닫아라!"

음료수 캔을 땄으면 다 마시고 뚜껑을 닫듯이, 태그도 시작했으면 어디서 끝나는지 슬래시(`/`) 꼬리표를 붙여서 닫아주어야 합니다.

# 태그의 기본 구조
<시작태그> 화면에 보여줄 내용 </끝내는태그>
💡 끝내는 태그에는 반드시 이름 앞에 슬래시(`/`)가 붙습니다!

🧱 비주얼 노벨을 조립하는 필수 레고 블록 5총사

<h1> ... </h1> 대문짝만한 게임 제목 간판

Heading(제목)의 약자예요. 게임의 타이틀이나 장소 이름("고대 도서관 3층")처럼 가장 굵고 크게 보여줄 때 사용합니다.

<p> ... </p> 이야기꾼의 대사 말풍선

Paragraph(문단)의 약자예요. 캐릭터의 긴 대사나 나레이션("어두운 복도 끝에서 수상한 발소리가 들려온다...")을 담습니다.

<button> ... </button> 콕 누르는 갈림길 선택 버튼

플레이어가 마우스로 클릭할 수 있는 선택지 버튼이에요. "[왼쪽 문을 연다]"처럼 결정을 내릴 때 누릅니다.

<div> ... </div> 레고 정리 상자 (투명 묶음 상자)

Division(나누기)의 약자예요. 캐릭터 이름, 대사, 버튼들을 하나의 '대사창 상자'로 묶어 이사시키거나 테두리를 칠할 때 씁니다.

<span> ... </span> 단어 강조 형광펜

문장 전체가 아니라 주인공 이름이나 중요한 단어("용사 레오", "황금 열쇠")에만 쏙 들어가 색을 칠할 때 쓰는 얇은 스티커예요.

초보자가 가장 많이 하는 실수 TOP 3
1. 닫는 슬래시 실종

`<button>선택<button>`처럼 슬래시를 빼먹으면 뒤에 오는 모든 글자가 버튼으로 변해버려요!

2. 부등호 괄호 오타

`<p>` 대신 `(p)`나 `[p]`를 쓰면 브라우저가 태그로 알아보지 못하고 그냥 글자로 보여줍니다.

3. 엉뚱한 짝짓기

`<p>`로 열고 `</div>`로 닫으면 컴퓨터가 "어느 상자를 닫아야 하지?" 하고 당황해요.

🔍 주니어 개발자를 위한 전문 용어 돋보기

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 웹 개발자들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 하이퍼텍스트 영문: Hypertext
Web
🧸 어린이 비유: "클릭 한 번으로 다른 방이나 다른 웹 세상으로 순식간에 날아가는 마법의 순간이동 포털 글자입니다."

🎓 개발자 공식 정의: 문서와 문서가 하이퍼링크(Hyperlink)를 통해 거미줄처럼 상호 연결되어 있어 사용자가 원하는 정보를 비순차적으로 탐색할 수 있는 텍스트 시스템입니다.

2. 마크업 언어 영문: Markup Language (HTML)
Markup
🧸 어린이 비유: "레고 설명서처럼 '여기서부터 여기까지는 대사창이야!'라고 컴퓨터 브라우저에게 붙여주는 이름표 스티커 언어입니다."

🎓 개발자 공식 정의: 태그(Tag)를 사용하여 문서의 구조, 제목, 본문, 버튼 등의 의미와 역할을 브라우저가 해석할 수 있도록 정의하는 표기 체계입니다.

3. DOM 트리 영문: Document Object Model Tree
DOM
🧸 어린이 비유: "큰 상자 안에 작은 상자가 쏙쏙 들어가 있는 러시아 인형(마트료시카)이나 가지를 뻗는 레고 나무 구조입니다."

🎓 개발자 공식 정의: 웹 브라우저가 HTML 문서를 읽어 태그들의 부모-자식 관계를 계층적 트리(Tree) 객체 구조로 메모리에 표현한 모델입니다.

4. 속성 영문: Attribute
Option
🧸 어린이 비유: "이름표 스티커에 적힌 보너스 옵션(색상, 아이디, 연결 주소)입니다."

🎓 개발자 공식 정의: HTML 태그에 추가적인 정보나 제어 옵션(id, class, src, href 등)을 부여하는 key="value" 형태의 설정값입니다.

5. 개발자 도구 영문: Browser DevTools (F12)
Debug
🧸 어린이 비유: "의사 선생님의 엑스레이 기계처럼 웹 화면의 뼈대와 숨겨진 버그를 들여다보는 투시 안경입니다."

🎓 개발자 공식 정의: 웹 브라우저에 내장되어 HTML 구조 분석, CSS 실시간 수정, 자바스크립트 콘솔 에러를 점검하는 전문 디버깅 도구입니다.

6. 인라인 vs 블록 요소 영문: Inline vs Block Elements
Layout
🧸 어린이 비유: "한 줄을 혼자 다 차지하는 뚱뚱한 기차 상자(Block) vs 글자 옆에 찰싹 달라붙는 얇은 스티커(Inline)입니다."

🎓 개발자 공식 정의: 화면 전체 너비를 차지하며 줄바꿈을 일으키는 블록 레벨 요소(div, p, h1)와, 콘텐츠 너비만큼만 차지하여 가로로 나열되는 인라인 요소(span, a)의 레이아웃 성질입니다.
