포켓몬 트레이너의 필수 장비, 스마트 전자도감을 내 손으로 코딩하기

스마트폰이나 게임기에서만 보던 멋진 포켓몬 도감을 우리가 직접 만든 웹 브라우저 화면에 띄웁니다. 수천 줄의 복잡한 원문 데이터를 분석하여, 친구들이 환호할 수 있도록 일러스트와 전투력 게이지로 변신시키는 데이터 시각화의 즐거움을 경험해 보세요!

이번 퀘스트의 4대 성공 루브릭 (성공 판정 기준)

1. PokeAPI REST 엔드포인트 연동

/pokemon/{id_or_name} 주소 규격에 맞추어 포켓몬 데이터 패킷을 수신합니다.

2. 스프라이트 그래픽 추출

복잡한 sprites.other['official-artwork'] 객체 트리를 탐색해 고화질 공식 일러스트를 화면에 렌더링합니다.

3. 스탯 바(Stats Bar) 데이터 시각화

HP, 공격력, 방어력, 스피드 숫자를 최대 255 기준의 체력 게이지 바(가로 막대그래프)로 생동감 있게 변환합니다.

4. 검색 오타 404 방어 & 이로치 모드

존재하지 않는 포켓몬 검색 시 404 에러를 낚아채어 친절한 안내를 띄우고, 반짝이(Shiny) 일러스트 토글을 지원합니다.

Stage 2: 핵심 원리 (도감 엔드포인트와 스탯 게이지 시각화)

숫자 데이터와 그림 주소를 조립해 하나의 완성된 도감 카드를 만드는 비법

1. 번호나 이름표만 주면 배달 출발! (RESTful 엔드포인트)

PokeAPI는 복잡한 물음표 쪽지 없이도, 주소 끝에 내가 원하는 포켓몬의 **도감 번호(ID)**나 **영문 이름**만 적어주면 알아서 찾아주는 똑똑한 규칙(REST API)을 가지고 있습니다.

// 1. 도감 번호 25번으로 피카츄 소환
https://pokeapi.co/api/v2/pokemon/25
// 2. 영문 이름으로 전설의 뮤츠 소환
https://pokeapi.co/api/v2/pokemon/mewtwo

2. 고화질 공식 일러스트 찾기: 스프라이트 객체 트리 탐색

포켓몬 서버가 보내주는 데이터에는 수십 장의 게임 도트 그림과 3D 일러스트가 들어있습니다. 우리가 원하는 멋진 공식 일러스트는 sprites.other['official-artwork'].front_default 주소에 보관되어 있어요!

1단계 data.sprites ➔ 모든 이미지 파일들이 모여있는 앨범 서랍
2단계 other['official-artwork'] ➔ 작은 도트가 아닌 고화질 공식 일러스트 전용 폴더
3단계 front_default ➔ 바로 화면의 <img src="...">에 꽂아 넣을 최종 URL!

3. 숫자를 게임 체력바로 바꾸는 데이터 시각화의 마법

단순히 "HP: 35, Speed: 90"이라고 글자로만 보여주면 피카츄가 얼마나 빠른지 한눈에 알기 어려워요. 포켓몬의 최대 스탯 한계치인 **255**를 기준으로 비율을 계산해 가로 막대그래프로 칠해주면 멋진 게임 화면이 완성됩니다!

// 스탯 숫자(0~255)를 퍼센트(0%~100%) 폭으로 변환하는 공식
const percent = Math.min(100, Math.round((statValue / 255) * 100));
// HTML 요소의 너비 스타일로 지정
statGaugeBar.style.width = `\${percent}%`;
