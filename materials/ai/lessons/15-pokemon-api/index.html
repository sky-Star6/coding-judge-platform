PokeAPI 도감 호출과 대소문자·공백 자동 손질(Trim & Lowercase) 함수 구현

사용자가 "PIKACHU "처럼 대문자나 공백을 섞어 검색해도 404 에러 없이 깔끔하게 소환할 수 있도록 입력값을 정돈하고 비동기 통신을 수행하는 파이프라인 함수를 작성합니다.

실전 함정: 대문자 'PIKACHU'나 앞뒤 공백을 그대로 URL에 전송하면 PokeAPI 서버가 404 Not Found를 응답해 도감이 멈춥니다!
실전 AI 프롬프트 (원클릭 복사)
[역할] 너는 웹 프론트엔드와 오픈 API 연동을 가르치는 시니어 개발자이자 코딩 멘토야. [상황 및 요구사항] 오픈 API인 PokeAPI('https://pokeapi.co/api/v2/pokemon/{query}')를 비동기로 호출하는 fetchPokemonData(query) 자바스크립트 함수를 작성하려고 해. [요청 사항] 1. 사용자가 'PIKACHU'나 ' 25 '처럼 입력해도 안전하도록 query.trim().toLowerCase()를 적용해 줘. 2. async/await와 fetch를 사용해 도감 번호(숫자) 또는 소문자 영문 이름을 엔드포인트에 전달할 것. 3. response.ok를 검사해 성공 시 data JSON을 반환하고, 실패 시 친절한 에러 객체를 던질 것. 4. 초등학생 및 입문자도 각 줄의 목적을 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.

대소문자 오차를 100% 방어하는 trim/toLowerCase 전처리와 안전한 async/await 통신 코드를 단 3초 만에 완성합니다!

QUEST 02 고화질 공식 일러스트 안전 추출
중급 객체 탐색 ★★☆

옵셔널 체이닝(?.)을 활용한 official-artwork 고화질 일러스트와 Fallback 도트 이미지 추출술

수십 단계로 중첩된 PokeAPI의 스프라이트 앨범에서 3D 공식 일러스트를 추출하고, 속성이 누락되었을 때 앱이 다운되지 않도록 안전한 기본 도트 이미지로 우아하게 대체하는 방어 로직을 작성합니다.

실전 함정: 방어 코드 없이 data.sprites.other['official-artwork'].front_default에 직행하면 속성이 없을 때 TypeError로 브라우저가 정지합니다!
실전 AI 프롬프트 (원클릭 복사)
[역할] 너는 자바스크립트 런타임 오류 방어와 중첩 객체 탐색 전문가야. [문제 상황] PokeAPI의 응답 JSON에서 공식 일러스트를 추출하려고 해. 경로는 data.sprites.other['official-artwork'].front_default인데, 일부 최신 포켓몬이나 특수 폼은 official-artwork 객체가 비어있거나 null일 수 있어. [해결 요청] 1. 최신 옵셔널 체이닝(?.) 문법을 사용하여 중첩 속성이 없어도 절대 TypeError를 내지 않는 getOfficialArtworkUrl(pokeData, isShiny) 함수를 작성해 줘. 2. 만약 공식 일러스트가 없으면 data?.sprites?.front_default(기본 도트 이미지)로 대체하고, 그것마저 없으면 더미 물음표 이미지 URL로 안전하게 fallback하는 삼중 안전망을 구축해 줘. 3. isShiny 플래그가 true일 때는 shiny 버전 일러스트를 우선 반환하도록 설계해 줘. 4. 옵셔널 체이닝이 왜 '점(.) 표기법'보다 안전한지 주니어 개발자 눈높이에서 설명해 줘.
✨ AI 충격 반응 & 소환 마법

어떤 포켓몬이 들어와도 절대 깨지지 않는 3중 안전망(Official ➔ 기본 도트 ➔ 물음표 Fallback) 이미지 추출기를 구축합니다!

옵셔널 체이닝(?.)은 참조 대상이 nullish(null/undefined)일 때 평가를 즉시 중단하고 undefined를 반환하여 런타임 크래시를 원천 차단합니다.

QUEST 03 데이터 시각화 & 스탯 바
시각화 디자인 ★★★

최대치 255 기준 퍼센트 비율 계산 및 컬러풀 게이지 바 동적 생성

지루한 텍스트 숫자 "HP: 35, Speed: 90"을 최대치 255 기준의 퍼센트 폭(width: X%)으로 변환해 부드러운 애니메이션과 함께 차오르는 게임 체력 막대그래프로 변신시킵니다.

실전 함정: 최대 기준치(255) 없이 그냥 숫자를 픽셀이나 퍼센트로 지정하면 게이지 바가 화면을 뚫고 나가거나 형태가 깨집니다!
실전 AI 프롬프트 (원클릭 복사)
[역할] 너는 게임 UI/UX 디자인과 프론트엔드 데이터 시각화를 가르치는 인터랙션 개발자야. [요구사항] PokeAPI의 data.stats 배열에는 6대 전투력 스탯(hp, attack, defense, special-attack, special-defense, speed)이 담겨있어. 이 수치를 게임 체력 게이지 바처럼 웹 브라우저에 시각화하려고 해. [해결 요청] 1. 포켓몬 정규 최대 스탯치인 255를 기준으로 퍼센트 비율(Math.min(100, Math.round((statValue / 255) * 100)))을 계산하는 renderStatGauges(statsArray) 함수를 작성해 줘. 2. 체력(초록색), 공격력(빨간색), 방어력(파란색), 스피드(노란색) 등 스탯 종류에 어울리는 Tailwind CSS 배경색 클래스를 적용해 줘. 3. 게이지 바가 0.5초 동안 부드럽게 뻗어나가는 transition-all CSS 스타일을 적용해 줘. 4. 매 줄마다 초보 학생이 이해하기 쉽도록 친절한 한국어 주석을 달아줘.

QUEST 04 속성(Type) 뱃지 맵핑 & 듀얼 타입
데이터 맵핑 ★★☆

18개 포켓몬 속성(Type) 영문명을 한국어와 고유 컬러 배지로 변환하는 딕셔너리 맵핑

영문 단어 'electric', 'fire', 'water'를 직관적인 한국어 뱃지로 번역하고, 리자몽처럼 불꽃과 비행을 모두 가진 듀얼 속성 포켓몬도 깔끔하게 나열 렌더링하는 객체 매핑 함수를 설계합니다.

실전 함정: if-else 문으로 18개 속성을 하나하나 분기하면 코드가 100줄이 넘어가고, 듀얼 속성 처리가 꼬여버립니다!
실전 AI 프롬프트 (원클릭 복사)
[역할] 너는 UI 디자인 시스템과 데이터 변환 딕셔너리 설계에 능숙한 자바스크립트 아키텍트야. [상황] PokeAPI의 data.types 배열은 [{'type': {'name': 'fire'}}, {'type': {'name': 'flying'}}] 형태로 전송돼. 사용자에게 친숙한 한국어 이름과 알록달록한 속성 배지를 화면에 렌더링하고 싶어. [요청 사항] 1. 18개 속성 영문 키를 받아 { nameKr, bgClass, textClass, borderClass } 객체를 반환하는 TYPE_DICTIONARY 상수를 정의해 줘. (fire: 불꽃, water: 물, grass: 풀, electric: 전기, psychic: 에스퍼 등) 2. data.types 배열을 .map()으로 순회해 1개(단일) 또는 2개(듀얼) 속성 배지 HTML 문자열을 생성하는 renderTypeBadges(typesArray) 함수를 작성해 줘. 3. 사전에 없는 낯선 속성이 들어왔을 때 회색 일반 배지로 대응하는 방어 로직을 포함해 줘. 4. if-else 문 대신 객체 매핑(Key-Value Lookup)을 사용하는 이유를 성능과 가독성 관점에서 설명해 줘.
✨ AI 충격 반응 & 소환 마법

100줄짜리 지저분한 if-else 문을 단 한 장의 세련된 딕셔너리 객체와 O(1) 초고속 조회 함수로 압축합니다!

💡 컴퓨터 과학 비밀 해설

해시 테이블(Hash Table) 기반의 객체 키 조회는 상수 시간 복잡도 O(1)로 실행되므로 조건문 분기보다 훨씬 빠르고 확장이 용이합니다.

QUEST 05 로켓단 404 방어 & 디바운싱
성능 & 예외 처리 ★★★

없는 포켓몬 404 예외 안내창과 키보드 연타를 막아주는 디바운싱(Debounce) 최적화

도감에 없는 번호 검색 시 "로켓단이 도감을 숨겼어요!"라는 Fallback 화면을 띄워 브라우저 멈춤을 방어하고, 타이핑할 때마다 수십 번 불필요하게 API를 호출하지 않도록 300ms 입력 지연 제어를 적용합니다.

실전 함정: 검색창에 글자를 칠 때마다 API를 매번 부르면 PokeAPI 서버로부터 요청 차단(Rate Limit 429)을 당할 수 있습니다!
실전 AI 프롬프트 (원클릭 복사)
[역할] 너는 프론트엔드 성능 최적화와 예외 처리 아키텍처 전문가야. [상황 및 요구사항] 포켓몬 도감 검색기에 두 가지 치명적 문제를 해결해야 해: 1. 없는 번호(예: 99999)나 오타 검색 시 404 에러를 감지하여 '로켓단이 도감을 숨겼어요!'라는 친절한 에러 카드 띄우기 2. 사용자가 실시간 검색창에 'pikachu'를 타이핑할 때 p, pi, pik... 7번 연속 호출되지 않도록 디바운싱(Debounce) 적용하기 [요청 사항] 1. response.status === 404를 깔끔히 가로채 에러 메시지 UI를 토글하는 safeSearchPokemon(query) 함수를 작성해 줘. 2. 클로저(Closure)와 setTimeout을 사용해 300ms 지연 후 마지막 입력만 실행시키는 debounce(func, delay) 유틸리티 함수를 구현해 줘. 3. 이 두 가지를 검색창 'input' 이벤트 리스너에 어떻게 연결하는지 실제 연동 예제 코드를 보여줘. 4. 초등학생도 이해할 수 있는 친절한 한국어 주석을 달아줘.
