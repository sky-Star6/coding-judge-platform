인터넷 세상의 비밀 배달부:
다른 서버에서 데이터 가져오기 (JSON & Fetch)

내 컴퓨터 안에서만 돌던 코드는 안녕! 전 세계 인터넷 서버에서 실시간 명언, 귀여운 동물 사진, 포켓몬 정보를 무료로 배달받는 fetch 마법을 배워봐요.

핵심 도구 fetch & async/await
완료 조건 오픈 API 요청 & 렌더링

1단계: 내 컴퓨터 밖으로 — 섬에 갇힌 컴퓨터에서 인터넷 세상으로!

지금까지 1강부터 12강까지 우리가 짠 자바스크립트는 오직 내 컴퓨터(브라우저) 안에서만 일어나는 일이었어요. 마치 바다 한가운데 외딴섬에 혼자 살면서 내가 가진 재료로만 집을 짓고 놀았던 것과 같아요.

하지만 진짜 멋진 앱들은 어떻게 동작할까요?
☀️ 실시간 날씨 앱 기상청 슈퍼컴퓨터에 물어봐서 현재 온도를 받아와요!
🍱 학교 급식 알리미 교육청 데이터베이스에 접속해 오늘 식단표를 가져와요!
🐶 동물 도감 앱 전 세계 사진 도서관 서버에서 강아지 사진을 배달받아요!
손님(클라이언트)과 식당(서버)의 비밀 대화 CLIENT & SERVER

인터넷 세상은 손님과 식당의 관계와 똑같아요!

👤 손님 (Client, 우리 웹 브라우저) "여기 오늘의 멋진 명언 하나 배달해 주세요!" (요청, Request)
🏢 식당 (Server, 상대방 컴퓨터) "네! 따끈따끈한 명언 JSON 데이터 포장해서 보냅니다!" (응답, Response)

2단계: 배달부 fetch — 자바스크립트의 초특급 배달 오토바이

브라우저에는 인터넷 세상의 다른 식당(서버)으로 주문서를 들고 달려가는 전용 배달부가 기본으로 탑재되어 있어요. 그 이름이 바로 fetch()입니다!

// 3단계 초간단 배달 공식
const response = await fetch('https://api.adviceslip.com/advice'); // 1. 배달 보내기
const data = await response.json(); // 2. 도착한 택배 상자 뜯기
console.log(data.slip.advice); // 3. 화면에 맛있는 데이터 쓰기
배달 영수증 확인하기: HTTP 상태 코드 3총사
200 OK ✅

배달 성공! 음식이 따끈따끈하게 정상 도착했어요.

404 Not Found ❓

가게나 음식이 없대요! 인터넷 주소 철자(URL)를 확인하세요.

500 Server Error 💥

식당 주방에 문제가 생겼어요! 상대방 서버 컴퓨터가 고장 난 상태예요.

3단계: 진동벨 대기 — 비동기 통신(async / await)의 비밀

인터넷 저 멀리 바다 건너 미국에 있는 서버에 데이터를 요청하면, 아무리 빛의 속도라도 0.5초에서 1초 정도 배달 시간이 걸려요!

❌ 얼음 땡 방식 (동기, Synchronous)

커피가 나올 때까지 계산대 앞에서 눈 하나 깜빡 안 하고 굳어있는 것! 화면이 꽁꽁 얼어붙어 마우스 클릭도 안 먹히고 사용자가 답답해해요.

⭕ 카페 진동벨 방식 (비동기, Asynchronous)

주문 후 진동벨(await)을 받고 다른 일을 자유롭게 하다가, 징~ 울리면 커피를 받아오는 스마트한 방식!

async와 await 한눈에 외우기
  • • async: "이 함수 안에서는 진동벨을 쓰는 배달이 있어요!"라고 미리 선언하기
  • • await: "배달이 도착할 때까지 여기서 얌전히 기다려요!"라고 멈춰 세우기

4단계: 오픈 API 보물찾기 — 전 세계가 무료로 나눠주는 데이터 뷔페

"오픈 API(Open API)"란 전 세계 개발자들과 학생들이 자유롭게 앱을 만들 수 있도록 비밀번호 없이 열어둔 무료 데이터 보물창고예요.

🌟 오늘의 명언 API api.adviceslip.com/advice 짧고 지혜로운 한 줄 인생 명언을 랜덤으로 배달!
🐶 귀여운 강아지 API dog.ceo/api/breeds/image/random 전 세계 귀여운 댕댕이 사진을 무한으로 배달!
⚡ 포켓몬 도감 API pokeapi.co/api/v2/pokemon/... 피카츄 등 수백 마리 포켓몬의 스탯과 이미지를 배달!
❌ 위험한 프롬프트 위험 
인터넷에서 명언 가져와서 보여줘.

API 주소나 에러 처리, 로딩 스피너가 없어서 통신이 실패하면 흰 화면으로 굳어버려요!

⭕ 안전한 프롬프트 (안정성 100%) 
무료 오픈 API(https://api.adviceslip.com/advice)에 fetch()를 사용해 오늘의 명언을 비동기(async/await)로 가져와줘.

1. 데이터를 불러오는 동안 로딩 중 스피너를 보여줘.
2. 네트워크 오류가 생기면 try-catch로 잡아서 친절한 재시도 안내를 띄워줘.
3. 배달이 완료되면 예쁜 카드 UI에 명언과 번호를 렌더링해줘.

로딩 표시와 오류 방어선(try-catch)을 모두 챙겨 전문가 수준의 웹앱이 완성됩니다!

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 백엔드·프론트엔드 개발자들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 오픈 API 영문: Open API (Application Programming Interface)
통신/인터페이스
🧸 어린이 비유: "누구나 마음껏 가져다 먹을 수 있도록 전 세계에 차려진 정보 뷔페 식당!"

🎓 개발자 공식 정의: 외부 개발자나 프로그램이 특정 서비스의 데이터나 기능에 표준화된 방식으로 접근하여 활용할 수 있도록 공개된 프로그래밍 인터페이스 규격입니다.

2. HTTP 요청과 응답 영문: HTTP Request & Response
웹 네트워크
🧸 어린이 비유: "손님이 식당에 건네는 주문서(요청)와 식당에서 테이블로 날라주는 맛있는 음식(응답)!"

🎓 개발자 공식 정의: 클라이언트가 특정 URI로 서버에 자원을 요구하는 HTTP 요청 메시지를 보내고, 서버가 처리 결과와 상태 코드를 담아 돌려주는 양방향 통신 모델입니다.

3. 비동기 처리 외래어·영문: 비동기 처리 (Asynchronous / async & await)
실행 엔진
🧸 어린이 비유: "음료가 나올 때까지 굳어있지 않고 진동벨을 들고 자유롭게 책을 읽으며 기다리는 스마트 카페 시스템!"

🎓 개발자 공식 정의: 시간이 걸리는 네트워크 I/O 작업 동안 메인 실행 흐름을 멈추지 않고(Non-blocking), 결과가 도착했을 때 등록된 작업을 순차 실행하는 자바스크립트 실행 메커니즘입니다.

4. 패치 API 외래어·영문: 패치 API (Fetch API)
브라우저 내장 API
🧸 어린이 비유: "자바스크립트가 다른 컴퓨터로 보내는 신속 배달 오토바이 라이더!"

🎓 개발자 공식 정의: 웹 브라우저에서 네트워크 리소스를 비동기적으로 가져오기 위해 제공하는 Promise 기반의 최신 자바스크립트 표준 통신 메서드입니다.

5. HTTP 상태 코드 외래어·영문: HTTP 상태 코드 (Status Code / 200, 404, 500)
프로토콜/검증
🧸 어린이 비유: "배달이 무사히 왔는지(200), 주소가 틀렸는지(404), 식당 주방에 불이 났는지(500)를 세 자리 숫자로 알려주는 신호등!"

🎓 개발자 공식 정의: 클라이언트의 HTTP 요청이 성공했는지, 리다이렉트되었는지, 클라이언트 또는 서버 오류가 발생했는지를 3자리 숫자로 표준화하여 나타내는 상태 식별자입니다.

6. 엔드포인트 URL 외래어·영문: 엔드포인트 URL (API Endpoint)
웹 자원 주소
🧸 어린이 비유: "원하는 메뉴(명언, 날씨, 강아지)가 준비되어 있는 인터넷 식당의 정확한 번지수 주소판!"

🎓 개발자 공식 정의: API 서버에서 특정 자원이나 기능에 접근할 수 있도록 공개해 둔 고유한 URL 경로(URI Path)입니다.

비밀 배달부 4대 핵심 공식 요약
1
fetch는 비동기 함수(async/await)와 짝꿍 배달이 올 때까지 화면이 얼지 않도록 진동벨(await)로 대기하세요.
2
response.json()으로 택배 상자 뜯기 서버에서 날아온 글자 패킷을 살아있는 자바스크립트 객체로 풀어내요.
3
200 OK 상태 코드 먼저 확인 음식이 제대로 왔는지 확인하고 404나 500 에러를 방어해요.
4
네트워크 실패를 대비해 try-catch 장착 와이파이가 끊겨도 게임이 꺼지지 않도록 친절한 에러 안내를 띄워요.
