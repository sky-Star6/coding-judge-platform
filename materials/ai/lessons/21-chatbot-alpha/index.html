AI와 대화가 오가는 첫 버전 완성 (알파 빌드)

19강에서 종이에 스케치한 '챗봇 페르소나'와 20강에서 완성한 '로컬 AI 추론 엔진'이 드디어 하나로 합체합니다! 외부 유료 API나 복잡한 열쇠 없이, 내가 말을 걸면 실시간으로 말풍선을 띄우고, 이전 대화 기록(멀티턴)까지 기억하며 티키타카가 오가는 '살아있는 첫 번째 챗봇 프로토타입(알파 빌드)'의 첫 심장 박동을 울려봅니다.

1. 동적 말풍선 렌더링

사용자와 AI의 메시지를 DOM으로 실시간 찍어내고 자동 스크롤로 바닥에 붙입니다.

2. 멀티턴 대화 기억 상자

이전 대화 내역(History Array)을 차곡차곡 누적하여 문맥을 잇는 지능형 대화를 만듭니다.

3. 3대 필수 UX 방어벽

빈 말풍선 전송 방지(trim), 응답 중 연타 방지(disabled), 새 대화 리셋을 구축합니다.

Core Principles

로컬 챗봇 알파 빌드의 3대 핵심 원리

화려한 스티커를 붙이기 전, 대화 프로그램이 멈추지 않고 끝없이 순환하게 만드는 3대 프로그래밍 기둥을 배웁니다.

1. 동적 DOM 말풍선 생성

Dynamic DOM Rendering

사용자 말풍선(우측)과 봇 말풍선(좌측)을 JavaScript로 동적 생성하여 대화창에 삽입하고, 새 메시지가 추가될 때마다 바닥으로 즉시 스크롤(scrollTop = scrollHeight)합니다.

어린이 눈높이 비유

"끝없이 늘어나는 롤페이퍼 만화책에 말풍선 스티커를 아래로 차곡차곡 이어 붙이는 것과 같아요!"

원리 02

2. 멀티턴 대화 기억 상자

Conversation History Array

AI는 이전 대화를 저절로 기억하지 못하므로, 주고받은 질문과 답변을 chatHistory 배열에 차곡차곡 보관하여 "그럼 아까 말한 건?" 같은 연속 질문에 답할 수 있게 합니다.

어린이 눈높이 비유

원리 03

3. 3대 필수 사용자 안전망

Input & UX Defensive Guards

공백만 입력하고 엔터를 칠 때 방어하는 trim(), 봇이 생각하는 동안 중복 클릭을 막는 disabled, 대화가 꼬였을 때 새로 시작하는 reset 안전망을 구축합니다.

어린이 눈높이 비유

"자동차를 달리기 전에 안전벨트를 매고, 신호등 빨간불에는 잠시 멈추는 든든한 가드레일이에요!"

주니어 개발자 원칙: 완벽한 디자인보다 '끝까지 돌아가는 한 바퀴(알파 빌드)'가 먼저입니다!

QUEST 01 DOM 렌더링 & 스크롤 ★★★

새 메시지가 오면 화면에 말풍선을 띄우고 바닥으로 자동 이동시키는 JS 렌더러 작성

사용자와 봇의 말풍선 UI를 동적으로 생성하고, 메시지가 길어져도 최신 대화가 가려지지 않게 바닥으로 스크롤을 내리는 코드를 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 웹 프론트엔드 인터랙션 전문 시니어 자바스크립트 엔지니어이자 코딩 멘토야.

[목표]
웹 브라우저 채팅창에서 사용자(우측 정렬)와 챗봇(좌측 정렬)의 말풍선을 동적으로 생성하여 추가하고, 대화창 스크롤을 자동으로 맨 바닥으로 내리는 appendMessage(sender, text) 함수를 순수 자바스크립트로 작성해 줘.

[세부 요구사항]
1. sender가 'user'면 우측 정렬(bg-indigo-600, 흰 글씨), 'bot'이면 좌측 정렬(bg-white, 캐릭터 아이콘 포함)로 분기해 줘.
2. 메시지가 화면에 삽입된 즉시 chatContainer.scrollTop = chatContainer.scrollHeight를 실행해 최신 글이 항상 보이게 해 줘.
3. DOM XSS 방지를 위해 사용자 텍스트는 textContent로 안전하게 처리해 줘.
4. 초보자도 쉽게 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 브라우저는 DOM에 새 요소를 추가한 뒤 화면을 다시 그리는 리플로우(Reflow)와 리페인트(Repaint) 과정을 거칩니다. 요소가 화면에 온전히 추가되기 전에 스크롤 위치를 계산하면 높이가 반영되지 않아 스크롤이 중간에 멈출 수 있습니다. 따라서 DOM 트리에 노드를 완전히 부착한 뒤 scrollTop = scrollHeight를 적용해야 완벽한 자동 스크롤이 작동합니다.

QUEST 02 상태 관리 & 문맥 계승 ★★★★

이전 대화를 기억하고 "방금 말한 거" 같은 지시어를 알아채는 멀티턴 기억 상자 구현

단발성 문답을 넘어 이전 질문과 답변의 맥락을 배열에 보관하고 연속된 질문을 처리하는 상태 머신 로직을 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 대화형 AI 시스템 아키텍처 전문가이자 자바스크립트 알고리즘 멘토야.

[목표]
챗봇이 이전 대화 내역을 최대 10개까지 배열로 보관하고, 사용자가 "방금 말한 거", "아까 그거" 같은 연속 질문을 던졌을 때 직전 턴의 의도(Intent)를 계승하여 대답할 수 있는 ConversationMemory 클래스를 작성해 줘.

[세부 요구사항]
1. addMessage(role, text, intent) 메서드로 메시지 객체를 차곡차곡 push하고, 10개가 넘으면 가장 오래된 메시지를 shift(FIFO)해 줘.
2. getContextIntent(currentText) 메서드를 만들어 만약 사용자의 입력에 ['방금', '아까', '그거', '다시'] 키워드가 포함되어 있다면 직전 봇 답변의 intent를 찾아 반환해 줘.
3. clear() 메서드로 기억 상자를 초기화하는 기능도 포함해 줘.
4. 초보자도 쉽게 따라할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 거대 언어 모델(LLM)이나 서버 API는 자체적으로 이전 대화를 기억하지 않는 '무상태(Stateless)' 방식으로 동작합니다. 따라서 대화가 자연스럽게 이어지는 모든 상용 챗봇은 클라이언트나 세션 저장소에서 이전 대화 이력(History Buffer)을 관리하며 매 요청마다 문맥을 함께 전달하는 구조로 설계됩니다.

QUEST 03 방어적 프로그래밍 & 안전망 ★★★

공백 입력 차단, 광클 연타 방지, 세션 리셋을 처리하는 3대 UX 방어 모듈 작성

사용자가 아무 글자도 안 치고 엔터를 누르거나 전송 버튼을 빠르게 10번 누를 때 시스템이 고장 나지 않도록 지키는 방어벽을 구축합니다.

실전 AI 복사 프롬프트 
[역할]
너는 사용자 경험(UX) 안전성과 프론트엔드 방어적 프로그래밍 전문 소프트웨어 엔지니어이자 코딩 멘토야.

[목표]
사용자의 비정상적인 돌발 행동으로부터 챗봇 시스템을 지키는 3대 안전 가드(빈 문자열 차단, 광클 연타 방지, 대화 리셋)를 순수 자바스크립트로 구현해 줘.

[세부 요구사항]
1. validateInput(text): text.trim()의 길이가 0이면 alert나 시각적 흔들림(shake) 효과와 함께 전송을 취소하는 함수 작성.
2. setGeneratingState(isGenerating): AI가 답변을 작성 중일 때(isGenerating = true) 전송 버튼을 disabled로 잠그고 입력창 포커스를 보호하는 함수 작성.
3. resetSession(): 대화창 DOM을 초기화하고 안내 인사말만 남기며 메모리 버퍼를 청소하는 함수 작성.
4. 초보자도 쉽게 이해할 수 있도록 매 줄마다 친절한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 실제 소프트웨어 개발에서는 정상적인 사용보다 사용자의 오작동이나 네트워크 딜레이 상황에서 발생하는 버그가 전체 이슈의 80% 이상을 차지합니다. 이를 사전에 차단하는 기법을 '방어적 프로그래밍(Defensive Programming)'이라 부르며, 버튼 비활성화(Debouncing)는 서버 부하와 클라이언트 충돌을 막는 가장 기본적이면서 강력한 기술입니다.

QUEST 04 비동기 인터랙션 & 딜레이 ★★★★

점 3개가 춤추는 생각 중 애니메이션과 인간미 넘치는 타이핑 지연 시뮬레이션

컴퓨터의 0.001초 즉답 대신, 사용자가 기계적이지 않게 느끼도록 자연스러운 생각 시간(0.6초~1초)을 부여하는 비동기 지연 모듈을 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 웹 프론트엔드 비동기 프로그래밍 및 마이크로 인터랙션 전문가야.

[목표]
사용자가 질문을 보낸 직후 채팅창에 "AI가 생각 중입니다... 💭" 말풍선(또는 점 3개 바운스 애니메이션)을 띄우고, 600ms~1000ms의 인위적 지연 후 실제 챗봇 답변으로 매끄럽게 교체하는 simulateBotResponseWithDelay() 비동기 함수를 작성해 줘.

[세부 요구사항]
1. Promise와 setTimeout을 활용한 sleep(ms) 헬퍼 함수를 구현해 줘.
2. 생각 중 말풍선을 임시로 화면에 추가했다가 응답이 준비되면 임시 요소를 제거하고 최종 답변 말풍선으로 치환해 줘.
3. 생각하는 동안 스크롤이 자동으로 바닥을 유지하도록 처리해 줘.
4. 초보자도 쉽게 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: HCI(인간-컴퓨터 상호작용) 연구에 따르면, AI가 0.001초 만에 답을 내놓으면 사용자는 "제대로 생각하지 않고 기계적으로 출력했다"고 느끼는 반면, 0.6초~1초의 짧은 타이핑 인디케이터가 표시되면 "내 질문을 분석하고 고민해서 답을 주었다"는 심리적 만족감(인지된 지능, Perceived Intelligence)이 크게 상승합니다.

QUEST 05 풀 아키텍처 완성 ★★★★★

렌더러, 추론 엔진, 멀티턴 기억, 안전망을 하나로 엮은 올인원 챗봇 알파 앱

20강의 추론 엔진과 21강의 대화 루프 모듈을 완벽하게 통합하여 독립 실행 가능한 하나의 완성형 알파 클래스를 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 에듀테크 웹 소프트웨어 총괄 아키텍트이자 학생들을 위한 코딩 멘토야.

[목표]
외부 라이브러리나 API 키 없이, 100% 브라우저 순수 자바스크립트로 동작하는 올인원 챗봇 알파 애플리케이션 클래스(ChatbotAlphaApp)를 작성해 줘.

[세부 요구사항]
1. 내부 상태로 messages 배열, conversationMemory 객체, isProcessing 플래그를 관리해 줘.

🧸 어린이 비유: "도화지를 통째로 새로 사지 않고, 새로운 만화 스티커를 가위로 오려 실시간으로 쏙쏙 붙이는 마법!"

🎓 개발자 공식 정의: 웹페이지를 새로고침하지 않고 JavaScript 코드를 통해 문서 객체 모델(DOM) 트리에 새로운 HTML 엘리먼트를 동적으로 생성(createElement)하고 부착(appendChild)하는 기술입니다.

4. 자동 스크롤 제어 Auto Scroll (scrollTop = scrollHeight)
🧸 어린이 비유: "새로운 글이 나타나면 손가락으로 밀지 않아도 화면이 스르륵 내려가서 바로 보여주는 마법 에스컬레이터!"

🎓 개발자 공식 정의: 컨테이너 엘리먼트의 스크롤 위치(scrollTop)를 전체 스크롤 높이(scrollHeight)로 설정하여 새로 추가된 최신 콘텐츠가 사용자 시야에 즉시 보이도록 보장하는 UI 인터랙션입니다.
