첫 심장 박동: 완벽함보다 중요한 '끝까지 돌아가는 한 바퀴'

세계적인 게임 회사나 IT 스타트업 개발자들은 제품을 만들 때 처음부터 완벽한 디자인을 꾸미지 않아요. 가장 먼저 하는 일은 "핵심 기능이 중단 없이 처음부터 끝까지 한 바퀴 도는가?"를 확인하는 것입니다. 이를 개발자들은 '알파 빌드(Alpha Build)'라고 불러요.

레고 로봇의 첫 걸음마

멋진 스티커나 도색은 아직 없지만, 모터와 배터리를 연결했을 때 로봇이 앞뒤로 쿵쾅쿵쾅 넘어지지 않고 걸어가는 순간! 그 첫 걸음마가 바로 알파 빌드예요.

2

말풍선 공장 가동: 자바스크립트로 그리는 대화창 UI

채팅창은 고정된 웹페이지가 아니에요. 사용자가 말을 걸고 AI가 답을 할 때마다 화면에 새로운 네모 상자(말풍선)가 실시간으로 쑥쑥 생겨나야 합니다. 자바스크립트의 DOM 조작을 사용하면 화면 새로고침 없이 부드럽게 만화책 대화 컷을 찍어낼 수 있어요.

USER
내 말풍선 (우측 정렬 & 보라색) justify-end

내가 쓴 글은 오른쪽에 착 붙고, 보라색 배경에 흰 글씨로 눈에 띄게 배치합니다.

BOT
챗봇 말풍선 (좌측 정렬 & 캐릭터 아바타) justify-start

왼쪽에 귀여운 캐릭터 아이콘(🐹 셰프 등)과 함께 하얀색 카드 형태로 답변을 또박또박 띄웁니다.

UX
자동 스크롤 마법 (Auto Scroll) scrollTop = scrollHeight

대화가 길어지면 새 메시지가 화면 밑으로 가려지지 않도록, 말풍선이 추가될 때마다 대화창 맨 아래로 자동 스크롤을 시켜줍니다!

3

기억 상자 조립: 이전 대화를 기억하는 멀티턴(Multi-turn) 마법

"계란으로 요리 추천해줘!" ➔ "오믈렛 어때요찍?" ➔ "그럼 양념 비율도 알려줘!"
만약 챗봇이 이전 대화를 기억하지 못한다면 "무슨 양념을 말씀하시는 거죠?"라며 엉뚱한 답을 할 거예요. 진짜 사람처럼 자연스럽게 대화가 이어지려면 대화 기억 상자(Chat History Array)가 필수입니다!

구글 Gemini에게 보내는 '눈덩이 기억 상자' 구조 contents: [ ... ]
// 이전 질문과 답변을 차곡차곡 누적해서 배열로 보냅니다!
[
  { role: 'user', parts: [{ text: '계란 요리 추천해줘' }] },
  { role: 'model', parts: [{ text: '스페인식 감자 오믈렛 어때요찍?' }] },
  { role: 'user', parts: [{ text: '그 오믈렛 소스 비율도 알려줘!' }] }
]

질문과 답변이 오갈 때마다 상자에 차곡차곡 쌓아서 구글 슈퍼컴퓨터에게 통째로 건네주면, AI가 이전 대화를 완벽히 이해하고 똑똑하게 답을 이어갑니다!

ACTION REQUIRED · 2단계 실습 미션 지금 수행할 차례!

대화를 나눴다면 우측 [기억 상자] 탭에서 대화 히스토리를 확인하세요!

AI가 내 이전 말을 잊어버리지 않게 누적 보관하는 대화 히스토리(History Array)를 확인하셨나요? 우측 콘솔의 [기억 상자] 탭에서 주고받은 role: user와 role: model 메시지 목록의 실시간 배열 구조를 관찰해 보세요!

4

알파 테스터 출동: 내 챗봇의 첫 대화 테스트 & 에러 방어

알파 빌드를 완성했다면 주니어 개발자로서 3가지 필수 방어벽을 테스트해야 합니다. 실제 사용자들이 실수로 누를 수 있는 오작동을 미리 차단해 두는 것이 멋진 프로그래머의 자세예요!

1. 빈 말풍선 방지

아무 글자도 안 쓰고 스페이스만 누른 채 엔터를 치면 전송되지 않도록 text.trim()으로 걸러냅니다.

2. 광클 연타 방지

AI가 답장을 쓰는 중에는 전송 버튼을 비활성화(disabled)하여 중복 질문 폭주를 막습니다.

3. 새 대화 청소

주제를 바꾸고 싶을 때 언제든 [🔄 새 대화] 버튼을 눌러 기억 상자와 대화창을 깔끔하게 리셋할 수 있습니다.

오늘 수업에서 배운 재미있는 원리들, 실제 컴퓨터 과학자들과 대화형 AI 개발자들은 어떤 멋진 전문 용어로 부를까요? 궁금한 친구들은 아래의 전문 지식을 돋보기로 들여다보세요!

1. 알파 버전 소프트웨어 영문: Alpha Build (Internal Milestone)
빌드/마일스톤
🧸 어린이 비유: "색칠은 아직 안 했지만 바퀴와 모터가 힘차게 돌아가는 레고 자동차 초기 모델!"

🎓 개발자 공식 정의: 핵심 기능(Core Feature)이 처음부터 끝까지 실제로 동작하는 첫 번째 내부 테스트 버전으로, 기능의 유효성을 최초로 검증하는 초기 개발 마일스톤 빌드입니다.

2. 다중 턴 대화 문맥 외래어·영문: 멀티턴 컨텍스트 (Multi-turn Context Window)
대화 상태 관리
🧸 어린이 비유: "앞서 나눈 이야기들을 까먹지 않고 머릿속에 기억해 둔 채 대화를 자연스럽게 이어가는 능력!"

🎓 개발자 공식 정의: 이전의 질문과 답변 기록(Chat History)을 배열 형태로 보존하고 다음 API 호출 시 함께 전송하여, LLM이 앞선 대화의 문맥(Context)을 이해하고 답변하도록 돕는 연속 대화 기법입니다.

3. 동적 화면 조작 외래어·영문: 돔 조작 (DOM Manipulation)
프론트엔드/DOM
🧸 어린이 비유: "만화책 종이에 새로운 캐릭터 말풍선 스티커를 착착 붙여 페이지를 생생하게 늘려가는 마법!"

🎓 개발자 공식 정의: 자바스크립트를 사용하여 웹 브라우저의 HTML 문서 객체 모델(DOM Tree)에 새로운 노드(말풍선 등)를 생성(createElement), 삽입(appendChild), 수정하는 동적 UI 제어 기법입니다.

4. 자동 스크롤 내리기 영문: Auto-scroll to Bottom (Scroll Anchoring)
채팅 UI/인터랙션
🧸 어린이 비유: "긴 영수증이 기계에서 출력될 때, 방금 찍힌 맨 밑 글자가 보이도록 종이를 스르륵 내려주는 센서!"

🎓 개발자 공식 정의: 채팅 메시지가 새로 추가될 때 사용자의 수동 조작 없이도 스크롤 위치를 대화창의 맨 아래(scrollTop = scrollHeight)로 자동 이동시켜 최신 발화를 즉각 시야에 노출하는 인터랙션 제어입니다.

5. 동시 입력 방지 가드 외래어·영문: 디바운스 & 방어 가드 (Request Guard)
안전성/방어코드
🧸 어린이 비유: "엘리베이터 문이 닫히는 중에는 닫힘 버튼을 아무리 백 번 눌러도 안전하게 한 번만 출발시키는 가드!"

🎓 개발자 공식 정의: 비동기 네트워크 요청이 진행 중일 때 추가 클릭이나 엔터 입력을 잠금(isPending = true) 처리하여 불필요한 중복 호출과 시스템 혼선을 원천 차단하는 상태 제어 기법입니다.

6. 대화 기록 초기화 영문: Session Reset & State Flush
세션/메모리
🧸 어린이 비유: "스케치북을 다 쓰면 지우개로 깨끗이 지우거나 새 도화지를 꺼내어 새로운 그림을 그리는 것!"

🎓 개발자 공식 정의: 메모리에 저장된 대화 히스토리 배열과 UI 메시지 트리를 초기 상태로 리셋하여, 이전 대화의 간섭 없이 새로운 세션을 시작하는 상태 관리 메커니즘입니다.
