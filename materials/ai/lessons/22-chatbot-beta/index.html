QUEST 01 Web Speech API · 음성 합성 ★★★

외부 라이브러리 없이 순수 브라우저 Web Speech TTS 한국어 음성 출력 함수 작성

챗봇이 작성한 답변 텍스트를 사람이 또박또박 읽어주듯 스피커로 출력하는 SpeechSynthesisUtterance 연동 모듈을 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 웹 프론트엔드 멀티미디어 인터랙션 전문 시니어 자바스크립트 엔지니어이자 코딩 멘토야.

[목표]
외부 유료 API나 라이브러리 없이, 100% 브라우저 내장 Web Speech API를 활용해 한국어 음성을 스피커로 또박또박 재생하는 speakText(text, options) 함수를 순수 자바스크립트로 작성해 줘.

[세부 요구사항]
1. window.speechSynthesis와 SpeechSynthesisUtterance 객체를 활용해 줘.
2. 언어 설정(lang = 'ko-KR'), 말하기 속도(rate, 기본 1.0), 목소리 높낮이(pitch, 기본 1.0)를 옵션으로 제어할 수 있게 해 줘.
3. 이미 이전 음성이 재생 중이라면 speechSynthesis.cancel()을 먼저 호출해 목소리가 겹치지 않도록 깔끔하게 처리해 줘.
4. 브라우저가 음성 합성을 지원하지 않을 때의 예외 방어 로직을 포함해 줘.
5. 초보자도 쉽게 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: Web Speech API는 운영체제(Windows, macOS, Android, iOS)에 내장된 음성 합성 엔진(TTS Engine)을 브라우저가 직접 호출하는 W3C 웹 표준 기술입니다. 클라우드 서버로 오디오 파일을 주고받지 않고 사용자의 기기 CPU에서 직접 소리를 생성하므로 네트워크 데이터 비용이 0원이며 지연 시간(Latency) 없이 즉각 재생됩니다.

QUEST 02 마이크로 인터랙션 · 토스트 ★★★

화면 중앙을 가리지 않고 2초 뒤 스르륵 사라지는 비간섭 플로팅 토스트 컴포넌트

웹 사용성을 저해하는 구식 alert()를 대체하여, 화면 하단에서 부드러운 애니메이션과 함께 상태를 알리는 토스트 UI를 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 UI/UX 인터랙션 전문 시니어 프론트엔드 엔지니어이자 코딩 멘토야.

[목표]
사용자의 작업을 방해하지 않는 모던 플로팅 토스트 알림창(Floating Toast Notification)을 순수 자바스크립트와 CSS(또는 Tailwind)로 구현하는 showToast(message, duration = 2000) 함수를 작성해 줘.

[세부 요구사항]
1. 화면 하단 중앙(fixed bottom-6 left-1/2 -translate-x-1/2)에 위치시키고 부드러운 슬라이드 업 & 페이드인 효과를 줘.
2. 여러 번 연속 호출되더라도 이전 타이머를 clear하고 새 메시지로 갱신하는 디바운스/타이머 가드를 적용해 줘.
3. 지정된 시간(기본 2초)이 지나면 페이드아웃 효과와 함께 DOM에서 사라지게 해 줘.
4. 초보자도 바로 웹페이지에 적용할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: alert() 창은 브라우저의 메인 자바스크립트 스레드를 일시 정지(Blocking)시키는 모달 방식이라 사용자 경험을 크게 해칩니다. 반면 플로팅 토스트는 스레드를 차단하지 않는 비동기 논블로킹(Non-blocking) 방식으로 동작하여 사용자가 타이핑이나 스크롤을 멈추지 않고도 실시간 상태 피드백을 전달받을 수 있습니다.

QUEST 03 클립보드 API · 사용성 배려 ★★★

말풍선마다 1-Click 복사 버튼을 달고 클립보드에 안전하게 담는 복사 핸들러 작성

긴 레시피나 학습 요약을 일일이 드래그할 필요 없이 버튼 한 번으로 복사하고 시각적 완료 피드백을 주는 코드를 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 클립보드 인터랙션 및 프론트엔드 보안 전문가이자 코딩 멘토야.

[목표]
챗봇 말풍선 카드 안에 [📋 복사하기] 버튼을 부착하고, 클릭 시 해당 말풍선의 텍스트를 navigator.clipboard.writeText를 통해 사용자의 클립보드에 복사하며 버튼 아이콘을 체크 표시(✓)로 1.8초간 피드백하는 copyBubbleContent(buttonEl) 함수를 작성해 줘.

[세부 요구사항]
1. 현대적인 비동기 navigator.clipboard API를 우선 사용하고, 보안 컨텍스트(HTTPS/localhost)가 아닐 경우의 document.execCommand 폴백도 안전하게 처리해 줘.
2. 복사 완료 즉시 버튼 텍스트를 '복사됨! ✨'으로 바꾸고 1.8초 후 원래 모양으로 복구해 줘.
3. 2번 퀘스트의 showToast와 연계하여 화면 아래에 토스트가 동시에 뜨도록 연결해 줘.
4. 초보자도 쉽게 따라할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 클립보드 접근은 사용자의 비밀번호나 개인정보를 탈취할 수 있는 민감한 권한이므로, 브라우저는 반드시 사용자의 직접적인 클릭(User Gesture) 이벤트 내부에서만 navigator.clipboard.writeText 호출을 허용합니다. 이러한 보안 규칙을 '사용자 활성화(User Activation)' 모델이라고 부릅니다.

QUEST 04 디자인 시스템 · 테마 동기화 ★★★★

캐릭터 페르소나에 맞춰 색상과 아바타가 살아 움직이는 동적 테마 스위처

셰프 챗봇(오렌지/에메랄드), 스터디 챗봇(인디고), 스토리 챗봇(바이올렛)으로 챗봇 룸의 분위기를 0.1초 만에 전환하는 테마 모듈을 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 프론트엔드 디자인 시스템 및 CSS 변수 아키텍처 전문가야.

[목표]
챗봇의 캐릭터 페르소나(셰프, 스터디봇, 스토리텔러)를 선택할 때마다 채팅창의 대표 색상(Primary Color), 아바타 아이콘, 헤더 타이틀을 실시간으로 변경하는 ThemeManager 모듈을 작성해 줘.

[세부 요구사항]
1. CSS Custom Properties(--theme-primary, --theme-bg 등) 또는 Tailwind 클래스를 동적으로 변경해 줘.
2. 사용자가 선택한 테마 설정을 localStorage에 저장하여 새로고침 후에도 유지되도록 해 줘.
3. 테마가 바뀔 때 환영 메시지와 봇 소개 텍스트도 캐릭터 성격에 맞게 갱신해 줘.
4. 초보자도 쉽게 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: CSS 커스텀 프로퍼티(변수, CSS Variables)를 사용하면 자바스크립트로 HTML 구조를 일일이 뜯어고치지 않고도 최상위 DOM 요소의 속성값 하나만 변경하여 전체 UI의 색상 테마를 한 번에 리렌더링할 수 있습니다. 이것이 넷플릭스나 디스코드의 다크 모드/테마 엔진의 기본 아키텍처입니다.

QUEST 05 풀옵션 아키텍처 완성 ★★★★★

추론 두뇌, 음성 TTS, 플로팅 토스트, 테마 시스템이 통합된 완성형 챗봇 베타 코어

20강의 인텐트 추론 두뇌와 21강의 멀티턴 대화 루프, 22강의 사포질 폴리싱을 집대성한 올인원 클래스를 소환합니다.

실전 AI 복사 프롬프트 
[역할]
너는 에듀테크 상용 소프트웨어 총괄 아키텍트이자 학생들을 위한 코딩 멘토야.

[목표]
외부 유료 의존성 없이, 100% 브라우저 순수 자바스크립트로 구동되는 완성형 챗봇 베타 애플리케이션 클래스(ChatbotBetaApp)를 작성해 줘.

[세부 요구사항]
1. 내부 상태로 messages, conversationHistory, currentTheme, isProcessing, ttsEnabled를 관리해 줘.
