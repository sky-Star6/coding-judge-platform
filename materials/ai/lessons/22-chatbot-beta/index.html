1

베타 빌드 깃발 꽂기: 친구에게 보여줄 수 있는 '완성도 90%의 마법'

알파 빌드가 "기능이 처음부터 끝까지 멈추지 않고 돌아가는가?"를 증명하는 단계였다면, 베타 빌드(Beta Build)는 "누가 써도 편안하고 친절한 완성도인가?"를 갖추는 단계예요. 실제 사용자(친구, 가족, 선생님)에게 제품을 공개하기 전 마지막 완성도를 채우는 필수 관문입니다.

놀이공원 사전 시승회 (프리오픈)

정식 개장 전, 반짝이는 도색과 안전벨트, 편안한 대기석까지 모두 설치하고 특별 초대권을 가진 VIP 손님들을 모셔 시승해보는 단계가 바로 베타 빌드예요!

알파에서 베타로 도약하는 3대 날개

1) 답변 음성 읽어주기(TTS) ➔ 2) 1초 복사 토스트 ➔ 3) 예외 상황 안내창! 이 3가지만 붙여도 조잡한 실습 코드가 진짜 서비스 앱으로 환골탈태합니다.

한눈에 비교하는 알파(21강) vs 베타(22강)
Build Evolution
21강 알파 빌드 (Alpha)
  • 핵심 대화 루프만 간신히 돌아감
  • 오류가 나면 콘솔에만 빨간 글씨 출력
  • 단순 텍스트 눈으로만 읽기 가능
22강 베타 빌드 (Beta) ✨
  • 귀로 듣는 브라우저 TTS 음성 합성 탑재
  • 클립보드 1-Click 복사 & 플로팅 토스트
  • 오프라인 감지 및 에러 회복 안내창 완비
2

사포질과 광택: 반응형 레이아웃과 감성 마이크로 인터랙션

목공소에서 거친 나무판자를 부드러운 사포로 슥슥 문지르면 만지고 싶은 매끄러운 가구가 되듯, 웹 개발에서도 소프트웨어 폴리싱(Polishing)을 거치면 사용자가 앱을 쓸 때 감탄이 터져 나와요!

토스트 알림창 (Toast Notification)

사용자의 화면을 가로막는 무식한 경고창(alert()) 대신, 화면 하단에서 빵처럼 뿅 올라왔다가 2초 뒤 스르륵 사라지는 세련된 플로팅 토스트를 적용합니다.

말풍선 개별 복사 버튼

AI가 작성해 준 좋은 레시피나 공부 요약을 마우스로 길게 드래그할 필요 없이, 말풍선 우측 상단의 작은 복사 아이콘만 누르면 즉시 스마트폰이나 PC 클립보드에 담기게 합니다.

캐릭터별 감성 테마 동기화

햄스터 셰프는 따뜻한 주황빛, 숙제 요정은 지적인 남색, 펫 번역기는 다정한 민트색으로 캐릭터를 바꿀 때마다 챗봇 룸의 테마 액센트가 살아 숨 쉽니다!

3

성우 마이크 장착: 브라우저 음성 합성(Web Speech TTS)

챗봇이 텍스트로만 말하면 심심하죠! 현대의 모든 최신 웹 브라우저에는 사람의 목소리로 글자를 또박또박 읽어주는 Web Speech API(음성 합성 엔진)가 기본으로 내장되어 있어요. 별도의 유료 도구 없이도 자바스크립트 단 3줄이면 챗봇에게 성우 마이크를 쥐어줄 수 있습니다!

단 3줄로 끝내는 브라우저 한국어 음성 출력 마법 Web Speech API
// 1. 읽을 글자와 한국어(ko-KR) 언어 설정
const speech = new SpeechSynthesisUtterance(botReplyText);
speech.lang = 'ko-KR';
// 2. 브라우저 스피커로 소리 출력!
window.speechSynthesis.speak(speech);
♿ 웹 접근성(a11y)의 감동: 눈이 침침하신 할머니나 글을 아직 잘 모르는 어린 동생도 귀로 챗봇과 즐겁게 대화할 수 있는 따뜻한 기술이에요.

말풍선 소리 읽어주기(Web Speech API), 원클릭 답변 복사, 실시간 대화 초기화 3대 편의 기능을 점검할 시간입니다! 우측 콘솔의 [기능 점검소] 탭에서 기능별 스위치를 켜고 끄며 베타 품질을 완성하세요!

4

마지막 버그 사냥: 끊김과 오작동을 막는 3대 안전 에어백

베타 버전의 마지막 임무는 뜻밖의 돌발 상황에서도 앱이 멈추지 않는 '우아한 실패 처리(Graceful Degradation)'를 탑재하는 것입니다.

1. 오프라인 자동 감지

와이파이가 끊기면 화면 상단에 "인터넷 연결을 확인해 주세요" 안내 바를 띄우고 전송 버튼을 안전하게 잠급니다.

2. API 에러 친절 번역

영어 외계어 오류 대신 "잠시 요청이 많아요. 5초 뒤 다시 물어봐줘찍!"처럼 캐릭터의 말투로 친절하게 설명합니다.

3. 긴 문장 넘침 방지

사용자가 띄어쓰기 없이 수백 자를 써도 말풍선 밖으로 글자가 삐져나오지 않도록 break-words를 적용합니다.
