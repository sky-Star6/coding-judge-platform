기본 방어 ★☆☆

데이터를 불러오는 동안 로딩 상태를 켜고, 오류 발생 시 안전하게 포획하며, 성공/실패 여부와 무관하게 finally에서 로딩을 종료하는 표준 함수를 요청합니다.

실전 AI 복사 프롬프트
[역할] 너는 웹 프론트엔드 안정성과 사용자 경험(UX)을 담당하는 시니어 엔지니어이자 친절한 코딩 코치야. [목표] REST API를 호출할 때 브라우저가 하얗게 멈추거나 먹통이 되지 않도록 지켜주는 비동기 통신 표준 함수 fetchSafeData(apiUrl)를 자바스크립트로 작성해 줘. [세부 요구사항] 1. isLoading(로딩 중 여부), error(에러 객체 또는 메시지), data(정상 수신 결과)의 3가지 상태 변수를 정의해 줘. 2. try 블록에서 fetch와 response.ok를 검증하고, !response.ok일 경우 throw new Error를 던져 catch로 넘기게 만들어 줘. 3. catch 블록에서는 에러 메시지를 한국어로 정제하여 error 상태에 저장해 줘. 4. finally 블록에서는 성공하든 실패하든 무조건 isLoading = false를 보장하게 작성해 줘. 5. 초보자도 쉽게 이해할 수 있도록 매 줄마다 상세한 한국어 주석을 달아줘.

QUEST 03 AbortController 타임아웃 가드
통신 제어 ★★☆

서버가 응답하지 않을 때 무한 대기를 차단하는 5초 타임아웃(Timeout) 가드 구현

자바스크립트의 표준 fetch는 기본적으로 무한정 대기할 수 있습니다. AbortController를 결합해 지정 시간 내 응답이 없으면 연결을 끊고 안전한 안내를 띄우는 기법을 배웁니다.

실전 AI 복사 프롬프트
[역할] 너는 네트워크 통신 최적화와 결함 내성(Fault Tolerance) 시스템을 구축하는 웹 아키텍트야. [상황 및 문제점] 브라우저의 fetch() 함수는 서버가 먹통이거나 응답을 주지 않을 때 기본적으로 타임아웃 제한이 없어서 사용자가 몇 분 동안 영원히 뺑글이 스피너만 쳐다보게 될 위험이 있어. [요청 사항] 1. 자바스크립트 표준 AbortController와 setTimeout을 결합한 fetchWithTimeout(url, options, timeoutMs = 5000) 유틸리티 함수를 작성해 줘. 2. 5초가 지나면 controller.abort()를 실행해 HTTP 요청을 강제로 중단시키고, catch 블록에서 AbortError인지 판별하는 방법을 알려줘. 3. 요청이 5초 전에 정상 성공하면 clearTimeout을 호출해 불필요한 메모리 누수를 방지하는 클린업 로직을 포함해 줘. 4. 모든 코드에 매 줄마다 상세한 한국어 주석을 달아줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: AbortController는 DOM과 브라우저 통신 전반에 취소 신호를 브로드캐스트하는 웹 표준 API입니다. 신호가 전달되면 브라우저는 즉시 소켓 연결을 닫아 불필요한 배터리 소모와 데이터 낭비를 막습니다.

QUEST 04 친절한 Fallback 카드 & 원클릭 복구
UX 복원력 ★★★

상황별 에러 코드(404, 500, Offline) 맞춤형 친절한 Fallback 안내창 및 재시도 함수 설계

영문 에러 메시지 노출을 엄격히 금지하고, 사용자가 이해하기 쉬운 한국어 설명과 따뜻한 아이콘, 그리고 페이지 새로고침 없이 즉시 재호출하는 [다시 시도] 메커니즘을 구축합니다.

실전 AI 복사 프롬프트
[역할] 너는 에러 상태의 회복 탄력성(Resilience)과 친화적 UX를 연구하는 프로덕트 디자이너이자 웹 프론트엔드 개발자야. [상황] API 통신 중 오류가 발생했을 때 사용자에게 영문 빨간 글씨(TypeError: Failed to fetch at line 42 등)를 보여주지 않고, 친절한 Fallback 안내 컴포넌트를 띄우려고 해. [요청 사항] 1. 에러 유형 3가지(오프라인 와이파이 단절, 404 데이터 미발견, 500 서버 일시 장애)에 따라 제목, 쉬운 한국어 설명, 아이콘을 분기하는 ErrorFallback({ errorType, onRetry }) 컴포넌트를 만들어 줘. 2. 컴포넌트 하단에 [🔄 다시 시도하기] 버튼을 배치하고, 클릭 시 로딩 스피너를 켜며 이전 실패한 API를 즉시 재호출하는 연결 코드를 작성해 줘. 3. 실패 횟수에 따라 지수 백오프(Exponential Backoff: 1초, 2초, 4초) 지연을 두고 자동 재시도하는 실무 팁을 한 줄로 요약해 줘.
AI 소환 마법 & 💡 컴퓨터 과학 비밀 해설

💡 컴퓨터 과학 비밀: 점진적 기능 저하(Graceful Degradation) 원칙은 일부 부품(서버 통신)이 고장 나더라도 시스템 전체가 폭발하지 않고 안전하게 멈추거나 대체 모드로 작동하도록 설계하는 소프트웨어 공학의 핵심 규격입니다.

실전 AI 복사 프롬프트
[역할] 너는 모바일 웹 앱과 PWA(Progressive Web Apps) 통신 인프라를 전담하는 웹 플랫폼 엔지니어이자 교육자야. [목표] 사용자의 기기가 와이파이나 모바일 네트워크에 연결되어 있는지 실시간으로 모니터링하는 NetworkStatusMonitor 코드를 작성해 줘. [세부 요구사항] 1. navigator.onLine 불리언 속성을 확인하여 최초 연결 상태를 감지하는 로직을 작성해 줘. 2. window.addEventListener('online', ...) 및 window.addEventListener('offline', ...) 이벤트 리스너를 등록해 줘. 3. 와이파이가 끊기면 화면 상단에 빨간색 '현재 오프라인 상태입니다' 알림 바를 슬라이드 다운으로 띄우고, 다시 복구되면 초록색 '온라인으로 복귀했습니다' 배너를 3초간 띄운 후 사라지게 해 줘. 4. 리액트 useEffect 훅 또는 바닐라 자바스크립트에서 이벤트 리스너를 해제(clean-up)하는 방법도 설명해 줘.

1. 네트워크 지연 시간 Network Latency (Round Trip Time)
🧸 어린이 비유: "배달 주문을 넣었을 때 배달 오토바이가 신호등에 걸려 도착할 때까지 걸리는 째깍째깍 기다림 시간!"

🎓 개발자 공식 정의: 데이터 패킷이 출발지(클라이언트 브라우저)에서 목적지(API 서버)로 전송되어 다시 응답을 받아 돌아올 때까지 소요되는 왕복 지연 시간(RTT)을 뜻합니다.

2. 회전 로딩 표시기 Loading Spinner (Activity Indicator)
🧸 어린이 비유: "컴퓨터가 쉬지 않고 열심히 달리고 있다고 알려주려고 빙글빙글 돌아가는 안심 바람개비!"

🎓 개발자 공식 정의: 백그라운드 비동기 작업(I/O, 네트워크 통신)이 진행 중임을 사용자에게 시각적으로 알려주어, 앱이 멈추거나 먹통이 된 것이 아님을 안내하는 애니메이션 인디케이터입니다.

3. 스켈레톤 화면 구조 Skeleton Screen (Placeholder Loading UI)
🧸 어린이 비유: "진짜 그림을 채우기 전에 스케치북에 연필로 먼저 슥슥 밑그림 윤곽선을 잡아두는 뼈대 스케치!"

🎓 개발자 공식 정의: 콘텐츠가 로드되는 동안 실제 UI 컴포넌트의 레이아웃 형태를 모방한 연회색 박스를 깜빡이며 먼저 보여줌으로써 레이아웃 흔들림(CLS)을 막고 체감 대기 시간을 심리적으로 단축시키는 화면 설계 기법입니다.

4. 예외 방어 블록 Exception Handling (try-catch-finally Defense)
🧸 어린이 비유: "스케이트보드를 탈 때 무릎 보호대와 헬멧을 차서 넘어져도 다치지 않고 툭툭 털고 일어나는 안전 장비!"

🎓 개발자 공식 정의: 런타임에 발생할 수 있는 잠재적 오류(예외, Exception)를 try 블록으로 감싸서 시스템 중단을 방지하고, catch 블록에서 안전한 후속 조치를 취하며, finally에서 정리 작업을 보장하는 방어 문법입니다.

5. 대체 안내 화면 Fallback UI & Graceful Degradation
🧸 어린이 비유: "자판기 음료수가 다 떨어졌을 때 그냥 돈을 삼키는 대신 '품절' 불을 켜고 돈을 돌려주는 친절한 자판기 안내판!"

🎓 개발자 공식 정의: 주요 기능이나 원본 데이터 수신이 실패했을 때, 전체 시스템이 백지로 깨지는 대신 사용자에게 친절한 에러 메시지와 재시도 버튼을 제공하여 서비스 지속성을 유지하는 점진적 기능 저하 설계입니다.
