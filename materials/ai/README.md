# AI·코딩 장기 교육과정 설계

중학생 이상을 대상으로 하는 주 1회·회당 2시간·24주 과정의 설계 문서다. 코딩을 처음 접하는 학생도 참여할 수 있으며, 경험자는 각 주차의 확장 미션으로 난도를 높인다.

이 단계에서는 HTML, CSS, JavaScript를 만들지 않는다. 아래 문서를 기준으로 교육 내용을 확정한 뒤 Antigravity CLI가 실제 온라인 교재를 구현한다.

## 문서 구성

- [01-curriculum.md](./01-curriculum.md): 교육 철학, 전체 로드맵, 24주 상세 수업안
- [02-content-architecture.md](./02-content-architecture.md): 온라인 교재의 정보 구조와 교사·학생 콘텐츠 분리
- [03-final-project.md](./03-final-project.md): 최종 프로젝트 단계, 평가 기준, 발표 운영
- [04-antigravity-handoff.md](./04-antigravity-handoff.md): Antigravity CLI에 전달할 단계별 제작 명세

## 과정의 핵심 경험

모든 학생은 반복해서 다음 흐름을 경험한다.

> 문제 발견 → 문제 정의 → 아이디어 구체화 → 요구사항 작성 → AI에 작업 지시 → 코드 생성 → 실행 → 테스트 → 오류 분석 → 수정 → 개선 → 완성 → 발표

AI의 답은 정답지가 아니라 검토할 초안으로 다룬다. 수업의 기본 루프는 `AI 생성 → 직접 확인 → 실행 → 테스트 → 오류 발견 → 오류 설명 → 수정 → 재테스트`다.

## 운영 원칙

- 특정 유료 AI 서비스 가입을 필수로 요구하지 않는다.
- 무료로 이용 가능한 AI 도구, 무료 API 또는 Codex CLI를 선택지로 제공한다.
- API 키가 필요한 실습에는 키 없이 가능한 대체 실습을 함께 제공한다.
- 학생에게 Antigravity CLI 사용을 요구하지 않는다. Antigravity는 교재 제작 도구다.
- 개인정보, 비밀번호, API 키를 프롬프트나 코드 저장소에 넣지 않는다.
- 설명보다 제작 시간을 길게 두고, 매주 작더라도 실행 가능한 결과물을 남긴다.

## 역할

- 교사: 교육과정의 최종 결정, 수업 진행, 안전 관리, 학생 피드백
- Hermes Agent: 교육과정 및 주차 콘텐츠 설계, 실습·미션·프롬프트 구성, 제작 작업 관리
- Antigravity CLI: 확정된 설계를 HTML 기반 온라인 교재로 구현
- 학생: 문제를 정의하고 AI와 협업하며 결과를 직접 실행·검증·개선
