과정의 핵심 경험: AI 협업 개발 루프

본 과정에서 AI의 답변은 정답지가 아니라 ‘검토하고 개선해야 할 초안’입니다. 모든 학생은 매 학습마다 다음의 8단계 개발 루프를 반복하며 스스로 검증하는 힘을 기릅니다.

문제 발견 → 문제 정의 → 아이디어 구체화 → 요구사항 작성 → AI에 작업 지시 → 코드 생성 → 실행 & 테스트 → 오류 분석 & 개선

24주 단계별 로드맵 (Roadmap)

단계별 학습 목표에 따라 구성된 24주 커리큘럼입니다. 현재 1과 2 교재가 제공되며, 3부터 24까지는 순차적으로 준비 중입니다.

1단계: AI 리터러시와 프롬프트 (1~4)
기초 탐구
1 학습 가능

AI는 무엇을 잘하고 무엇을 틀릴까

생성형 AI의 확률적 생성 원리와 환각 현상을 이해하고, AI 답변을 비판적으로 검증하는 방법을 배웁니다.

1 학습 시작하기 →
2 잠김

좋은 질문이 좋은 결과를 만든다

목적, 대상, 조건, 출력 형식을 명확히 포함하여 프롬프트 품질을 개선하는 기법을 실습합니다.

3 준비 중

문제를 작은 작업으로 나누기

큰 프로젝트를 5개 이하의 단위 작업과 완료 조건으로 분해하는 요구사항 분석을 연습합니다.

4 준비 중

생성, 검증, 개선의 반복

평가 기준을 먼저 세우고 구체적인 피드백을 통해 AI 결과물을 점진적으로 개선합니다.

2단계: 웹 코딩 기초 (5~9)
웹 기술
5 준비 중

웹페이지의 뼈대, HTML

의미에 맞는 시맨틱 태그(Semantic Tag)를 이해하고 웹페이지의 뼈대를 직접 만듭니다.

6 준비 중

CSS로 읽기 좋은 화면 만들기

박스 모델(Box Model), 색 대비, 레이아웃을 통해 가독성 높은 반응형 카드를 만듭니다.

7 준비 중

JavaScript로 반응하는 페이지

변수, 함수, 이벤트(Event)를 연결하여 사용자 클릭에 동작하는 웹페이지를 작성합니다.

8 준비 중

조건과 반복으로 퀴즈 만들기

조건문(if/else)과 배열(Array)을 이용해 3문항 퀴즈와 자동 채점 로직을 구현합니다.

9 준비 중

미니 웹 프로젝트 통합

HTML, CSS, JavaScript를 하나로 통합하여 작은 완성형 웹 애플리케이션을 제작합니다.

3단계: AI 협업 개발 (10~14)
실전 협업
10 준비 중

요구사항 명세서 작성하기

AI가 오해하지 않고 정확한 코드를 작성하도록 입력·처리·출력 명세를 작성합니다.

11 준비 중

AI에게 코드 요청하고 읽기

생성된 코드의 구조를 읽고, 위험 요소나 오작동을 찾아 부분 수정을 요청합니다.

12 준비 중

Codex CLI와 터미널 환경

명령줄 인터페이스(CLI)를 통해 로컬 환경에서 도구를 제어하고 안전하게 실행합니다.

13 준비 중

디버깅과 오류 추적

브라우저 개발자 도구 콘솔의 오류 메시지를 분석하고 AI에게 디버깅을 지시합니다.

14 준비 중

단위 테스트와 자동 검증

정상 입력, 경계값, 비정상 입력에 대해 코드가 올바르게 작동하는지 테스트합니다.

4단계: 프로젝트와 에이전트 (15~18)
데이터 & 에이전트
15 준비 중

외부 데이터와 API 다루기

날씨, 뉴스 등 공개 API(Open API) 또는 키 없는 로컬 JSON 데이터를 연동합니다.

16 준비 중

프롬프트 체이닝과 워크플로우

이전 작업의 출력을 다음 작업의 입력으로 연결하는 연속 프롬프트 흐름을 설계합니다.

17 준비 중

에이전트 역할 분담과 파이프라인

기획자, 개발자, 검토자 역할을 나누어 다중 에이전트(Multi-agent) 협업을 구현합니다.

18 준비 중

포트폴리오 뼈대 잡기

최종 프로젝트를 시작하기 전, 지금까지 배운 내용을 정리할 포트폴리오를 준비합니다.

5단계: 최종 프로젝트 스튜디오 (19~24)
실전 프로젝트
19 준비 중

제안 승인 게이트

사용자, 해결할 문제, 핵심 가치를 정의하고 프로젝트 제안서를 승인받습니다.

20 준비 중

설계 승인 게이트

화면 와이어프레임과 필수 기능, 완료 조건, 데이터 구조를 확정합니다.

21 준비 중

알파(Alpha) 게이트

핵심 사용자 흐름 하나가 처음부터 끝까지 끊김 없이 동작하도록 구현합니다.

22 준비 중

베타(Beta) 게이트

필수 기능 및 예외 처리를 완성하고 버그 수정 기록을 작성합니다.

23 준비 중

출시 후보(RC) 게이트

동료 사용자 테스트를 거쳐 발견된 피드백을 반영하고 안정성을 검증합니다.

24 준비 중

최종 발표 및 쇼케이스

라이브 데모, AI 협업 기록, 문제 해결 증거, 한계와 회고를 공유합니다.

안전 수칙 및 윤리 가이드라인 (Safety & Ethics)

본 교육과정에서는 안전하고 책임감 있는 AI 활용을 위해 다음 4대 원칙을 철저히 준수합니다.

개인정보 보호

실명, 전화번호, 학교명, 집 주소, 계정 비밀번호는 AI 프롬프트나 코드에 절대 입력하지 않습니다. 항상 가상의 데이터(홍길동, 010-0000-0000 등)를 사용합니다.

비밀 키(API Key) 보안

유료 API 키를 학생 코드나 깃허브(GitHub) 등 공개 저장소에 올리지 않습니다. 본 과정은 키 없이 작동하는 대체 방식을 우선 지원합니다.

AI 답변 비판적 검증

AI는 그럴듯하지만 완전히 틀린 정보(환각, Hallucination)를 생성할 수 있습니다. AI의 코드는 반드시 직접 실행하고 2개 이상의 근거로 검증합니다.

저작권 및 라이선스 준수

타인의 코드, 이미지, 텍스트를 무단 복제하지 않으며, 오픈소스 라이선스(MIT, CC BY 등)의 출처 표기 규칙을 지킵니다.

도구 선택지 및 오프라인 대체 경로 (Fallback Paths)

학생들의 다양한 컴퓨터 환경과 네트워크 상황을 고려하여 특정 유료 서비스 가입 없이도 100% 실습 가능한 대체 경로를 기본 제공합니다.

구분 기본 권장 도구 설치/네트워크 불가 시 대체 경로
AI 협업 무료 웹 AI 서비스 (ChatGPT Free, Claude Free, Copilot) 수업용 사전 제공 오프라인 프롬프트-응답 데이터셋 카드 활용
코드 작성 VS Code (Visual Studio Code) 또는 기본 메모장 웹 브라우저 내장 개발자 도구 (Console) 또는 온라인 웹 에디터
데이터 연동 공개 REST API (날씨, 미세먼지 등) API 키가 전혀 필요 없는 로컬 샘플 data.json 파일
결과물 저장 브라우저 로컬 스토리지 (Local Storage) 마크다운(.md) 및 JSON 파일 직접 다운로드

최종 프로젝트 스튜디오 안내 (19~24)

최종 프로젝트는 단순히 긴 코드를 작성하는 것이 아니라, 학생이 직접 정의한 실제 문제를 AI와 협업하여 해결하는 프로젝트입니다.

학습 통과 게이트(Gate) 핵심 통과 기준
19 제안 승인 사용자·문제·선택 이유·핵심 가치가 명확히 정의되었는가?
20 설계 승인 핵심 사용자 흐름, 와이어프레임, 필수 기능, 완료 조건이 마련되었는가?
21 알파 (Alpha) 핵심 사용자 흐름 하나가 오류 없이 처음부터 끝까지 작동하는가?
22 베타 (Beta) 필수 기능과 예외 처리(에러 핸들링)가 구현되고 버그 추적표가 있는가?
23 출시 후보 (RC) 실제 사용자 테스트를 거쳐 발견된 문제를 수정하고 재검증했는가?
24 최종 발표 라이브 데모, AI 협업 기록, 테스트 증거, 한계와 회고를 공유했는가?
