8단계 AI 협업 개발 루프

본 과정에서 AI의 답변은 정답지가 아니라 ‘검토하고 개선해야 할 초안’입니다. 모든 학생은 매 강마다 다음의 8단계 개발 루프를 반복하며 스스로 비판적으로 사고하고 검증하는 힘을 기릅니다.

1

1. 문제 발견

일상 속의 진짜 불편함이나 주변 친구들이 겪는 비효율적인 상황을 포착합니다.

2

2. 문제 정의

누가 쓸 것인지, 기대하는 핵심 가치와 입력·출력 데이터가 무엇인지 명확히 좁힙니다.

3

3. 아이디어 구체화

화면 구조와 버튼 배치, 스토리 전개 및 게임 룰을 종이나 메모에 스케치합니다.

4

4. 요구사항 작성

Given-When-Then 형식으로 구체적인 조건과 예상 동작을 논리적으로 명세합니다.

5

5. AI에 작업 지시

역할(Role), 맥락(Context), 제약조건(Constraints)을 갖추어 AI에게 명확히 지시합니다.

6

6. 코드 생성

AI가 작성한 초안 코드를 한 줄씩 꼼꼼히 읽으며 모르는 문법과 변수명을 확인합니다.

7

7. 실행 & 테스트

브라우저에서 직접 실행하여 정상 시나리오와 예외 입력(오타, 빈칸 등)을 테스트합니다.

8

8. 오류 분석 & 개선

개발자 콘솔 에러를 분석하고, AI와 함께 디버깅 및 회귀 테스트를 거쳐 완성합니다.

생성형 AI의 원리 이해부터 인터랙티브 웹 비주얼 노벨 v1 완성까지

생성형 AI의 확률적 생성 원리와 환각 현상을 이해하고, AI 거짓말 탐지기 챌린지로 팩트체크를 훈련합니다.

2강 잠김

나만의 판타지 캐릭터와 세계관 프롬프트

3강 잠김

갈림길의 모험: 스토리 분기와 선택지 설계

작업 분해 기법으로 스토리를 장면 단위로 쪼개고, 독자의 선택에 따라 엔딩이 바뀌는 인터랙티브 분기 트리를 완성합니다.

4강 잠김

AI와 함께하는 밸런스 패치: 스토리 검증

스토리의 논리적 모순과 버그를 찾아 수정하고, 극적인 반전을 더해 완성도 높은 대본 v2를 확정합니다.

5강 잠김

게임 화면의 뼈대 세우기: HTML 대사창

HTML 태그와 문서 구조를 익혀 게임 화면에 대사창, 캐릭터 일러스트 자리, 선택 버튼을 직접 마크업합니다.

시즌 2: 미니 웹 아케이드 & 버그 헌터 (7~12강)

동적 인터랙션, 로직 설계, 디버깅 배틀, 회귀 테스트로 완성하는 실시간 웹 아케이드

8강 잠김

조건과 확률로 상자 열기: 럭키 가챠 & 3문항 퀴즈

조건문(if/else)과 배열, 무작위 확률(Math.random)을 활용해 행운의 보물 상자 뽑기와 3문항 퀴즈 게임을 구현합니다.

9강 잠김

웹 기초 미니 프로젝트: 별똥별 피하기 & MVP 아케이드 완성

HTML·CSS·JS를 총동원하여 키보드 방향키 조작과 충돌 판정, 점수 시스템을 갖춘 실시간 웹 아케이드를 완성합니다.

10강 잠김

AI 코딩 도구와 버그 사냥꾼: 콘솔 에러 분석 & AI 디버깅 배틀

개발자 도구 콘솔의 오류 메시지를 읽고 Given-When-Then 형식으로 AI에게 정확한 수정 프롬프트를 내려 버그를 체포합니다.

11강 잠김

게임 난이도 조절과 회귀 테스트: 안전한 AI 코드 변경 & Diff 검토

새 기능을 추가할 때 기존 기능이 고장 나지 않도록 검증하는 회귀 테스트(Regression Test)와 안전한 AI 변경 승인 원칙을 배웁니다.

12강 준비 중

미니 아케이드 게임 완성 & 랭킹전

최고 점수 저장 기능(Local Storage)을 넣고 완성된 아케이드 게임으로 반 친구들과 점수 경쟁을 펼칩니다.

JSON과 fetch, 공공 오픈 API, 날씨 연동, 예외 처리로 만드는 스마트 일상 웹앱

16강 준비 중

친구들이나 가족들이 실제로 매일 쓸 수 있는 유용한 웹 도구를 완성하고 링크로 공유합니다.

20강 준비 중

화면 설계와 Google Gemini 무료 API

카드 등록 없이 구글 계정으로 발급받는 Gemini 무료 API를 연동하고 와이어프레임을 그립니다.

21강 준비 중

핵심 흐름 알파(Alpha) 구현

22강 준비 중

통합 기능 완성 및 베타(Beta) 디버깅

모든 부가 기능을 연결하고, 버그 사냥과 예외 처리를 통해 완성도를 끌어올립니다.

23강 준비 중

친구들의 사용자 테스트(User Test)와 개선

친구 2명 이상에게 내 앱을 쓰게 하고, 막히거나 불편한 점을 찾아 마지막 다듬기를 마칩니다.

24강 준비 중

최종 데모 데이 쇼케이스 & 회고

완성된 프로젝트를 부모님과 친구들 앞에서 시연하고, 24강 동안의 성장 과정을 발표합니다.

SAFETY & ETHICS GUIDELINES

안전 수칙 및 윤리 가이드라인 (Safety & Ethics)

안전하고 신뢰할 수 있는 개발을 위해 모든 학생이 준수해야 하는 4대 기본 원칙입니다.

개인정보 보호

실명, 전화번호, 주소, 학교명 등 실제 개인정보를 AI 프롬프트나 코드에 절대 입력하지 않습니다. 테스트는 항상 가상의 데이터(예: 홍길동, user01)를 사용합니다.

원칙: 가상 데이터 필수

비밀 키(API Key) 보안

API 비밀 키는 절대 공개 깃허브나 웹에 업로드하지 않습니다. 유출 시 즉시 재발급하며, 본 과정에서는 키 등록 없는 무인증 오픈 API 실습을 최우선합니다.

원칙: 키 없는 오픈 API 권장

AI 답변 비판적 검증

생성형 AI는 그럴듯한 거짓말(환각, Hallucination)을 생성할 수 있습니다. AI가 작성한 코드는 맹신하지 않고 반드시 직접 브라우저 콘솔에서 실행하고 테스트합니다.

원칙: 실행과 팩트체크 필수

저작권 및 출처 표기

타인의 이미지나 오픈소스 코드를 활용할 때는 반드시 상업적 이용 가능 여부(CC0, MIT 등)를 확인하고, 출처와 AI 협업 프롬프트 기록을 투명하게 남깁니다.

원칙: 라이선스 확인 & 출처 명시
FALLBACK PATHS

도구 선택지 및 오프라인 대체 경로 (Fallback Paths)

학교 실습실의 보안 방화벽이나 네트워크 제약 환경에서도 100% 정상 실습이 가능하도록 대체 경로를 기본 제공합니다.

구분 기본 권장 도구 설치/네트워크 불가 시 대체 경로
AI 협업 무료 웹 AI 서비스 (ChatGPT Free, Claude Free, Gemini) 수업용 사전 제공 오프라인 프롬프트-응답 데이터셋 카드 활용
코드 작성 VS Code (Visual Studio Code) 또는 기본 메모장 웹 브라우저 내장 개발자 도구 (Console) 또는 온라인 웹 에디터
데이터 연동 공개 REST API (날씨, 미세먼지 등) API 키가 전혀 필요 없는 로컬 샘플 data.json 파일
결과물 저장 브라우저 로컬 스토리지 (Local Storage) 마크다운(.md) 및 JSON 파일 직접 다운로드 (회고 내보내기 지원)
