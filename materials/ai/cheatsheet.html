코드를 외우지 마세요!
화면 부위와 속성의 '정확한 이름' 을 알면 AI가 완성합니다.

"글씨를 박스 안에서 좀 띄워줘"라고 말하면 AI는 엉뚱한 코드를 짜며 헤맵니다. 하지만 "카드 내부 패딩(Padding)을 20px 줘"라고 명확한 전문 용어로 지시하면 AI는 단 한 번에 완벽한 코드를 만들어냅니다.

AI에게 100점짜리 코드를 얻어내는 3단계 지시 공식

1 [어디를? (대상)]

부위 / 컴포넌트 명칭

예: GNB 헤더, 카드 컴포넌트, 모달 팝업

2 [무엇을? (속성)]

박스 모델 / 상태 / CSS 속성

예: padding, margin, :hover, disabled

3 [어떻게? (수치·동작)]

원하는 구체적 결과

예: 20px로 넓혀줘, sticky로 화면 상단 고정

💡 완성 프롬프트 예시: "GNB 헤더를 화면 상단에 sticky로 고정하고, 카드 내부 패딩을 24px로 줘"

가장 많이 쓰이는 필수 개념: 웹 박스 모델 (Box Model)

"글씨 띄워줘"라고 하지 말고, 패딩(Padding)과 마진(Margin)을 구분해서 지시하세요!

CSS 06강 핵심 원리
Margin (바깥쪽 여백) 이웃 박스와의 거리 간격
Border (테두리선) 상자의 두께와 둥글기(border-radius)
Padding (안쪽 여백) 테두리와 글자 사이의 숨 쉴 공간
Content (글자, 사진, 아이콘 알맹이)
패딩 (Padding) : 상자 안쪽 숨구멍

비유: 선물 상자 안의 뽁뽁이 쿠션! 글자가 상자 벽에 딱 붙지 않게 안쪽 공간을 줍니다.

🪄 "카드 내부 padding을 20px(또는 p-5)로 줘서 답답하지 않게 해줘"
마진 (Margin) : 상자 바깥 사회적 거리두기

비유: 책상과 책상 사이의 통로 간격! 다른 카드나 글과 부딪히지 않게 거리를 벌립니다.

🪄 "카드들 사이에 margin-bottom: 24px(또는 gap-6)을 줘서 띄워줘"

01

GNB (헤더 내비게이션 바)

Global Navigation Bar / Header
웹 구조

🧸 비유: 건물의 1층 안내 데스크처럼, 어느 페이지를 가든 항상 보이는 최상단 메뉴 간판!

AI 프롬프트 키워드 sticky top-0 z-50
"GNB 헤더를 화면 스크롤 시에도 맨 위에 고정되도록 position: sticky top-0로 처리하고 z-index를 높여줘"

웹 구조

AI 프롬프트 키워드 Hero Area & CTA
"메인 화면에 눈에 띄는 히어로(Hero) 섹션을 만들고, 큰 대제목과 부제목, 그리고 강조된 시작하기 CTA 버튼을 배치해줘"

웹 구조

AI 프롬프트 키워드 w-64 fixed / drawer
"모바일에서는 햄버거 버튼 클릭 시 옆에서 튀어나오는 슬라이드 드로어(Drawer) 사이드바 메뉴로 만들어줘"

컨테이너 (Container)

Max-width Centered Wrapper
웹 구조

🧸 비유: 모니터가 아무리 커도 내용이 양옆으로 찢어지지 않게 예쁜 액자 안에 모아주는 울타리!

AI 프롬프트 키워드 max-w-5xl mx-auto
"본문 내용이 가로로 너무 퍼지지 않게 max-w-5xl 컨테이너로 감싸고 mx-auto로 화면 중앙에 오게 해줘"

카드 그리드 (Card Grid)

Responsive CSS Grid / Bento Grid
웹 구조

🧸 비유: 바둑판이나 계란판처럼 여러 개의 아이템을 일정한 열(2열, 3열)로 깔끔하게 정리하는 격자판!

AI 프롬프트 키워드 grid-cols-1 md:grid-cols-3 gap-6
"상품 카드들을 모바일은 1열, PC 화면에서는 3열 그리드로 나란히 배치하고 카드 사이 간격(gap)을 24px 줘"

푸터 (Footer)

Semantic <footer> Tag
웹 구조

🧸 비유: 책의 판권 정보 페이지! 사이트 가장 아랫단에 저작권, 주소, 소셜 링크를 모아두는 곳.

AI 프롬프트 키워드 footer copyright & links
"화면 최하단에 시맨틱 footer 태그를 추가하고, 어두운 배경색에 저작권 표시와 이용약관 링크를 넣어줘"
07

패딩 (Padding)

Inner Spacing / 안쪽 여백
공간·스타일

🧸 비유: 포장 상자 안의 뽁뽁이 쿠션! 글자나 사진이 상자 벽에 닿아 찌그러지지 않게 안쪽 숨구멍을 줌.

AI 프롬프트 키워드 padding: 24px (p-6)
"글씨가 박스 테두리에 너무 붙어있어 답답해. 카드 컴포넌트 내부 패딩(padding)을 20px로 넓혀줘"
08

마진 & 갭 (Margin & Gap)

Outer Spacing & Grid Gap / 바깥 간격
공간·스타일

🧸 비유: 책상과 책상 사이의 복도 간격! 다른 컴포넌트와 부딪히지 않게 바깥으로 밀어내는 안전거리.

AI 프롬프트 키워드 margin-bottom / gap-4
"버튼과 아래 설명 텍스트 사이가 너무 붙었어. 버튼에 margin-bottom: 16px(mb-4)을 줘서 간격을 벌려줘"

공간·스타일

🧸 비유: 뾰족한 책상 모서리에 안전 스펀지를 붙여 부드럽고 매끄러운 곡선으로 깎아주는 마법!

AI 프롬프트 키워드 border-radius: 16px (rounded-2xl)
"네모난 카드가 너무 딱딱해 보여. border-radius: 16px(rounded-2xl)을 줘서 모서리를 요즘 스타일로 둥글게 깎아줘"
10

박스 섀도우 (Box-shadow)

Drop Shadow & Elevation / 입체 그림자
공간·스타일

🧸 비유: 종이가 바닥에 찰싹 붙어있지 않고 공중에 붕 떠 있는 것처럼 밑에 살짝 지는 은은한 그림자!

AI 프롬프트 키워드 box-shadow (shadow-lg)
"카드가 평면처럼 밋밋해 보여. 은은한 그림자 효과(box-shadow-md 또는 shadow-lg)를 줘서 입체감을 줘"
11

:hover & 트랜지션 (Transition)

Pseudo-class & Smooth State Change
공간·스타일

🧸 비유: 강아지를 쓰다듬으면 기분 좋게 꼬리를 흔들듯이, 마우스를 올렸을 때 버튼이 부드럽게 반응하는 마법!

AI 프롬프트 키워드 :hover & transition 0.2s
"버튼에 마우스를 올렸을 때(:hover) 살짝 위로 떠오르고 색상이 진해지도록 transition: all 0.2s 애니메이션을 넣어줘"

Flexible Box Layout & Alignment

🧸 비유: 줄다리기 팀처럼 아이콘과 글자를 나란히 한 줄로 세우고, 좌우 끝에 딱 맞게 정렬하는 고무줄 정렬기!

AI 프롬프트 키워드 flex items-center justify-between
"아이콘과 글씨를 가로 한 줄로 나란히 놓고, 세로 중앙 정렬(items-center)에 양 끝으로 벌려줘(justify-between)"
