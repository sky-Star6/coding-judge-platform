3. 슬라이드 변수 - 굵기 조절 그림그리기

개념 설명

컴퓨터 그림판 프로그램에서 붓의 두께를 자유롭게 조절하듯이, 엔트리에서도 변수를 슬라이드(Slide) 형태로 만들어 마우스로 값을 직접 1부터 10까지 조절할 수 있어요! 🎨

연필 오브젝트가 마우스 포인터를 따라다니며 클릭할 때만 선을 긋고, 붓의 굵기에 [굵기 값] 변수를 넣어 실시간 두께가 바뀌는 그림판을 만들어 봅시다!

🎨 슬라이드 그리기 굵기 반영 ↓
1
마우스 추적
연필이 항상 마우스 포인터의 위치로 따라다니도록 합니다.
2
붓 속성 실시간 반영
붓 색을 검정으로 정하고, 굵기에 [굵기 값] 변수를 연결합니다.
3
클릭 시 그리기 시작
마우스를 누르고 있을 때만 선이 그어지도록 [그리기 시작하기]를 실행합니다.
4
클릭 해제 시 멈추기
마우스에서 손을 떼면 그리기를 멈추어 선을 끊어서 그릴 수 있습니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [연필]을 선택하고, 아래 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [연필] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (슬라이더 굵기 조절 그리기)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
움직임 반복 안쪽에 [( 마우스포인터 ▼ ) 위치로 이동하기] 블록을 넣습니다.
붓 아래에 [붓의 색을 ( 검정 ) 으로 정하기] 블록을 연결합니다.
붓 아래에 [붓의 굵기를 ( 10 ) 으로 정하기] 블록을 연결하고, 숫자 칸에 [굵기 값](자료)을 끼워 넣습니다.
흐름 아래에 [만일 < 참 > 이라면 / 아니면] 블록을 연결합니다.
판단 조건 칸에 [< 마우스를 클릭했는가? >] 블록을 끼워 넣습니다.
붓 '만일 참' 안쪽에는 [그리기 시작하기], '아니면' 안쪽에는 [그리기 멈추기] 블록을 각각 넣습니다.
💡 TIP : 변수의 '슬라이드' 모드란?

엔트리에서 변수를 만들 때 [기본형] 대신 [슬라이드]를 선택하면, 실행 화면의 변수 상자가 마우스로 좌우 드래그할 수 있는 조절 바로 변신해요! 최솟값(1)과 최댓값(10) 사이에서 실행 중에도 자유롭게 붓 굵기를 바꿀 수 있답니다.
