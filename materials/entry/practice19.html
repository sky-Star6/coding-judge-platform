실습 19 엔트리 실습

저격

창의 실습
30초 제한 시간 동안 밤하늘을 가로지르는 3종의 몬스터(매드 플라워·니브·드래곤 테일)를 마우스 과녁으로 조준해 클릭으로 저격하는 스나이퍼 슈팅 게임입니다! 🎯👾⏱️
엔트리 실습은 정해진 하나의 정답이 없습니다. 신호 보내고 기다리기 재귀 루프와 마우스 조준 시 크기 확대(줌인) 효과를 익히고, 나만의 저격 게임으로 확장해 보세요!
1
과녁 조준 & 30초 타이머
과녁이 마우스를 따라다니고, 밤 하늘(1)이 초시계를 시작해 30초 이상이 되면 모든 코드를 멈춥니다.
2
몬스터 3종 왕복 이동
매드·니브·드래곤 신호를 받으면 위치 변수(1~2)에 따라 좌↔우 또는 상↔하로 가로질러 이동합니다.
3
조준 확대 & 클릭 저격 득점
마우스 포인터가 닿으면 크기가 커지고, 그 상태에서 클릭하면 사라지며 점수(+1 또는 +3)가 올라갑니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 변수](점수, 매드위치, 니브위치, 드래곤위치), [속성 > 신호](매드, 니브, 드래곤) 및 5개 오브젝트를 확인한 뒤 코딩해 보세요!
⭐ [과녁] & [밤 하늘(1)] 코딩
시작 과녁: [시작하기 버튼을 클릭했을 때] 아래에 [계속 반복하기] → [( 마우스 포인터 ▼ ) 위치로 이동하기]를 연결합니다.
시작 밤 하늘(1): [시작하기 버튼을 클릭했을 때] 아래에 [초시계 ( 시작하기 ▼ )] → [< ( 초시계 값 ) ≥ ( 30 ) > 이 될 때까지 기다리기] → [초시계 ( 정지하기 ▼ )] → [( 모든 ▼ ) 코드 멈추기]를 연결합니다.
⭐ [매드 플라워] 오브젝트 코딩 (기본 크기 50)
시작 (1) [시작하기 버튼을 클릭했을 때] 아래에 [매드 ▼ 신호 보내고 기다리기]를 연결합니다.
시작 (2) [매드 ▼ 신호를 받았을 때] 아래에 [모양 보이기] → [매드위치 ▼ 를 ( ( 1 ) 부터 ( 2 ) 사이의 무작위 수 )(으)로 정하기]를 연결합니다.
흐름 [만일 < ( 매드위치 ▼ 값 ) = ( 1 ) > (이)라면] 안에 [x: ( 240 ), y: ( -135~135 ) 이동] → [( 2~3 ) 초 동안 x: ( -240 ), y: ( -135~135 ) 이동]을 넣고, 2라면 반대로 -240 → 240 이동을 넣은 뒤 맨 아래에 [매드 ▼ 신호 보내고 기다리기]를 연결합니다.
흐름 (3) 또 하나의 [시작하기 버튼을 클릭했을 때] → [계속 반복하기] 안에 [만일 < ( 마우스 포인터 ▼ ) 에 닿았는가? > (이)라면 크기를 ( 60 ), 아니면 크기를 ( 50 )으로 정하기]와 [만일 < 마우스를 클릭했는가? 그리고 ( 마우스 포인터 ▼ ) 에 닿았는가? > (이)라면 모양 숨기기, 점수 +1]을 넣습니다.
⭐ [니브] 오브젝트 코딩 (기본 크기 100, +3점)
시작 매드 플라워와 같은 구조로 니브 신호와 니브위치(1~2)를 사용하되, 1이면 위→아래(x: -240~240, y: 135 → -135), 2이면 아래→위(y: -135 → 135)로 1~2초 동안 빠르게 이동합니다.
자료 마우스에 닿으면 크기 120(아니면 100)으로 바뀌며, 클릭 명중 시 점수를 3만큼 더하기 합니다.
⭐ [드래곤 테일] 오브젝트 코딩 (기본 크기 100, +1점)
시작 드래곤 신호와 드래곤위치(1~2)로 좌↔우(240 ↔ -240)를 2~3초 동안 이동하고, 마우스에 닿으면 크기 120(아니면 100), 클릭 명중 시 점수를 1만큼 더합니다.

🎮 실행 및 조작 방법

조작 가이드
5개의 오브젝트를 모두 코딩한 뒤 30초 최고 점수에 도전해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하면 밤하늘을 배경으로 몬스터 3종이 출몰합니다.
2. 마우스로 과녁을 몬스터 위에 올리면 몬스터가 커지며 조준됩니다.
3. 마우스 클릭으로 빠르게 저격하세요! 상하로 빠르게 움직이는 니브를 잡으면 무려 +3점!

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
교재 추가 도전 미션으로 나만의 저격 게임을 업그레이드해 보세요!
1. 시작 장면 & 3초 카운트다운: 시작 장면을 추가하고 글상자 시작 버튼을 클릭하면 3, 2, 1 카운트다운 후 게임이 시작되며, 끝났을 때 점수를 말하도록 만들어 보세요.
2. 함정 오브젝트(저격 감점): 저격했을 때 오히려 점수가 깎이는 아군 또는 함정 오브젝트를 추가해 보세요.
3. 닿기만 해도 감점되는 방해꾼: 마우스 포인터(과녁)에 닿기만 해도 점수가 떨어지는 위험 오브젝트를 만들어 긴장감을 높여 보세요!
