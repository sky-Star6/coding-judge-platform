실습 08 엔트리 실습

엔트리봇 달리기

창의 실습
엔트리봇 1마리가 자신을 4번 복제해 총 5명의 선수가 출발선에 나란히 서서 달리기 경주를 펼치고, 결승선에 도착한 순서대로 등수를 외치는 게임입니다! 🏃‍♂️🏁
엔트리 실습은 정해진 하나의 정답이 없습니다. 기본 지문으로 복제본 병렬 실행과 공유 변수 등수 판정 원리를 익히고, 나만의 운동회로 멋지게 확장해 보세요!
1
5명의 엔트리봇 줄 세우기
(-210, 100)에서 시작해 아래(y: -50)로 내려가며 4번 복제하고, 1초 뒤 출발 신호를 보냅니다.
2
무작위 보폭으로 결승선 질주
자신의 x 좌푯값 > 210이 될 때까지 1 ~ 3 무작위 크기로 이동하며 다음 모양으로 걸어갑니다.
3
도착 순서대로 등수 말하기
결승선을 통과한 선수부터 공유 변수 등수를 1씩 증가시키며 자신의 순위를 말합니다.

⭐ [엔트리봇] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (선수 5명 배치 & 출발 신호)

움직임 [x: ( -210 ), y: ( 100 ) 위치로 이동하기] 블록을 연결합니다.
흐름 아래에 [( 4 ) 번 반복하기] 블록을 연결합니다.

🎮 실행 및 조작 방법

조작 가이드
블록을 조립한 뒤 아래 순서대로 달리기 경주를 시작해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하면 왼쪽 출발선 위에서 아래로 5마리 엔트리봇이 줄을 섭니다.
2. 1초 뒤 출발 신호와 함께 5마리가 저마다 다른 무작위 속도로 결승선(x: 210)을 향해 달려갑니다.
3. 결승선에 먼저 들어온 선수부터 차례대로 1, 2, 3, 4, 5 등수를 말합니다! 🏁✨

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
교재 추가 도전 미션으로 박진감 넘치는 장애물 경주를 완성해 보세요!
1. 중간 장애물 함정 추가: 트랙 중간 위치에 장애물 오브젝트를 추가해, 달리던 엔트리봇이 장애물에 닿으면 x 좌표를 ( -100 )만큼 바꾸기로 뒤로 밀려나도록 만들어 보세요.
2. 시작 버튼으로 경기 시작하기: [+ 오브젝트 추가하기]로 시작 버튼을 추가하고, 시작 버튼을 클릭했을 때 달리기 경주가 시작되도록 고쳐 보세요.
3. 등수 초기화 & 결승선 트랙 꾸미기: 시작 시 [등수를 0으로 정하기]를 넣고, [합치기] 블록으로 "1등!"처럼 말하거나 운동장 배경과 결승선을 추가해 보세요!
