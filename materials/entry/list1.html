1. 리스트의 정의와 명단 만들기

개념 & 실습
변수가 데이터(값)를 딱 하나만 넣는 상자라면, 리스트(List)는 칸칸이 번호가 매겨진 보관함 서랍장이에요! 🗂️
여러 사람의 이름이나 여러 개의 물건 목록처럼 많은 자료를 하나의 묶음 이름 아래 보관할 수 있습니다.
엔트리봇이 5명의 이름을 물어보고, 사용자가 대답한 이름을 [명단] 리스트에 차곡차곡 모은 뒤 1번부터 5번 친구의 이름을 하나씩 불러주는 출석부 프로그램을 만들어 볼까요?
1
리스트 생성
여러 개의 자료를 1번, 2번 순서대로 보관할 수 있는 [명단] 리스트를 준비합니다.
2
5번 반복 이름 입력
[이름을 입력하세요.] 묻고 대답받기를 5번 반복하여 연속으로 이름을 입력받습니다.
3
리스트에 차곡차곡 추가
입력받은 [대답]을 [명단]에 추가하기 블록으로 리스트의 맨 뒤에 차례차례 쌓습니다.
4
순서대로 호명하기
[명단]의 1번째 항목 말하기부터 5번째 항목까지 차례대로 2초 동안 말합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 화면에서 [엔트리봇] 오브젝트를 선택하고, 아래 블록들을 순서대로 조립해 보세요!
🤖 [엔트리봇] 오브젝트 코딩 명단.ent
시작 [시작하기 버튼을 클릭했을 때] 블록을 작업창에 배치합니다.
흐름 [10] 번 반복하기 블록을 연결하고, 10 대신 [5]로 수정합니다.
자료 반복 안쪽에 [이름을 입력하세요.] 묻고 대답 기다리기 블록을 넣습니다.
자료 묻기 블록 아래에 [대답] 항목을 [명단] 에 추가하기 블록을 연결합니다.
생김새 반복문이 끝난 아래에 [안녕!]을 [2]초 동안 말하기 블록을 5개 순서대로 연결합니다.
자료 각 말하기 블록의 안녕! 칸에 [명단] 의 [1~5] 번째 항목 블록을 순서대로 끼워 넣습니다.

💡 엔트리 꿀팁: 변수와 리스트의 결정적 차이!

변수는 1개, 리스트는 여러 개를 모아두는 바구니!
변수에 새로운 이름을 넣으면 기존에 있던 이름이 지워지지만, 리스트는 ~에 추가하기를 사용하면 기존 데이터를 그대로 보존하면서 1번, 2번, 3번... 순서대로 계속해서 자료를 늘려갈 수 있습니다.
이처럼 같은 종류의 데이터가 여러 개 필요할 때는 변수를 여러 개 만드는 것보다 리스트 하나를 사용하는 것이 훨씬 편리하고 효율적이에요!
