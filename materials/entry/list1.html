1. 리스트의 정의와 명단 만들기

개념 설명

변수가 데이터(값)를 딱 하나만 넣는 상자라면, 리스트(List)는 번호가 매겨진 칸칸이 서랍장이에요! 🗂️

엔트리봇이 5명의 이름을 물어보고 사용자가 대답한 이름을 [명단] 리스트에 차곡차곡 모은 뒤, 1번부터 5번 친구의 이름을 순서대로 불러주는 출석부 프로그램을 만들어 봅시다!

🗂️ 명단 리스트 추가 · 호명 ↓
1
리스트 생성
여러 개의 자료를 1번, 2번 순서대로 보관하는 [명단] 리스트를 준비합니다.
2
5번 반복 이름 입력
[이름을 입력하세요.] 묻고 대답받기를 5번 반복합니다.
3
리스트에 차곡차곡 추가
입력받은 [대답]을 [명단]에 추가하기 블록으로 맨 뒤에 쌓습니다.
4
순서대로 호명하기
1번째 항목부터 5번째 항목까지 차례대로 2초 동안 말합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [엔트리봇]을 선택하고, 아래 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [엔트리봇] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (명단 추가 및 호명)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
흐름 아래에 [( 10 ) 번 반복하기] 블록을 연결하고, 반복 횟수를 ( 5 )로 바꿉니다.
자료 반복 안쪽에 [( 이름을 입력하세요. ) 을(를) 묻고 대답 기다리기] 블록을 넣습니다.
자료 아래에 [( [대답] ) 항목을 ( 명단 ▼ ) 에 추가하기] 블록을 연결합니다.
생김새 반복문 아래에 [( 안녕! ) 을(를) ( 2 ) 초 동안 말하기] 블록 5개를 순서대로 연결합니다.
자료 각 말하기 칸에 [( 명단 ▼ ) 의 ( 1 ) 번째 항목] ~ [( 5 ) 번째 항목] 블록을 순서대로 끼워 넣습니다.
💡 TIP : 변수와 리스트의 결정적 차이!

변수는 값을 하나만 담아 새 값을 넣으면 기존 값이 덮어씌워지지만, 리스트는 ~에 추가하기로 기존 데이터를 지우지 않고 1번, 2번, 3번 순서대로 계속 쌓아둘 수 있습니다!
