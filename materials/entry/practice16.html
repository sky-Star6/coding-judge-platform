실습 16 엔트리 실습

벽돌깨기

창의 실습
이중 반복문으로 5행 7열(35개) 벽돌을 자동 배치하고, 마우스로 움직이는 막대로 공을 튕겨 모든 벽돌을 부수는 클래식 아케이드 게임입니다! 🧱🏓⚫
엔트리 실습은 정해진 하나의 정답이 없습니다. 이중 반복문 격자 복제와 각도 반사 계산 원리를 익히고, 나만의 벽돌깨기 게임으로 확장해 보세요!
1
5×7 벽돌 격자 복제 배치
벽돌이 (-200, 120)에서 시작해 가로 7번(x: +65), 세로 5줄(y: -20)로 총 35개의 복제본을 깔아줍니다.
2
마우스 막대 이동 & 공 반사 각도
막대가 마우스 x좌표를 따라가고, 공은 막대에 닿으면 0 - 이동방향, 벽돌에 닿으면 180 - 이동방향으로 튕깁니다.
3
점수 350점 클리어 또는 바닥 탈락
벽돌을 깰 때마다 +10점씩 올라 350점 이상이 되거나 공이 아래쪽 벽에 닿으면 게임이 멈춥니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 변수](점수)와 3개 오브젝트(벽돌, 막대, 공)를 확인한 뒤 코딩해 보세요!
⭐ [벽돌] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 — 5×7 벽돌 만들기
시작 [시작하기 버튼을 클릭했을 때] 아래에 [x: ( -200 ), y: ( 120 ) 위치로 이동하기]와 [모양 보이기]를 연결합니다.
흐름 [( 5 ) 번 반복하기] 블록을 연결합니다.
흐름 안쪽에 [( 7 ) 번 반복하기]를 넣고, 그 안에 [( 자신 ▼ )의 복제본 만들기]와 [x 좌표를 ( 65 )만큼 바꾸기]를 넣습니다.
움직임 안쪽 반복문 아래에 [x: ( -200 ) 위치로 이동하기]와 [y 좌표를 ( -20 )만큼 바꾸기]를 차례로 넣습니다.
생김새 바깥 반복문 아래에 [모양 숨기기]를 연결합니다.
(2) 복제본이 처음 생성되었을 때 — 충돌 & 점수 추가
흐름 [복제본이 처음 생성되었을 때] 아래에 [< ( 공 ▼ ) 에 닿았는가? > 이(가) 될 때까지 기다리기]를 연결합니다.
자료 [점수 ▼ 에 ( 10 ) 만큼 더하기]와 [이 복제본 삭제하기]를 차례로 연결합니다.
⭐ [막대] 오브젝트 코딩
시작 [시작하기 버튼을 클릭했을 때] 아래에 [계속 반복하기]를 연결하고, 안에 [x: ( 마우스 x 좌표 ) 위치로 이동하기]를 넣습니다.
⭐ [공] 오브젝트 코딩
시작 [시작하기 버튼을 클릭했을 때] 아래에 [( 1 ) 초 기다리기]와 [계속 반복하기]를 연결합니다.
움직임 [화면 끝에 닿으면 튕기기]와 [이동 방향으로 ( 3 )만큼 움직이기]를 넣습니다.
흐름 [만일 < ( 막대 ▼ ) 에 닿았는가? > (이)라면] 안에 [이동 방향을 ( ( 0 ) - ( 공 ▼ 의 이동 방향 ▼ ) )(으)로 정하기]와 [이동 방향을 ( ( -60 ) 부터 ( 60 ) 사이의 무작위 수 )˚ 만큼 회전하기]를 넣습니다.
흐름 [만일 < ( 벽돌 ▼ ) 에 닿았는가? > (이)라면] 안에 [이동 방향을 ( ( 180 ) - ( 공 ▼ 의 이동 방향 ▼ ) )(으)로 정하기]와 [이동 방향을 ( ( -60 ) 부터 ( 60 ) 사이의 무작위 수 )˚ 만큼 회전하기]를 넣습니다.
흐름 [만일 < ( 아래쪽 벽 ▼ ) 에 닿았는가? 또는 ( 점수 ▼ 값 ) ≥ ( 350 ) > (이)라면] 안에 [( 모든 ▼ ) 코드 멈추기]를 넣습니다.

🎮 실행 및 조작 방법

조작 가이드
3개의 오브젝트를 모두 코딩한 뒤 벽돌깨기에 도전해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하면 위쪽에 벽돌 35개가 생성되고 1초 뒤 공이 움직입니다.
2. 마우스를 좌우로 움직여 하늘색 막대로 공을 받아치세요!
3. 벽돌 35개를 모두 깨서 350점을 달성하면 클리어! 공이 아래쪽 벽에 닿으면 게임이 종료됩니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
교재 추가 도전 미션으로 나만의 벽돌깨기 게임을 업그레이드해 보세요!
1. 벽돌 깰 때마다 공 가속: 속도 변수를 만들고 벽돌이 없어질 때마다 속도를 0.1씩 더해보세요.
2. 목숨(기회) 시스템 & 다음 스테이지: 아래쪽 벽에 닿을 때 바로 끝나지 않고 목숨 횟수를 차감하게 만들고, 350점 달성 시 다음 스테이지로 넘어가게 확장해 보세요.
3. 특수 아이템 추가: 공 개수를 늘리거나 무작위 블록을 부수는 아이템 오브젝트를 만들어 보세요!
