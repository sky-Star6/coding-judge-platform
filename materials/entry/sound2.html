2. 키보드로 피아노 연주하기

악기 연주

키보드의 숫자 키(1 ~ 9, 0)를 피아노 건반의 각 음계와 연결하여, 내가 원하는 건반을 누를 때마다 청아한 피아노 소리가 연주되는 인터랙티브 전자 건반을 완성해 봅니다!

🎹 10개 건반 음계 매핑 매커니즘
1
낮은 음역 (1~3키): 1키(도) → 2키(레) → 3키(미)
2
중간 음역 (4~7키): 4키(파) → 5키(솔) → 6키(라) → 7키(시)
3
높은 음역 (8~0키): 8키(높은도) → 9키(높은레) → 0키(높은미)

🎯 실습 미션: 10개 음계 소리 연결 코딩

작업 영역에 배치된 각 숫자 키 블록 아래에 [소리] > [소리 [해당 음계] 재생하기] 블록을 하나씩 연결하세요!

🎼 [건반별 소리 연결 가이드]

1. 블록 복사 활용하기
1번 키에 소리 블록을 연결한 뒤, 블록 위에서 마우스 우클릭 > [코드 복사]를 하고 빈 공간에 [붙여넣기]하면 블록을 하나씩 찾는 번거로움 없이 빠르게 10개를 조립할 수 있습니다!

2. 숫자 0키의 위치 주의!
키보드에서 숫자 0은 9의 오른쪽에 있으므로 가장 높은 음인 피아노_13높은미 소리를 재생하도록 지정해 주세요!
