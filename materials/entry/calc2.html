2. 연산과 문자 합치기

개념 설명

연산이란 컴퓨터의 사칙연산 블록으로 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/) 등을 실시간 계산하는 것을 의미합니다.

계산 결과 숫자와 설명 글자를 [글자 합치기] 블록으로 하나로 묶으면 "4+2=6"처럼 사람이 한눈에 알아보기 쉬운 멋진 수식 문장을 만들 수 있습니다!

수식 연산 및 말풍선 출력 프로세스
1
[엔트리봇] 오브젝트 클릭
교실 칠판 앞의 엔트리봇을 마우스로 클릭하여 퀴즈 말하기를 시작합니다.
2
수식 텍스트 준비 ("4+2=")
문제 수식을 알려주는 안내 글자 "4+2="를 문자 블록의 앞자리에 배치합니다.
3
사칙연산 계산 실행 ((4) + (2))
컴퓨터가 4 더하기 2의 결과값인 6을 실시간으로 계산해 냅니다.
4
글자 합쳐서 4초 동안 말하기
수식과 정답을 하나로 합친 "4+2=6" 문장을 4초 동안 말풍선으로 띄웁니다!

🎯 실습 미션 지시사항

오른쪽 엔트리 화면에서 [엔트리봇] 오브젝트를 선택하고, 지시사항에 맞추어 블록을 조립해 보세요!
🤖 [엔트리봇] 오브젝트 코딩 연산1.ent
시작 [오브젝트를 클릭했을 때] 블록 아래에 연결합니다.
생김새 [안녕!] 을(를) [4] 초 동안 말하기 블록을 가져와 연결합니다.
계산 '안녕!' 입력칸에 [(안녕) 과(와) (엔트리) 를 합치기] 블록을 쏙 끼워 넣습니다.
글자 앞쪽 입력칸에 4+2= 글자를 직접 입력합니다.
계산 뒤쪽 입력칸에 [(10) + (10)] 계산 블록을 넣고 숫자를 4 + 2로 수정합니다.
교재 핵심 TIP: 컴퓨터의 4대 사칙연산 기호
1. 컴퓨터의 곱셈과 나눗셈 기호
컴퓨터 키보드에는 수학 기호인 ×나 ÷가 없기 때문에, 곱하기는 별표(*)를 쓰고, 나누기는 빗금(/)을 사용합니다.

2. 왜 [글자 합치기]를 쓸까요?
만약 (4 + 2) 계산 블록만 말하기에 넣으면 엔트리봇이 아무 설명 없이 숫자 6만 말하게 됩니다. 4+2= 문자와 (4+2) 계산 블록을 합쳐 넣으면 친절하게 "4+2=6"을 완성하여 말할 수 있습니다!
