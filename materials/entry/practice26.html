리듬게임

창의 실습

위에서 무작위로 떨어지는 화살표 노트가 아래 판정선에 닿는 순간, 알맞은 방향키를 눌러 점수를 올리는 키보드 리듬게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 도장 찍기, 복제본 위치 계산, 동시 입력 감점 방지, 신호 판정 애니메이션을 익힌 뒤 나만의 리듬게임으로 확장해 보세요!

1
상단 기준선 & 무작위 노트 생성
상단에 4방향 도장을 찍은 뒤, 1 / 속도초 간격으로 무작위 화살표 복제본을 내려보냅니다.
2
방향키 타이밍 판정
각 아래화살표 1~4에 닿았을 때 해당 방향키를 누르면 +1점과 함께 신호를 보냅니다.
3
누락·중복 입력 감점
노트를 놓쳐 아래쪽 벽에 닿거나 방향키 두 개를 동시에 누르면 점수가 -1 감소합니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오에서 [위화살표] 오브젝트를 선택하고, [속성 > 변수(모양, 점수, 속도) / 신호(1, 2, 3, 4)]를 확인한 뒤 아래 블록들을 조립해 보세요!
⭐ 위화살표 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (상단 도장 & 복제본 생성)
시작 [시작하기 버튼을 클릭했을 때] → [모양 보이기]
흐름 [( 4 ) 번 반복하기] 안에서 [도장 찍기] → [다음 모양으로 바꾸기] → [x 좌표를 ( 100 ) 만큼 바꾸기]
생김새 [모양 숨기기] 후 [계속 반복하기] 안에서 [( 자신 )의 복제본 만들기] → [( 1 / 속도 값 ) 초 기다리기]
(2) 복제본이 처음 생성되었을 때 (낙하 & 판정)
흐름 [복제본이 처음 생성되었을 때] → 모양을 1~4 무작위 수 → ( 모양 값 ) 모양으로 바꾸기
움직임 x: (-260), y: (110) 이동 → x 좌표를 모양 값 × 100만큼 바꾸기 → [모양 보이기]
흐름 [( 아래쪽 벽에 닿았는가? ) 이 될 때까지 반복하기] 안에서 y 좌표를 속도 값 × -5만큼 바꾸기
판단 아래화살표 1~4에 닿고 각각 오른쪽/아래쪽/왼쪽/위쪽 화살표 키가 눌렸으면 점수 +1, 1~4 신호 보내기, [이 복제본 삭제하기]
자료 바닥에 닿아 반복이 끝나면 점수에 -1 더하고 [이 복제본 삭제하기]
(3) 시작하기 버튼을 클릭했을 때 (초기화 & 동시 키 입력 방지)
자료 속도를 1, 점수를 0으로 정하고, [계속 반복하기] 안에서 두 방향키가 동시에 눌리면 점수를 -1 감점
⭐ 아래화살표 1 · 2 · 3 · 4 오브젝트 코딩
시작 (1) [( 1 / 2 / 3 / 4 ) 신호를 받았을 때] → 크기 60 → 0.1초 기다리기 → 크기 40
시작 (2) [( 오/아/왼/위쪽 화살표 ) 키를 눌렀을 때] → 색깔 효과 150 → 0.1초 기다리기 → [효과 모두 지우기]

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기] 버튼을 클릭합니다.
  2. 위에서 내려오는 화살표가 아래쪽 같은 모양 화살표에 겹치는 순간, 키보드의 방향키(→, ↓, ←, ↑)를 누르세요.
  3. 타이밍에 맞으면 아래 화살표가 반짝 커지며 점수가 1점 올라가고, 놓치거나 두 키를 동시에 누르면 감점됩니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
💡 자신만의 리듬게임으로 발전시켜 보세요!
기본 동작을 완성했다면, 아래 미션 중 1~2가지를 골라 음악과 함께 즐기는 리듬게임으로 업그레이드해 보세요.
  1. 배경 음악 및 효과음 추가: [소리] 탭에서 신나는 배경 음악과 노트 명중 효과음을 넣어보세요.
  2. 속도 점진적 증가: 점수가 10점 오를 때마다 속도를 0.2씩 높여 난이도가 올라가게 만들어 보세요.
  3. 정해진 악보 패턴 출제: 무작위 대신 리스트에 원하는 화살표 순서(예: 1, 2, 3, 4, 1, 1)를 저장해 곡에 맞춰 내려오게 수정해 보세요.
