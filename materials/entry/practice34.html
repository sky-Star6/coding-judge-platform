실습 34 엔트리 실습

독수리 피하기

창의 실습

쫓아오는 독수리를 피해 스테이지마다 나타나는 매미 5마리를 모두 먹고 나무로 탈출하는 스테이지 생존 추격 게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 스테이지별 적 복제 증가, 추적 AI(~쪽 바라보기), 클리어 조건 판정 원리를 익힌 뒤 나만의 생존 게임으로 확장해 보세요!

1
스테이지별 독수리 복제
장면이 시작될 때마다 스테이지가 1 오르고, 그 수만큼 독수리(2) 복제본이 생성되어 [묶음] 새를 추격합니다.
2
매미 5마리 먹기 & 나무 탈출
매미(2) 복제본 5마리에 닿아 매미개수를 0으로 만든 뒤 나무(1)에 닿으면 다음 스테이지로 넘어갑니다.
3
게임 종료 & 결과 대사
독수리에게 잡히면 게임종료 신호로 멈추고, 1스테이지면 "망했네..", 아니면 "(스테이지-1)까지 성공!"을 말합니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오에서 [시작 장면 / 플레이 장면]과 [속성 > 변수(스테이지, 매미개수) / 신호(게임종료)]를 확인한 뒤 아래 블록들을 조립해 보세요!
⭐ 시작 버튼 오브젝트 코딩 (시작 장면)
시작 (1) [오브젝트를 클릭했을 때] → [다음 장면 시작하기]
⭐ [묶음] 새 오브젝트 코딩 (플레이 장면)
시작 (1) [시작하기 버튼을 클릭했을 때] → 시작 장면 시작하기 / [장면이 시작되었을 때] → 위·아래·좌·우 화살표 키로 ±5 이동(좌/우 이동 시 270°/90° 방향 전환, 벽 닿으면 반대로 5 이동)
생김새 (2) [장면이 시작되었을 때] → 0.1초 기다리기 + [다음 모양으로 바꾸기] 계속 반복
흐름 (3) [장면이 시작되었을 때] → 만일 나무(1)에 닿고 매미개수 = 0이면 0.5초 대기 후 플레이 장면 다시 시작하기
시작 (4) [( 게임종료 ) 신호를 받았을 때] → 다른 오브젝트·자신의 다른 코드 멈추기 → 스테이지 = 1이면 "망했네..", 아니면 (스테이지 - 1) + "까지 성공!" 1초 동안 말하기
⭐ 독수리(2) · 매미(2) 오브젝트 코딩 (플레이 장면)
움직임 [독수리(2)] 장면 시작 시 스테이지 +1, 숨기기, 스테이지번 복제 → 복제본 생성 시 0.2초마다 다음 모양 + 보이기, (-200~200, -130~130) 이동 후 계속 [묶음] 새 쪽을 바라보며 0.5~1 이동(닿으면 게임종료 신호)
흐름 [매미(2)] 장면 시작 시 매미개수 = 5, 숨기기, 매미개수번 복제 → 복제본 생성 시 (-200~200, -130~130) 이동 후 보이기 → [묶음] 새에 닿을 때까지 기다리기 → 매미개수 -1 → 이 복제본 삭제

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기]를 누른 뒤, 중앙의 노란 [시작 버튼]을 클릭해 플레이 장면으로 들어갑니다.
  2. 방향키(← ↑ ↓ →)로 새를 조종해 독수리를 피하면서 화면에 흩어진 매미 5마리를 모두 먹으세요.
  3. 매미개수가 0이 되면 오른쪽 아래 나무로 날아가 다음 스테이지에 도전하세요!

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
💡 자신만의 독수리 피하기 게임으로 업그레이드해 보세요!
기본 동작을 완성했다면, 아래 미션 중 1~2가지를 골라 완성도를 높여 보세요.
  1. 스테이지별 매미·독수리 수 조절 & 소리 추가: 스테이지가 올라갈수록 매미 개수도 늘리고, 나무에 닿았을 때 반짝반짝 빛나는 효과음을 재생해 보세요.
  2. 시작·종료 화면 꾸미기: 배경을 추가하고, 게임이 끝났을 때 걸린 시간이나 최고 스테이지를 보여주는 종료 장면을 만들어 보세요.
  3. 인공지능 읽어주기 대사: 읽어주기 블록으로 게임 종료 대사를 음성으로도 들려주도록 확장해 보세요.
