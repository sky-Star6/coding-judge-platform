2. 해적선 움직이기

작품 & 실습
넓은 바다를 항해하는 해적선의 방향 전환과 이동을 함수로 정의하여 방향키로 조종하는 멋진 항해 프로그램을 만들어 봅니다! 🏴‍☠️⛵
'오른쪽으로 움직이기'와 '왼쪽으로 움직이기' 함수를 각각 만들고, 배의 모양 변경과 이동 방향(각도), 이동 거리를 담아 두어 메인 코드를 깔끔하고 직관적으로 완성해 보세요!
1
오른쪽 이동 함수 정의
[해적선_오른쪽] 모양 바꾸기 + 이동 방향 90˚ 정하기 + [문자/숫자값1] 만큼 움직이기
2
왼쪽 이동 함수 정의
[해적선_왼쪽] 모양 바꾸기 + 이동 방향 270˚ 정하기 + [문자/숫자값1] 만큼 움직이기
3
방향키로 항해 시작!
[계속 반복하기] 안에서 오른쪽/왼쪽 화살표 키가 눌리면 각각의 함수에 [3]을 전달하여 항해합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 화면에서 [해적선] 오브젝트를 선택하고, 아래 블록들을 순서대로 조립해 보세요!
⛵ [해적선] 오브젝트 코딩 해적선.ent
시작 [시작하기 버튼을 클릭했을 때] 블록을 작업창에 배치합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
흐름 반복 안쪽에 만일 <참> 이라면 블록을 넣습니다.
판단 조건(<참>) 칸에 <오른쪽 화살표 키가 눌려져 있는가?> 블록을 끼웁니다.
함수 만일 안쪽에 [오른쪽으로 ( ) 만큼 움직이기] 함수 블록을 넣고, 값 칸에 [3]을 입력합니다.
흐름 아래에 다시 만일 <참> 이라면 블록을 하나 더 연결합니다.
판단 조건(<참>) 칸에 <왼쪽 화살표 키가 눌려져 있는가?> 블록을 끼웁니다.
함수 만일 안쪽에 [왼쪽으로 ( ) 만큼 움직이기] 함수 블록을 넣고, 값 칸에 [3]을 입력합니다.

💡 엔트리 꿀팁: 매개변수로 이동 속도 자유자재 조절!

숫자값을 바꾸면 배의 속도가 쑥쑥!
함수 블록의 빈칸(매개변수)은 함수에 전달하는 입력값이에요.
