4. 카운트다운 타이머 만들기

개념 & 실습
초 단위의 시간을 사용자가 직접 입력하면, 그 시간부터 1초마다 숫자가 1씩 줄어들며 0초까지 카운트다운하는 시한폭탄 타이머를 만들어 볼까요? ⏱️💣
엔트리봇이 [초 단위로 입력해 보세요.]라고 묻고 사용자가 숫자를 대답하면, [타이머작동] 신호를 보내 폭탄 위의 카운터 글상자가 1초마다 남은 시간을 줄여가며 실시간으로 화면에 글씨를 쓰게 됩니다!
1
초 단위 시간 입력 및 신호 전송
엔트리봇이 시간을 묻고 대답을 받으면 [타이머작동] 신호를 보냅니다.
2
타이머 변수 초기화
카운터 글상자가 신호를 받아 [타이머] 변수를 입력받은 [대답] 값으로 정합니다.
3
1초 대기 후 1씩 차감
[대답] 번 반복하며 1초를 기다린 뒤 [타이머] 변수에 -1을 더합니다.
4
남은 시간 실시간 글쓰기
폭탄 위 글상자에 바뀐 [타이머] 변수 값을 실시간으로 써서 카운트다운을 보여줍니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 화면에서 [엔트리봇]과 [카운터] 오브젝트를 선택하고, 아래 블록들을 순서대로 조립해 보세요!
🤖 [엔트리봇] 오브젝트 코딩 타이머만들기.ent
시작 [시작하기 버튼을 클릭했을 때] 블록을 작업창에 배치합니다.
자료 [초 단위로 입력해 보세요.] 라고 묻고 대답 기다리기 블록을 연결합니다.
시작 [타이머작동] 신호 보내기 블록을 연결하여 카운터에 신호를 보냅니다.
💣 [카운터] 오브젝트 코딩 (글상자) 타이머만들기.ent
시작 [타이머작동 신호를 받았을 때] 블록을 작업창에 배치합니다.
자료 [타이머]를 [대답]으로 정하기 블록을 연결하여 시작 시간을 설정합니다.
흐름 [대답] 번 반복하기 블록을 연결합니다 (10 대신 [대답] 블록을 끼워 넣으세요).
흐름 반복 안쪽에 [1] 초 기다리기 블록을 넣어 1초 간격을 만듭니다.
자료 기다리기 아래에 [타이머]에 [-1] 만큼 더하기 블록을 넣어 시간을 줄입니다.
글상자 차감 블록 아래에 [타이머] 글쓰기 블록을 넣어 남은 시간을 폭탄 위에 보여줍니다.

💡 엔트리 꿀팁: 신호와 변수의 연동

엔트리봇과 폭탄 카운터가 서로 통신하는 원리!
엔트리봇은 사용자에게 초 단위 시간을 물어보는 입력 담당이고, 폭탄 위의 카운터는 글씨를 줄여나가는 표시 담당이에요.
이처럼 서로 다른 오브젝트가 협동할 때는 [신호 보내기]를 통해 시작 타이밍을 맞추고, [대답] 및 [변수] 상자를 통해 입력받은 값을 공유한답니다!
