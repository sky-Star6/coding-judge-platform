합성효과

창의 실습
시작하기 버튼을 클릭하면 화면 양쪽에서 계란과 밥공기가 가운데로 모이며 서서히 투명해지고, '합성' 신호를 받아 맛있는 달걀초밥이 서서히 나타나는 마법 같은 합성 애니메이션입니다! 🍣✨
엔트리 실습은 정해진 하나의 정답이 없습니다. 기본 지문을 따라 투명도와 신호 원리를 익히고, 나만의 요리 조합으로 멋지게 확장해 보세요!
1
초기 위치 & 투명도 설정
계란은 왼쪽 x: -150, 밥공기는 오른쪽 x: 150에서 시작하고, 달걀초밥은 정중앙 (0, 0)에서 투명도 100으로 숨어 있습니다.
2
중앙 이동 & 서서히 사라지기
계란(+15)과 밥공기(-15)가 10번 반복하며 가운데로 이동하고 투명도를 10씩 높여 사라진 뒤, 계란이 [합성] 신호를 보냅니다.
3
신호 수신 & 달걀초밥 등장
달걀초밥이 [합성] 신호를 받으면 10번 반복하며 투명도를 -10씩 줄여 선명하게 나타납니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 신호]에서 [합성] 신호가 만들어져 있는지 확인한 뒤, [계란] · [밥공기] · [달걀초밥] 오브젝트를 차례대로 코딩해 보세요!
⭐ [계란] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
생김새 [모양 보이기]와 [효과 모두 지우기] 블록을 연결합니다.
움직임 [x: ( -150 ), y: ( 0 ) 위치로 이동하기] 블록을 연결합니다.
흐름 아래에 [( 10 ) 번 반복하기] 블록을 연결합니다.

흐름 [( 0.1 ) 초 기다리기] 블록을 넣습니다.
시작 반복 블록 아래에 [합성 ▼ 신호 보내기] 블록을 연결합니다.
⭐ [밥공기] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
생김새 [모양 보이기]와 [효과 모두 지우기] 블록을 연결합니다.
움직임 [x: ( 150 ), y: ( 0 ) 위치로 이동하기] 블록을 연결합니다.
흐름 아래에 [( 10 ) 번 반복하기] 블록을 연결합니다.
생김새 반복 안쪽에 [투명도 ▼ 효과를 ( 10 )만큼 주기] 블록을 넣습니다.
움직임 [x 좌표를 ( -15 )만큼 바꾸기] 블록을 넣습니다.

⭐ [달걀초밥] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (투명하게 대기)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
움직임 [x: ( 0 ), y: ( 0 ) 위치로 이동하기] 블록을 연결합니다.

(2) 합성 신호를 받았을 때 (서서히 등장)
시작 [합성 ▼ 신호를 받았을 때] 블록을 새로 꺼냅니다.
흐름 아래에 [( 10 ) 번 반복하기] 블록을 연결합니다.
생김새 반복 안쪽에 [투명도 ▼ 효과를 ( -10 )만큼 주기] 블록을 넣습니다.
흐름 [( 0.1 ) 초 기다리기] 블록을 넣습니다.

🎮 실행 및 조작 방법

조작 가이드
세 오브젝트의 코드를 모두 조립한 뒤, 아래 순서대로 실행해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭합니다.
2. 왼쪽의 계란과 오른쪽의 밥공기가 가운데로 모이며 서서히 투명해집니다.
3. 두 재료가 사라지는 순간 [합성] 신호가 전달되어 가운데에 달걀초밥이 부드럽게 나타납니다! 🍣✨

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
나만의 마법 요리 합성기를 만들어 보세요!
1. 새로운 합성 요리 추가: [+ 오브젝트 추가하기]로 다른 재료와 요리(예: 빵 + 패티 → 햄버거, 생선 + 밥공기 → 생선초밥)를 추가하고 새로운 신호로 2단계 합성을 만들어 보세요!
2. 반짝이는 연출 & 효과음: 달걀초밥이 나타날 때 크기를 살짝 키웠다가 줄이거나, [효과음] 소리와 배경(식당/주방)을 넣어 실감 나게 꾸며 보세요.
3. 합성 속도 실험: 반복 횟수와 기다리기 시간(0.05초, 0.1초)을 바꾸어 더 부드러운 페이드 효과를 연출해 보세요! ✨
