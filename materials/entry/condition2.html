2. 만일 참이라면, 아니면 (if-else)

양갈래 분기 조건

일상생활에서 "신호등이 초록불이면 길을 건너고, 아니면 멈춰 기다린다"처럼 어떤 조건이 참일 때와 거짓일 때 각각 다른 행동을 하도록 만드는 핵심 블록이 바로 [만일 참이라면 / 아니면] 블록입니다!

🔐 비밀번호 일치 판단 3단계 흐름도 양갈래 분기 ↓
1
질문과 입력: [번호를 입력하세요. 를 묻고 대답 기다리기]로 사용자에게 번호를 입력받아 [대답] 상자에 저장합니다.
2
비밀번호 비교: [ [정답] 값 = [대답] ] 판단 블록으로 미리 지정된 1234와 같은지 비교합니다.
3
양갈래 실행:
• 같으면(참) : "맞았습니다." 2초 말하기
• 다르면(아니면) : "틀렸습니다." 2초 말하기

🎯 실습 미션: 비밀번호 판정 엔트리봇

아래 지시사항을 보고 [엔트리봇] 오브젝트에 비밀번호를 물어보고 맞았는지 틀렸는지 판정하는 블록 코드를 완성해 보세요!

오브젝트 엔트리봇 : 질문하고 대답과 정답 비교하기
시작 [시작하기 버튼을 클릭했을 때]
자료 [ 번호를 입력하세요. 을(를) 묻고 대답 기다리기 ]
흐름 [ 만일 <참> 이라면 ]
판단 육각형 조건: [ [ [정답 ▼] 값 ] = [ 대답 ] ]
생김새 만일 안 (참): [ 맞았습니다. 을(를) 2 초 동안 말하기 ]
흐름 [ 아니면 ]
생김새 아니면 안 (거짓): [ 틀렸습니다. 을(를) 2 초 동안 말하기 ]
💡 TIP : 변수란 무엇이고 왜 사용할까요?

변수(Variable)란 컴퓨터 안에 값을 담아두는 '이름표가 붙은 상자'입니다.
화면 왼쪽 위에 보이는 [정답 : 1234]처럼 변수를 만들어두면, 프로그램이 실행되는 동안 언제든지 상자 속의 값을 꺼내어 사용자가 입력한 [대답]과 똑같은지 안전하게 비교할 수 있답니다!
