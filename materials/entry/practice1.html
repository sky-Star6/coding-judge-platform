1. 불꽃효과

창의 실습
키보드 방향키를 누르면 별이 회전하며 점점 커지거나 작아지면서, 알록달록 색상이 바뀌며 도장을 찍어 환상적인 불꽃놀이 효과를 만들어 내는 프로그램입니다! 🎆✨
엔트리 실습은 정해진 하나의 정답이 없습니다. 기본 지문을 따라 원리를 익히고, 나만의 아이디어를 더해 멋진 불꽃쇼를 연출해 보세요!
1
시작 위치 설정
[시작하기 버튼을 클릭했을 때] 화면 정중앙 x: ( 0 ), y: ( 0 ) 위치로 이동합니다.
2
불꽃 도장 찍기 (방향키)
↑ 위쪽 키: 크기(100%), 색깔(0) 설정 후 20번 반복 (크기 +5, 색깔 +10, 10˚ 회전, 도장 찍기)
↓ 아래쪽 키: 크기(200%), 색깔(0) 설정 후 20번 반복 (크기 -5, 색깔 +10, -10˚ 회전, 도장 찍기)
3
모든 붓 지우기 (스페이스)
[스페이스 키를 눌렀을 때] 화면에 찍힌 모든 도장 자국을 깨끗하게 지웁니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
밤하늘의 불꽃놀이 축제를 만들어 보세요!
1. 연속 불꽃놀이 만들기: 불꽃 1개 → 불꽃 3개까지만 연달아 터지도록 코드를 확장해 보세요! (⚠️ 도장 찍기가 너무 많아지면 화면에 렉이 걸릴 수 있으니 3개까지만 도전해 보세요!)
2. 다양한 회전과 각도 실험: 회전 각도를 10˚ 대신 15˚나 30˚로 바꾸거나, 반복 횟수를 조절하면 어떤 새로운 불꽃 패턴이 만들어질까요?
3. 배경과 소리 추가: 배경을 '밤하늘'로 바꾸고, '폭죽 소리' 효과음을 넣어 실감 나는 불꽃 축제 작품을 완성해 보세요! 🎆
🎮 실행 및 조작 방법
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭합니다.

3. 키보드의 ↓ (아래쪽 화살표)를 누르면 모여드는 불꽃이 만들어집니다.
