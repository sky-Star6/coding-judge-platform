3. 사고력 Test 01 화재출동 신호 만들기

사고력 TEST

소방서에 비상벨이 울렸습니다!

빨강 및 파랑 단추를 이용하여 소방서 건물 위의 빨간LED와 파란LED 경광등을 번갈아 깜빡이고, [장면 2]로 전환하여 비상 텍스트 신호를 띄우는 스마트 소방 방재 시스템을 완성해 봅니다!

화재출동 시스템 상호작용 프로세스
1
[장면 1] 빨강 단추 클릭 → LED 교대 점멸
빨강 단추를 누르면 빨간신호가 시작되어 빨간LED와 파란LED가 1초씩 번갈아가며 끝없이 깜빡입니다.
2
[장면 1] 파랑 단추 클릭 → [장면 2] 출동 전환
파랑 단추를 누르면 [장면 2]로 무대가 즉시 바뀌며 "출동!!" 글상자가 1초 간격으로 점멸합니다.

🎯 실습 미션 지시사항

엔트리 화면 상단의 장면 탭([장면 1], [장면 2])을 오가며 아래 4개 오브젝트의 코드를 순서대로 완성해 보세요!
🔘 장면 1: [파랑] 단추 코딩 장면 1
시작 [오브젝트를 클릭했을 때] 아래에 연결
시작 [장면 2] 시작하기
🔵 장면 1: [파란LED] 경광등 코딩 장면 1
시작 [파란신호 신호를 받았을 때] 아래에 연결
생김새 [파란LED_켜짐] 모양으로 바꾸기 → [흐름] [1] 초 기다리기
생김새 [파란LED_꺼짐] 모양으로 바꾸기 → [시작] [빨간신호] 신호 보내고 기다리기
🔴 장면 1: [빨간LED] 경광등 코딩 장면 1
시작 [빨간신호 신호를 받았을 때] 아래에 연결
생김새 [빨간LED_켜짐] 모양으로 바꾸기 → [흐름] [1] 초 기다리기
생김새 [빨간LED_꺼짐] 모양으로 바꾸기 → [시작] [파란신호] 신호 보내고 기다리기
📢 장면 2: [글상자] 출동 알림 코딩 장면 2 탭 이동
시작 [장면이 시작되었을 때] 아래에 [흐름] [계속 반복하기] 연결
생김새 [계속 반복하기] 안에 [모양 숨기기] → [1] 초 기다리기 → [모양 보이기] → [1] 초 기다리기
교재 핵심 TIP: 신호 핑퐁(Ping-Pong)과 글상자 점멸
1. 신호 주고받기(Ping-Pong) 원리
빨간LED가 꺼진 뒤 파란신호 신호 보내고 기다리기를 실행하고, 파란LED가 꺼진 뒤 빨간신호 신호 보내고 기다리기를 실행하면 두 오브젝트가 탁구공을 주고받듯 끝없이 번갈아가며 점멸하는 환상의 콤비네이션이 완성됩니다!

2. 글상자 깜빡임 효과
계속 반복하기 블록 안에 모양 숨기기 → 1초 대기 → 모양 보이기 → 1초 대기를 배치하면 전광판처럼 깜빡이며 시선을 사로잡는 긴급 경보를 만들 수 있습니다!
