실습 12 엔트리 실습

풍선피하기

창의 실습
마우스 포인터를 따라다니는 비행기 엔트리봇이 벽에 닿을 때마다 늘어나는 풍선들을 피해 버티고, 10초마다 등장하는 하트 아이템으로 풍선을 제거하는 생존 피하기 게임입니다! ✈️🎈❤️
엔트리 실습은 정해진 하나의 정답이 없습니다. 기본 지문으로 복제 증식·초시계 기록·아이템 크기 조건 판정 원리를 익히고, 나만의 생존 게임으로 확장해 보세요!
1
비행기 조종 & 초시계 생존 기록
1초 뒤 중앙에서 출발해 벽이나 풍선에 닿을 때까지 마우스를 따라다니며, 종료 시 기록 변수에 버틴 시간을 저장하고 말합니다.
2
벽 반사 시 풍선 복제 증식
풍선이 벽에 닿으면 비행기 쪽을 바라보고 방향을 살짝 틀어 튕겨 나오면서 자신의 복제본을 하나씩 추가합니다.
3
10초마다 하트 아이템으로 풍선 제거
기본하트는 10초마다 나타나 비행기에 닿으면 크기가 60으로 커지며, 이때 닿은 풍선 복제본을 삭제합니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 변수](기록, 숨김)와 3개 오브젝트 설정(비행기를 탄 모습 크기 40, 기본하트 20, 풍선 20)을 확인한 뒤 코딩해 보세요!
⭐ [비행기를 탄 모습] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때
시작 [시작하기 버튼을 클릭했을 때] 아래에 [( 1 ) 초 기다리기], [x: ( 0 ), y: ( 0 ) 위치로 이동하기], [초시계 ( 시작하기 ▼ )]를 차례로 연결합니다.
흐름 [< ( 벽 ▼ ) 에 닿았는가? 또는 ( 풍선 ▼ ) 에 닿았는가? > ( 이 될 때까지 ▼ ) 반복하기] 블록을 연결합니다.
움직임 안쪽에 [( 마우스 포인터 ▼ ) 위치로 이동하기]를 넣습니다.
자료 반복문 아래에 [기록 ▼ 를 ( 초시계 값 )(으)로 정하기]를 연결합니다.
흐름 [( 다른 오브젝트의 ▼ ) 코드 멈추기]와 [( 기록 ▼ 값 ) ( 말하기 ▼ )]를 차례로 연결합니다.
⭐ [기본하트] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때
시작 [시작하기 버튼을 클릭했을 때] 아래에 [( 1 ) 초 기다리기]와 [계속 반복하기]를 연결합니다.
움직임 [x: ( ( -200 ) 부터 ( 200 ) 사이의 무작위 수 ), y: ( ( -100 ) 부터 ( 100 ) 사이의 무작위 수 ) 위치로 이동하기]를 넣습니다.
생김새 [크기를 ( 20 ) (으)로 정하기], [모양 숨기기], [( 10 ) 초 기다리기], [모양 보이기]를 차례로 넣습니다.
흐름 [< ( 비행기를 탄 모습 ▼ ) 에 닿았는가? > 이 될 때까지 기다리기]를 넣습니다.
생김새 [크기를 ( 60 ) (으)로 정하기], [( 1 ) 초 기다리기], [모양 숨기기]를 차례로 넣습니다.
⭐ [풍선] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (원본 풍선)
시작 [시작하기 버튼을 클릭했을 때] 아래에 [( 1 ) 초 기다리기]를 연결합니다.
움직임 [x: ( ( -200 ) 부터 ( 200 ) 사이의 무작위 수 ), y: ( ( -100 ) 부터 ( 100 ) 사이의 무작위 수 ) 위치로 이동하기]와 [이동 방향을 ( ( 0 ) 부터 ( 360 ) 사이의 무작위 수 )(으)로 정하기]를 연결합니다.
흐름 [계속 반복하기] 안에 [이동 방향으로 ( 5 )만큼 움직이기]를 넣습니다.
흐름 [만일 < ( 벽 ▼ ) 에 닿았는가? > (이)라면] 안에 [( 비행기를 탄 모습 ▼ ) 쪽 바라보기], [방향을 ( ( -10 ) 부터 ( 10 ) 사이의 무작위 수 )˚ 만큼 회전하기], [이동 방향으로 ( 10 )만큼 움직이기], [( 자신 ▼ )의 복제본 만들기]를 넣습니다.
(2) 복제본이 처음 생성되었을 때
흐름 [복제본이 처음 생성되었을 때] 아래에 [계속 반복하기]를 연결하고 [이동 방향으로 ( 5 )만큼 움직이기]를 넣습니다.
흐름 [만일 < ( 벽 ▼ ) 에 닿았는가? > (이)라면] 안에 위와 같이 바라보기·회전·10만큼 움직이기를 넣습니다. (복제본은 추가 복제 제외)
흐름 [만일 < ( 기본하트 ▼ ) 에 닿았는가? 그리고 ( 기본하트 ▼ 의 크기 ▼ ) = ( 60 ) > (이)라면] 안에 [이 복제본 삭제하기]를 넣습니다.

🎮 실행 및 조작 방법

조작 가이드
3개의 오브젝트를 모두 코딩한 뒤 생존 기록에 도전해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하고 1초 뒤 마우스를 움직여 비행기를 조종하세요.
2. 풍선이 벽에 닿을 때마다 복제되어 개수가 늘어나니 빈 공간을 찾아 피하세요!
3. 10초마다 나타나는 기본하트에 닿으면 하트가 커지며 주변 풍선을 터뜨려 줍니다! 벽이나 풍선에 닿으면 버틴 기록을 말하고 종료됩니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
나만의 아이디어를 더해 풍선피하기 게임을 업그레이드해 보세요!
1. 풍선 표정 변화 효과: 하트에 닿아 삭제되기 직전에 풍선 모양을 풍선_터짐으로 잠깐 바꾼 뒤 사라지게 만들어 보세요.
2. 최고 기록 갱신: 최고 기록 변수를 추가해 이전 기록보다 오래 버티면 축하 메시지를 띄워 보세요.
3. 배경·효과음 추가: [+ 오브젝트 추가하기]로 하늘 배경이나 BGM을 추가해 비행기 게임 분위기를 완성해 보세요!
