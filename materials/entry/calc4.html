4. 작품으로 알아보기 - 구구단 2단 외우기

작품 실습

유치원생 친구가 학교 운동장에서 신나게 구구단 2단을 외우고 있어요! 🎒
유치원생을 클릭하면 2×1부터 2×9까지 계산 결과와 식을 문자로 합쳐서 1초씩 차례대로 말하도록 만들어 볼까요?

🎒 구구단 2단 도해 연산 출력 ↓
1
오브젝트 클릭
유치원생을 클릭하면 구구단 2단 외우기가 시작됩니다.
2
문자 합치기
'2*1=' 글자와 (2 × 1) 곱셈 연산 결과를 하나로 합칩니다.
3
1초 동안 말하기
합쳐진 문자열(예: 2*1=2)을 말풍선으로 1초 동안 보여줍니다.
4
2단 완주 (2*1 ~ 2*9)
2×2=4, 2×3=6 ... 2×9=18까지 9번 연속으로 이어집니다!

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [유치원생]을 선택하고, 아래 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [유치원생] 오브젝트 코딩
(1) 오브젝트를 클릭했을 때 (구구단 2단 말하기)
시작 [오브젝트를 클릭했을 때] 블록을 배치합니다.
생김새 아래에 [( 안녕! ) 을(를) ( 4 ) 초 동안 말하기] 블록을 연결하고, 시간을 ( 1 )초로 바꿉니다.
계산 말하기 칸에 [( 안녕 ) 과(와) ( 엔트리 ) 를 합치기] 블록을 끼워 넣습니다.
계산 앞 칸에 ( 2*1= ) 글자를 입력하고, 뒤 칸에 [( 10 ) * ( 10 )] 곱하기 블록을 넣어 ( 2 ) * ( 1 )로 설정합니다.
생김새 같은 방식으로 2*2=4부터 2*9=18까지 총 9개의 말하기 블록을 차례대로 아래에 연결합니다.
💡 TIP : 복사 & 붙여넣기로 빠르게 완성하기!

9개의 긴 블록을 일일이 새로 조립하려면 힘들겠죠? 완성한 말하기 블록을 마우스 우클릭한 뒤 [코드 복사하기] → [붙여넣기]를 누르면 똑같은 블록이 즉시 복제됩니다! 숫자만 2, 3, 4...로 바꿔주면 순식간에 구구단을 완성할 수 있어요!
