5. 사고력 Test - 자유롭게 움직이는 별

사고력 실습
깜깜한 우주 밤하늘에서 반짝이는 별이 살아 움직여요! ✨
시작하기 버튼을 누르면 별이 무작위 시간(1~3초) 동안 우주 공간의 무작위 위치(X: -200~200, Y: -120~120)로 자유롭게 날아가고, 색깔도 50~100 사이의 무작위 수만큼 계속 변하도록 만들어 볼까요?
1
시작하기 클릭
시작하기 버튼을 누르면 계속 반복하기 루프가 동작합니다.
2
무작위 시간 이동
1부터 3 사이의 무작위 초 동안 부드럽게 날아갑니다.
3
무작위 좌표 (X, Y)
x: -200~200, y: -120~120 범위 내의 임의의 위치로 이동합니다.
4
무작위 색깔 효과
색깔 효과를 50부터 100 사이의 무작위 수만큼 주어 환상적인 색으로 변합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 화면에서 [별] 오브젝트를 선택하고, 지시사항에 맞추어 블록을 조립해 보세요!
⭐ [별] 오브젝트 코딩 움직이는별.ent
시작 [시작하기 버튼을 클릭했을 때] 블록 아래에 연결합니다.
흐름 [계속 반복하기] 블록을 가져와 연결합니다.
움직임 반복문 안쪽에 [(2)초 동안 x:(10) y:(10) 위치로 이동하기] 블록을 넣습니다.
계산 시간 입력칸에 [1]부터 [3] 사이의 무작위 수 블록을 끼워 넣습니다.
계산 x 위치에 [-200]부터 [200] 사이의 무작위 수, y 위치에 [-120]부터 [120] 사이의 무작위 수 블록을 각각 연결합니다.
생김새 이동하기 바로 아래에 [색깔 효과를 (10)만큼 주기] 블록을 넣고, 값 입력칸에 [50]부터 [100] 사이의 무작위 수 블록을 연결합니다.
💡 코딩 쏙쏙 TIP : 둥근 값 블록 끼워 넣기
엔트리에서 양 끝이 둥근 블록은 '값(숫자나 문자)'을 나타내는 블록이에요. [( )부터 ( ) 사이의 무작위 수] 블록도 둥근 모양이므로, 시간·x좌표·y좌표·효과량처럼 둥근 입력칸이 있는 곳이라면 어디든 쏙 끼워 넣을 수 있답니다!
