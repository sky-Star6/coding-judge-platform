2. 특수 변수 '대답' - 이름을 묻고 인사하기

개념 & 실습
우리가 컴퓨터나 스마트폰 앱을 쓸 때 이름을 입력하면 화면에 "OOO님 환영합니다!" 하고 나타나는 기능을 본 적이 있나요? 💬
엔트리에는 사용자가 키보드로 입력한 글자를 자동으로 쏙 담아두는 특별한 변수 상자인 [대답]이 준비되어 있어요! 묻고 대답 기다리기와 문자 합치기를 사용하면 살아 숨 쉬는 대화형 프로그램을 만들 수 있답니다.
1
대답 변수 숨기기
시작할 때 기본으로 보이는 대답 창을 깔끔하게 숨깁니다 (대답 숨기기).
2
질문 창 띄우기
"이름을 입력해 주세요."를 묻고 화면 아래에 텍스트 입력창을 엽니다 (묻고 대답 기다리기).
3
사용자 입력 & 저장
사용자가 이름을 입력하고 [✔]를 누르면 입력한 내용이 [대답] 변수에 쏙 들어갑니다!
4
환영 인사 말하기
[대답]에 들어있는 이름과 "님 안녕하세요."를 합쳐서 2초 동안 멋지게 말합니다!

🎯 실습 미션 지시사항

오른쪽 엔트리 화면에서 [승무원] 오브젝트를 선택하고, 지시사항에 맞추어 블록을 조립해 보세요!
👩‍✈️ [승무원] 오브젝트 코딩 인사하기.ent
시작 [시작하기 버튼을 클릭했을 때] 블록 아래에 연결합니다.
자료 [대답 숨기기 ▾] 블록을 가져와 맨 위에 연결합니다.
자료 그 아래에 [(이름을 입력해 주세요.)을(를) 묻고 대답 기다리기] 블록을 연결합니다.
생김새 질문 블록 아래에 [(안녕!)을 (2)초 동안 말하기] 블록을 연결합니다.
계산 말하기 내용 칸에 [( )과(와) ( )을(를) 합치기] 블록을 끼워 넣습니다.
자료 합치기 블록 앞쪽에 [대답] 값 블록을 넣고, 뒤쪽 빈칸에는 "님 안녕하세요."를 직접 입력합니다.
💡 코딩 쏙쏙 TIP : [대답]은 엔트리가 제공하는 똑똑한 내장 변수!
사용자가 입력창에 글자를 치고 엔터를 누르는 순간, 엔트리는 그 내용을 자동으로 [대답]이라는 특별한 변수 상자에 저장해 둡니다. 나중에 이 값을 꺼내 쓰려면 [자료] > [대답] 블록을 가져와 원하는 곳에 쏙 끼워 넣기만 하면 돼요!
