2. 체험학습 장소 리스트 만들기

작품 실습

리스트에 자료를 추가하는 것에서 나아가 원하는 위치의 항목을 수정·삭제하거나 모두 비우는 리스트 관리 프로그램을 만들어 볼까요? 🎒

4가지 버튼(입력하기, 수정하기, 삭제하기, 모두삭제)을 클릭하면 각각의 신호가 전달되고, 엔트리봇이 신호를 받아 체험학습 장소 리스트를 똑똑하게 관리합니다!

🎒 장소 리스트 입력 · 관리 ↓
1
입력하기 (자료 추가)
[입력하기] 신호가 오면 장소를 묻고 리스트에 추가합니다.
2
수정하기 (항목 바꾸기)
번호를 저장하고 새 장소를 물어 (번호)번째 항목을 바꿉니다.
3
삭제하기 (항목 삭제)
지울 번호를 묻고 [대답]번째 항목을 쏙 삭제합니다.
4
모두삭제 (전체 비우기)
Y/y 확인 후 항목 수만큼 반복하여 1번째 항목을 지워 비웁니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [엔트리봇]과 4개의 버튼 오브젝트를 선택하고 아래 블록들을 조립해 보세요!
⭐ [엔트리봇] 오브젝트 코딩
(1) 입력하기 신호를 받았을 때 (장소 추가)
시작 [( 입력하기 ▼ ) 신호를 받았을 때] 블록을 배치합니다.
자료 아래에 [( 체험학습 장소를 입력해 주세요. ) 을(를) 묻고 대답 기다리기] 블록을 연결합니다.
자료 아래에 [( [대답] ) 항목을 ( 체험학습장소 ▼ ) 에 추가하기] 블록을 연결합니다.
(2) 수정하기 신호를 받았을 때 (항목 바꾸기)
시작 [( 수정하기 ▼ ) 신호를 받았을 때] 블록을 배치합니다.
자료 아래에 [( 몇 번 장소를 수정할까요? ) 을(를) 묻고 대답 기다리기] 블록을 연결합니다.
자료 아래에 [( 번호 ▼ ) 를 ( [대답] ) 으로 정하기] 블록을 연결합니다.
자료 아래에 [( 수정할 체험학습 장소를 입력해 주세요. ) 을(를) 묻고 대답 기다리기] 블록을 연결합니다.
자료 아래에 [( 체험학습장소 ▼ ) 의 ( [번호 값] ) 번째 항목을 ( [대답] ) 으로 바꾸기] 블록을 연결합니다.
(3) 삭제하기 신호를 받았을 때 (특정 항목 삭제)
시작 [( 삭제하기 ▼ ) 신호를 받았을 때] 블록을 배치합니다.
자료 아래에 [( 몇 번 장소를 삭제할까요? ) 을(를) 묻고 대답 기다리기] 블록을 연결합니다.
자료 아래에 [( 체험학습장소 ▼ ) 의 ( [대답] ) 번째 항목 삭제하기] 블록을 연결합니다.
(4) 모두삭제 신호를 받았을 때 (전체 비우기)
시작 [( 모두삭제 ▼ ) 신호를 받았을 때] 블록을 배치합니다.
자료 아래에 [( 모두 지우시겠습니까? Y/N ) 을(를) 묻고 대답 기다리기] 블록을 연결합니다.
흐름 아래에 [만일 < 참 > 이라면] 블록을 연결하고, 조건 칸에 [( ( Y ) = ( [대답] ) ) 또는 ( ( y ) = ( [대답] ) )](판단)을 넣습니다.
흐름 만일 안쪽에 [( [체험학습장소 항목수] ) 번 반복하기] 블록을 넣습니다.
자료 반복 안쪽에 [( 체험학습장소 ▼ ) 의 ( 1 ) 번째 항목 삭제하기] 블록을 넣습니다.
⭐ [입력하기 · 수정하기 · 삭제하기 · 모두삭제] 버튼 코딩
(1) 각 버튼 오브젝트를 클릭했을 때 (신호 보내기)
시작 [입력하기]: [오브젝트를 클릭했을 때] → [( 입력하기 ▼ ) 신호 보내기]
시작 [수정하기]: [오브젝트를 클릭했을 때] → [( 수정하기 ▼ ) 신호 보내기]
시작 [삭제하기]: [오브젝트를 클릭했을 때] → [( 삭제하기 ▼ ) 신호 보내기]
시작 [모두삭제]: [오브젝트를 클릭했을 때] → [( 모두삭제 ▼ ) 신호 보내기]
💡 TIP : 리스트 모두삭제의 비밀!

리스트에서 1번째 항목을 삭제하면, 뒤에 있던 2번·3번 항목들이 자동으로 한 칸씩 앞으로 당겨집니다! 따라서 전체 항목 수만큼 반복하면서 매번 1번째 항목만 지워도 리스트 전체가 깔끔하게 비워집니다!
