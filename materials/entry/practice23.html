그림 개수 맞추기

창의 실습

화면에 무작위 개수로 등장하는 그림(선물, 왕관, 모자)의 개수를 세어 맞히는 순발력 퀴즈 게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 복제본 개수 제어, 신호 보내기, 확인 함수와 초시계 기록 측정 원리를 익힌 뒤, 나만의 퀴즈 게임으로 확장해 보세요!

1
무작위 그림 복제
선물·왕관·모자 신호를 받으면 개수(1~10)만큼 복제본을 화면 곳곳에 배치합니다.
2
정답 확인 함수
사용자가 입력한 대답과 개수를 비교해 정답이면 다음 단계, 오답이면 종료합니다.
3
플레이 시간 기록 발표
3문제를 모두 맞히면 숨기기 신호로 그림을 지우고 초시계 기록을 말합니다.

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기] 버튼을 클릭합니다.
  2. "퀴즈를 시작합니다." 안내 후 화면에 나타난 선물, 왕관, 모자의 개수를 빠르게 세어 입력창에 숫자를 입력하고 엔터를 누르세요.
  3. 3문제를 모두 맞히면 승무원이 총 초시계 플레이 시간을 발표합니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
💡 자신만의 아이디어로 업그레이드해 보세요!
기본 동작을 완성했다면, 아래 미션 중 1~2가지를 골라 나만의 퀴즈 게임으로 발전시켜 보세요.
  1. 그림 개수 늘리기: 1~10 대신 5~20개까지 더 많은 그림이 나오도록 난이도를 높여 보세요.
  2. 성공 / 실패 장면 추가: 모든 문제를 맞혔을 때와 틀렸을 때 각각 전용 장면으로 전환되도록 만들어 보세요.
  3. 제한 시간 모드 추가: 정해진 제한 시간(예: 15초) 내에 문제를 못 풀면 실패 배경 화면으로 바뀌도록 수정해 보세요.
