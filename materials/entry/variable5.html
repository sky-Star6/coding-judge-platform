5. 사고력 Test - 튕기는 바운스볼 만들기

사고력 실습

실제 공이 떨어질 때는 중력 때문에 점점 빨라지고, 바닥에 부딪히면 위로 힘차게 튕겨 오릅니다! 🏀

[높이] 변수로 공중에 있을 때는 값을 -1씩 빼서 떨어지게 하고, [막대]에 닿는 순간 높이를 10으로 정해주면 통통 튕기는 바운스볼 게임이 완성됩니다!

🏀 중력 바운스 속도 · 충돌 ↓
1
좌우 방향키 조작
왼쪽/오른쪽 화살표 키를 누르면 x 좌표를 -5 / 5만큼 바꿉니다.
2
중력 가속도 낙하
공중에 떠 있을 때는 [높이] 변수에 -1을 계속 더해 아래로 떨어집니다.
3
막대 충돌 & 점프
공이 [막대]에 닿는 순간 [높이]를 10으로 정해 위로 튕겨 오릅니다.
4
y 좌표 실시간 이동
매 순간 y 좌표를 [높이 값]만큼 바꾸어 부드러운 바운스를 구현합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [볼]을 선택하고, 아래 2개 실행 묶음의 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [볼] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (좌우 방향키 조작)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
흐름 반복 안쪽에 첫 번째 [만일 < 참 > 이라면] 블록을 넣습니다.
판단 조건 칸에 [< ( 왼쪽 화살표 ▼ ) 키를 눌렀는가? >] 블록을 넣습니다.
움직임 만일 안쪽에 [x 좌표를 ( -5 ) 만큼 바꾸기] 블록을 넣습니다.
흐름 아래에 두 번째 [만일 < 참 > 이라면] 블록을 나란히 연결합니다.
판단 조건 칸에 [< ( 오른쪽 화살표 ▼ ) 키를 눌렀는가? >] 블록을 넣습니다.
움직임 만일 안쪽에 [x 좌표를 ( 5 ) 만큼 바꾸기] 블록을 넣습니다.
(2) 시작하기 버튼을 클릭했을 때 (중력 낙하 및 막대 바운스)
시작 두 번째 [시작하기 버튼을 클릭했을 때] 블록을 새로 배치합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
움직임 반복 안쪽 맨 위에 [y 좌표를 ( [높이 값] ) 만큼 바꾸기] 블록을 넣습니다.
흐름 아래에 [만일 < 참 > 이라면 / 아니면] 블록을 연결합니다.
판단 조건 칸에 [< ( 막대 ▼ ) 에 닿았는가? >] 블록을 끼워 넣습니다.
자료 '만일 참' 안쪽에는 [( 높이 ▼ ) 를 ( 10 ) 으로 정하기], '아니면' 안쪽에는 [( 높이 ▼ ) 에 ( -1 ) 만큼 더하기] 블록을 각각 넣습니다.
💡 TIP : 점프와 중력 가속도의 비밀

게임 속 공이 위로 솟구쳤다가 점점 빠르게 떨어지는 원리는 바로 [높이] 변수 덕분이에요! 막대에 닿을 때 높이를 큰 양수(10)로 정해주고, 공중에 있을 때는 매 순간 -1을 계속 더해주면 자연스럽게 감속과 가속이 일어납니다.
