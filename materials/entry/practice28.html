실습 28 엔트리 실습

물고기 키우기

창의 실습

바닷속을 헤엄치며 나보다 작은 물고기를 먹어 크기를 키우고, 큰 물고기를 피해 살아남는 물고기 키우기 생존 게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 오브젝트 크기 비교, 시작 버튼 재시작 신호, 양쪽 복제 물고기 생성 원리를 익힌 뒤 나만의 해양 생존 게임으로 확장해 보세요!

1
시작 버튼 & 방향키 이동
시작 버튼을 클릭하면 게임시작 신호가 전송되고, 크기 15의 물고기가 방향키로 이동합니다.
2
작은 물고기 먹기 & 성장
좌/우에서 5~100 크기로 나타나는 주황·빨간 물고기 중 나보다 작은 물고기에 닿으면 크기 신호로 +2씩 커집니다.
3
승리 / 게임 종료 & 재시작
크기가 50을 넘으면 승리, 큰 물고기에 닿으면 게임끝 신호로 복제본이 지워지고 시작 버튼이 다시 나타납니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오에서 [물고기] 오브젝트를 선택하고, [속성 > 신호(게임시작, 게임끝, 크기)]와 좌/우 회전방식을 확인한 뒤 아래 블록들을 조립해 보세요!
⭐ 물고기 오브젝트 코딩
시작 (1) [시작하기 버튼을 클릭했을 때] → [모양 숨기기]
시작 (2) [( 게임시작 ) 신호를 받았을 때] → 모양 보이기, (0, 0) 이동, 크기 15로 정하기 → [계속 반복하기] 안에서 상/하/좌/우 방향키 이동(±3) 및 사방 벽 닿음 반사(±3) 처리
시작 (3) [( 게임시작 ) 신호를 받았을 때] → [계속 반복하기] 안에서 자신의 크기 > 50이면 "잘 먹었다." 1초 말하고 [( 게임끝 ) 신호 보내기]
시작 (4) [( 크기 ) 신호를 받았을 때] → [크기를 ( 2 ) 만큼 바꾸기]
⭐ 주황 물고기 · 빨간 물고기 오브젝트 코딩
시작 (1) [시작하기 버튼을 클릭했을 때] → [모양 숨기기]
시작 (2) [( 게임시작 ) 신호를 받았을 때] → [계속 반복하기] 안에서 [( 자신 )의 복제본 만들기] → 2~3초 기다리기
시작 (3) [( 게임끝 ) 신호를 받았을 때] → [모든 복제본 삭제하기]
흐름 (4) [복제본이 처음 생성되었을 때] → (빨간 물고기는 [좌우 모양 뒤집기]), 모양 보이기, 크기 5~100 무작위, x: -250(주황)/250(빨강), y: -120~120 이동 → 반대쪽 벽에 닿을 때까지 x를 2(주황)/-2(빨강)씩 이동하며 물고기에 닿으면 크기 비교 후 크기 또는 게임끝 신호 보내기
⭐ 시작 버튼 오브젝트 코딩
시작 (1) [오브젝트를 클릭했을 때] → [모양 숨기기] → [( 게임시작 ) 신호 보내기]
시작 (2) [( 게임끝 ) 신호를 받았을 때] → [모양 보이기]

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기] 버튼을 클릭한 뒤, 화면 안의 [시작 버튼]을 클릭합니다.
  2. 방향키(↑, ↓, ←, →)로 작은 물고기를 조종해 나보다 작은 물고기를 찾아 먹으며 크기를 키우세요.
  3. 내 크기가 50을 넘으면 승리하며, 더 큰 물고기에 닿아 끝나면 다시 나타난 시작 버튼으로 재도전할 수 있습니다.
