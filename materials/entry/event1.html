1. 이벤트(Event)란 무엇일까요?

개념으로 알아보기

엔트리 프로그램에서 특정 키보드의 키를 누르거나, 마우스를 클릭하거나, 특정 오브젝트를 직접 터치했을 때처럼 어떤 사건(이벤트)이 일어났을 때 실행되는 명령을 이벤트라고 합니다.
시작하기 버튼 외에도 다양한 입력을 감지해 스스로 반응하는 똑똑한 프로그램을 만들어 봅니다!

1
마우스 클릭 이벤트: 화면 속 오브젝트를 마우스로 직접 콕 클릭했을 때 즉시 지정된 코드를 실행합니다.
2
키보드 누름 이벤트: 키보드의 스페이스(Space) 키 등을 눌렀을 때 컴퓨터가 입력을 즉시 알아채고 코드를 실행합니다.
3
개별 상호작용: 2마리의 엔트리봇이 각자의 이벤트에만 따로따로 반응하여 즐겁게 인사합니다!

🎯 실습 미션: 2마리 엔트리봇 이벤트 코딩

오른쪽 엔트리 화면 아래 오브젝트 목록에서 [엔트리봇(오브젝트클릭)]과 [엔트리봇(키보드누름)]을 차례대로 선택하고 지시사항에 맞게 블록을 완성해 보세요!

🐭 [엔트리봇(오브젝트클릭)] : 마우스로 콕 누르면 인사하기
시작 [오브젝트를 클릭했을 때]
생김새 [안녕! 을(를) 2 초 동안 말하기]
⌨️ [엔트리봇(키보드누름)] : 스페이스 키를 누르면 인사하기
시작 [스페이스 키를 눌렀을 때]
생김새 [안녕! 을(를) 2 초 동안 말하기]
💡 TIP : 블록에서 키보드의 키 선택하기

• [시작] > [q 키를 눌렀을 때] 블록의 키 부분(q)을 마우스로 클릭하면 키보드 모양 대화상자가 화면에 나타납니다.
• 원하는 키(예: 스페이스(Space))를 누르면 원하는 키를 감지하는 이벤트 블록으로 자유롭게 변경할 수 있습니다!
