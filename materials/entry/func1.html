학습중

1. 함수의 정의와 소피 이동하기

개념 설명

자주 사용하는 여러 블록들을 하나로 묶어 나만의 새로운 블록으로 만드는 마법, 함수(Function)를 배워봅시다! 📦

모양 바꾸기·이동 방향 정하기·움직이기 블록들을 이동 함수로 묶어두면, 방향키를 누를 때 함수 블록 한 줄만으로 소피를 깔끔하게 움직일 수 있어요!

📦 함수 정의 조립 · 호출 ↓
1
함수 정의하기
모양 바꾸기 + 이동 방향 각도 + 움직이기를 묶어 좌·우 이동 함수를 만듭니다.
2
기본 모양 유지
[계속 반복하기] 안에서 기본 [정면] 모양으로 바꾸기를 유지합니다.
3
방향키로 함수 호출
좌·우 화살표 키가 눌리면 이동 함수에 ( 3 )을 넣어 호출합니다!

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [소피]를 선택하고, 아래 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [소피] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (방향키 함수 이동)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
생김새 반복 안쪽 맨 위에 [( 정면 ▼ ) 모양으로 바꾸기] 블록을 넣습니다.
흐름 아래에 첫 번째 [만일 < 참 > 이라면] 블록을 연결합니다.
판단 조건 칸에 [< ( 왼쪽 화살표 ▼ ) 키가 눌려져 있는가? >] 블록을 끼웁니다.
함수 만일 안쪽에 [왼쪽으로 ( 3 ) 만큼 이동하기] 블록을 넣습니다.
흐름 아래에 두 번째 [만일 < 참 > 이라면] 블록을 연결합니다.
판단 조건 칸에 [< ( 오른쪽 화살표 ▼ ) 키가 눌려져 있는가? >] 블록을 끼웁니다.
함수 만일 안쪽에 [오른쪽으로 ( 3 ) 만큼 이동하기] 블록을 넣습니다.
💡 TIP : 함수를 사용하면 무엇이 좋을까요?

1. 코드 절약: 반복되는 여러 명령 블록을 매번 새로 꺼내 조립할 필요가 없습니다.
2. 빠른 수정: 이동 속도나 각도를 바꾸고 싶을 때 함수 안의 내용만 한 번 고치면 호출한 모든 곳에 바로 적용됩니다!
