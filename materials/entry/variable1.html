1. 변수란? - 변수로 구구단 2단 외우기

개념 설명

변수(Variable)란 변하는 수를 의미하며, 컴퓨터 메모리에 데이터(값)를 임시로 담아두는 특별한 상자예요! 📦

앞선 8단원에서는 9개의 말하기 블록을 일일이 조립했지만, 숫자 변수와 9번 반복하기를 활용하면 단 1개의 블록 묶음으로 2*1=2부터 2*9=18까지 스마트하게 외울 수 있답니다!

📦 변수 구구단 반복 계산 ↓
1
변수 초기화
시작할 때 숫자 변수 상자의 값을 0으로 깨끗이 비웁니다.
2
9번 반복하기
구구단 1부터 9까지 외우기 위해 9회 반복 루프를 실행합니다.
3
변수 1 증가
루프가 1번 돌 때마다 숫자 변수에 1을 더합니다 (1, 2, 3 ... 9).
4
스마트 말하기
'2*' + 숫자값 + '=' + (2 * 숫자값)을 계산하여 1초 동안 말합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [유치원생]을 선택하고, 아래 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [유치원생] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (변수로 구구단 2단 출력)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
자료 아래에 [( 숫자 ▼ ) 를 ( 0 ) 으로 정하기] 블록을 연결합니다.
흐름 아래에 [( 10 ) 번 반복하기] 블록을 연결하고, 반복 횟수를 ( 9 )로 바꿉니다.
자료 반복 안쪽 맨 위에 [( 숫자 ▼ ) 에 ( 1 ) 만큼 더하기] 블록을 넣습니다.
생김새 아래에 [( 안녕! ) 을(를) ( 4 ) 초 동안 말하기] 블록을 연결하고, 시간을 ( 1 )초로 바꿉니다.
계산 말하기 칸에 [합치기] 블록들을 중첩해 ( 2* ) + [숫자 값] + ( = ) + [( 2 ) * ( [숫자 값] )] 형태로 조립합니다.
💡 TIP : 변수를 쓰면 코드가 1/9로 줄어들어요!

변수를 쓰지 않았을 때는 9줄의 긴 코드가 필요했지만, 변수 숫자에 [숫자 값] 블록을 넣어주면 컴퓨터가 알아서 1, 2, 3... 9로 값을 바꿔가며 계산해 줍니다! 이것이 바로 프로그래밍에서 변수를 사용하는 핵심 비결이에요!
