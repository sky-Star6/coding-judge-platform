실습 17 엔트리 실습

두더지 잡기

창의 실습
20초 제한 시간 동안 무작위 타이밍으로 쏙쏙 올라오는 6마리의 두더지를 마우스 뿅망치로 내려쳐 점수를 올리는 두더지 잡기 게임입니다! 🔨🐹⏱️
엔트리 실습은 정해진 하나의 정답이 없습니다. 마우스 클릭 회전 애니메이션과 때렸다 신호를 이용한 다중 오브젝트 판정 원리를 익히고, 나만의 아케이드 게임으로 확장해 보세요!
1
뿅망치 조종 & 내려치기 신호
뿅망치가 마우스를 따라다니며 클릭할 때마다 -45° 회전 후 때렸다 신호를 보내고 다시 +45° 돌아옵니다.
2
6마리 두더지 랜덤 출현 & 명중
각 두더지가 0.5~3초 무작위 간격으로 나타났다 숨으며, 때렸다 신호 시 뿅망치에 닿아 있으면 숨고 점수 +1을 올립니다.
3
20초 타이머 종료
들판(1) 배경이 초시계를 시작하고, 초시계 값 ≥ 20이 되면 초시계와 모든 코드를 멈춥니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 변수](점수), [속성 > 신호](때렸다) 및 오브젝트 설정(뿅망치 크기 50·방향 315°, 두더지 6마리 크기 70, 들판(1))을 확인한 뒤 코딩해 보세요!
⭐ [뿅망치] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 — 마우스 따라다니기
시작 [시작하기 버튼을 클릭했을 때] 아래에 [계속 반복하기]를 연결하고, 안에 [( 마우스 포인터 ▼ ) 위치로 이동하기]를 넣습니다.
(2) 마우스를 클릭했을 때 — 내려치기 & 신호 보내기
시작 [마우스를 클릭했을 때] 아래에 [( 0.1 ) 초 동안 방향을 ( -45˚ )만큼 회전하기]를 연결합니다.
시작 [때렸다 ▼ 신호 보내기]와 [( 0.1 ) 초 동안 방향을 ( 45˚ )만큼 회전하기]를 차례로 연결합니다.
⭐ [들판(1)] 오브젝트 코딩
시작 [시작하기 버튼을 클릭했을 때] 아래에 [초시계 ( 시작하기 ▼ )]와 [계속 반복하기]를 연결합니다.
흐름 [만일 < ( 초시계 값 ) ≥ ( 20 ) > (이)라면] 안에 [초시계 ( 정지하기 ▼ )]와 [( 모든 ▼ ) 코드 멈추기]를 넣습니다.
⭐ [두더지 ~ 두더지5] 오브젝트 코딩 (6마리 동일)
(1) 시작하기 버튼을 클릭했을 때 — 랜덤 나타나기/숨기
시작 [시작하기 버튼을 클릭했을 때] 아래에 [계속 반복하기]를 연결합니다.
흐름 [( ( 0.5 ) 부터 ( 3 ) 사이의 무작위 수 ) 초 기다리기], [모양 보이기], [( ( 0.5 ) 부터 ( 3 ) 사이의 무작위 수 ) 초 기다리기], [모양 숨기기]를 차례로 넣습니다.
(2) 때렸다 신호를 받았을 때 — 명중 판정
시작 [때렸다 ▼ 신호를 받았을 때] 아래에 [만일 < ( 뿅망치 ▼ ) 에 닿았는가? > (이)라면]을 연결합니다.
자료 안쪽에 [모양 숨기기]와 [점수 ▼ 에 ( 1 ) 만큼 더하기]를 넣습니다. (필요 시 [소리] 탭에서 효과음을 추가해 [소리 재생하기]도 함께 넣어보세요!)
팁 첫 번째 두더지에 코드를 완성한 뒤 우클릭 > 코드 복사하기로 나머지 두더지1~5에 붙여넣으면 금방 완성됩니다!

🎮 실행 및 조작 방법

조작 가이드
모든 오브젝트를 코딩한 뒤 20초 동안 몇 마리를 잡을 수 있는지 도전해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하면 초시계가 시작되고 6마리 두더지가 랜덤으로 얼굴을 내밉니다.
2. 마우스로 뿅망치를 움직여 두더지 위에서 클릭해 내려치세요!
3. 20초가 지나면 게임이 자동으로 멈추며 최종 점수를 확인할 수 있습니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
교재 추가 도전 미션으로 나만의 두더지 잡기 게임을 업그레이드해 보세요!
1. 글상자로 카운트다운 시작하기: 게임 시작 전 글상자를 이용해 3, 2, 1, 시작! 카운트다운을 보여준 뒤 두더지가 나오도록 만들어 보세요.
2. 함정 오브젝트(-5점) 추가: [+ 오브젝트 추가하기]로 폭탄이나 선인장 같은 함정 오브젝트를 추가하고, 이 오브젝트를 치면 점수가 -5점 깎이도록 수정해 보세요.
3. 보너스 황금 두더지: 가끔 등장해 잡으면 +3점을 주는 황금 두더지 모양(또는 오브젝트)을 만들어 보세요!
