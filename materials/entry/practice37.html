실습 37 엔트리 실습

인형뽑기

창의 실습

좌우 화살표 키로 집게를 움직이고 스페이스바로 내려가 인형을 집어 출구(검은 선 왼쪽)로 옮기는 아케이드 인형뽑기 게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 집게 이동·하강 타이밍, 집게팔 복제본 연결, 잡음 상태 변수 제어 원리를 익힌 뒤 나만의 인형뽑기 기계로 확장해 보세요!

1
집게 좌우 이동 & 하강·집기
화살표 키로 이동 후 스페이스바를 누르면 집게가 y: -110까지 내려가 오므린 뒤(모양 2) 올라와 x: -190으로 복귀합니다.
2
인형뽑기팔 연결선 그리기
인형뽑기팔이 집게 위(y+90)를 따라다니며 집게그리기 = 0일 때 복제본을 남겨 줄이 늘어나는 효과를 만듭니다.
3
곰인형 잡기 & 출구 낙하
집게(모양 2)에 닿으면 잡음 = 1이 되어 집게를 따라오다가, 집게가 열리면(모양 1) 아래쪽 벽까지 떨어집니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오에서 [[묶음] 인형뽑기 집게] 오브젝트를 선택하고, [속성 > 변수(잡음, 집게그리기) / 신호(시작)]를 확인한 뒤 아래 블록들을 조립해 보세요!
⭐ [묶음] 인형뽑기 집게 오브젝트 코딩
시작 (1) [시작하기 버튼을 클릭했을 때] → 시작 신호 보내기
움직임 (2) [( 시작 ) 신호를 받았을 때] → 인형뽑기 집게(1)_1 모양, (-190, 40) 이동 → 계속 집게그리기 = 1, 좌/우 키로 x ±5 이동
흐름 (3) 스페이스 키를 누르면 → 집게그리기 = 0 → 1초 동안 (현재 x, -110) 이동 → 집게_2 모양 → 집게그리기 = 1 → 1초 대기 → 1초 동안 (현재 x, 40) 복귀 → x ≤ -190 될 때까지 -3씩 이동 → x: -190, 0.5초 대기 → 집게_1 모양 → 잡음 = 0, 집게그리기 = 0
⭐ 인형뽑기팔 · 곰인형 오브젝트 코딩
움직임 [인형뽑기팔] 시작 신호 시 집게 모양 번호 1이면 (집게 x, 집게 y + 90), 아니면 (집게 x + 7, 집게 y + 90) 위치 따라가기 / 집게그리기 = 0이면 복제본 생성(복제본은 보이고 0.3초 후 집게에 닿으면 숨기기)
흐름 [곰인형] 시작 신호 시 (-110~200 무작위, -50) 이동 → 집게에 닿고 집게 모양 번호 2이며 잡음 = 0이면 잡음 = 1 설정 후 집게 모양 1이 될 때까지 집게 위치로 이동 (아니면 아래쪽 벽까지 y: -5 이동)

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기] 버튼을 클릭합니다.
  2. 왼쪽/오른쪽 화살표 키(← / →)로 곰인형 위까지 집게를 이동시킨 뒤 스페이스바를 누르세요.
  3. 집게가 인형을 잡아 검은 벽 왼쪽(x: -190)으로 옮겨 놓는지 확인해 보세요!

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
💡 자신만의 인형뽑기 게임으로 업그레이드해 보세요!
기본 동작을 완성했다면, 아래 미션 중 1~2가지를 골라 완성도를 높여 보세요.
  1. 실패 확률 적용하기: 집게가 올라오는 도중 무작위 확률로 잡음 = 0이 되어 인형이 떨어지는 긴장감을 추가해 보세요.
  2. 동전·지폐 투입 시스템: 500원 넣으면 1판, 1000원 넣으면 3판씩 횟수가 올라가도록 남은횟수 변수를 추가해 보세요.
  3. 다양한 인형 추가: [오브젝트 추가하기]로 여러 종류의 인형을 배치하고 인형마다 점수를 다르게 정해 보세요.
