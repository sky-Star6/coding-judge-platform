로봇&엔트리

창의 실습
우주선을 탄 엔트리봇과 새 로봇이 각각 불꽃과 검은 돌멩이를 복제 발사하며 1대1 슈팅 대결을 펼치는 액션 게임입니다! 🚀🔥🦜
엔트리 실습은 정해진 하나의 정답이 없습니다. 변수로 양쪽 체력을 관리하고 체력에 따라 보스(새 로봇)의 움직임 패턴을 바꾸는 원리를 익힌 뒤, 나만의 슈팅 게임으로 확장해 보세요!
1
엔트리봇 위/아래 조종 & 불 발사
↑ / ↓ 키로 y좌표를 10 / -10 이동하고, 스페이스 키를 누르면 불(3) 복제본이 회전하며 오른쪽으로 날아갑니다.
2
새 로봇 패턴 변화 & 돌멩이 반격
새 로봇은 새봇체력이 5보다 작아지면 순간 이동 패턴으로 바뀌며, 검은 돌멩이를 290~250° 부채꼴 방향으로 계속 발사합니다.
3
체력 1 미만 달성 시 승패 결정
공격이 명중할 때마다 상대 체력이 -1씩 줄어들고, 봇체력 또는 새봇체력이 1보다 작아지면 대사를 말하고 모든 코드가 멈춥니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 변수](봇체력, 새봇체력)와 4개 오브젝트 설정(우주선 탄 엔트리봇 크기 50·x: -210, 불(3) 20, 새 로봇 40·x: 210, 검은 돌멩이 20)을 확인한 뒤 코딩해 보세요!

흐름 [만일 < ( 아래쪽 화살표 ▼ ) 키가 눌러져 있는가? > (이)라면] 안에 [y 좌표를 ( -10 )만큼 바꾸기]를 넣습니다.

(2) 복제본이 처음 생성되었을 때 (오른쪽으로 회전 발사)
흐름 [복제본이 처음 생성되었을 때] 아래에 [모양 보이기]와 [( 우주선 탄 엔트리봇 ▼ ) 위치로 이동하기]를 연결합니다.
흐름 [< ( 벽 ▼ ) 에 닿았는가? > ( 이 될 때까지 ▼ ) 반복하기] 블록을 연결합니다.

흐름 [만일 < ( 새 로봇 ▼ ) 에 닿았는가? > (이)라면] 안에 [새봇체력 ▼ 에 ( -1 ) 만큼 더하기]와 [이 복제본 삭제하기]를 넣습니다.

🎮 실행 및 조작 방법

조작 가이드
모든 오브젝트를 코딩한 뒤, 아래 순서대로 보스 대결을 테스트해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하면 새 로봇이 위아래로 움직이며 검은 돌멩이를 발사합니다.
2. 키보드 ↑ / ↓ (위·아래 화살표)로 돌멩이를 피하면서 스페이스(Space) 키를 눌러 불(3)을 발사하세요!
3. 새봇체력이 5보다 작아지면 새 로봇이 순간 이동 패턴으로 변신하고, 어느 한쪽 체력이 1 미만이 되면 대사를 말하며 게임이 종료됩니다! 🚀🔥

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
교재 추가 도전 미션으로 나만의 보스 슈팅 게임을 업그레이드해 보세요!
1. 새 로봇 움직임 변화 & 체력 늘리기: 시간이 흐를수록 새 로봇의 이동 패턴을 더 다양하게 바꾸고 체력도 늘려 보세요.
2. 강력한 추가 발사체 추가: [+ 오브젝트 추가하기]로 새 로봇의 두 번째 발사체를 만들고, 닿으면 봇체력이 -3만큼 줄어들도록 차별화해 보세요.
3. 시작 버튼 오브젝트로 출발: 시작 버튼을 추가하고 클릭했을 때 신호를 보내 게임이 시작되도록 구조를 수정해 보세요!
