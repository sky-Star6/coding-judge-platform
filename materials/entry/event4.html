4. 사고력 Test 01 영화관 신호 만들기

사고력 TEST

영화관 무인 키오스크에서 번호 단추(1관~4관)를 누르면 해당 상영관의 영화 포스터가 대형 스크린에 안내되고, 관객이 영화에 몰입할 수 있도록 번호 단추들이 잠시 숨겨졌다가 2초 후 다시 나타나는 신호 통신 시스템을 만들어 봅니다!

📡 영화관 다중 신호 통신 매커니즘
1
단추 클릭 & 다중 신호 전송: 1관 단추를 클릭하면 [1관신호]와 [버튼숨김] 신호를 연이어 전송합니다.
2
상영작 포스터 전환 & 복귀: [1관신호]를 받은 [영화소개]가 모양을 1관 포스터(남극을 가다!!)로 바꾸고, 2초 후 다시 메인 화면으로 복귀합니다.
3
버튼 일괄 숨김 & 재등장: [버튼숨김] 신호를 받은 모든 번호 단추(1~4관)가 모양을 숨기고 2초 후 다시 화면에 나타납니다.

🎯 실습 미션: 영화소개 및 번호 단추 코딩

오른쪽 엔트리 화면 아래 오브젝트 목록에서 [영화소개]와 [1관 ~ 4관] 번호 단추를 차례로 선택하고, 아래 지시사항에 맞추어 블록을 조립하세요!

🎬 [영화소개 오브젝트: 4개 관 신호 처리]

1관, 2관, 3관, 4관 신호를 받았을 때 각각 해당 상영관 모양으로 바꾸고 2초 뒤 메인으로 되돌립니다.

시작 [[1관신호 / 2관신호 / 3관신호 / 4관신호] 신호를 받았을 때]
생김새 [[1관 / 2관 / 3관 / 4관] 모양으로 바꾸기]
흐름 [2] 초 기다리기
생김새 [[메인] 모양으로 바꾸기]
🔘 [1관 ~ 4관 오브젝트: 클릭 이벤트 & 숨김 제어]
1. 클릭 시 신호 보내기 (스레드 1):
시작 [오브젝트를 클릭했을 때]
시작 [[○관신호] 신호 보내기] (1관은 1관신호, 2관은 2관신호...)
시작 [[버튼숨김] 신호 보내기]
2. 버튼숨김 신호 받았을 때 (스레드 2):
시작 [[버튼숨김] 신호를 받았을 때]
생김새 [모양 숨기기]
흐름 [2] 초 기다리기
생김새 [모양 보이기]
교재 실전 코딩 TIP: 마우스 우클릭 [코드 복사] 활용하기!
1관 단추에 코드를 완성한 후 블록 뭉치 위에서 마우스 우클릭 > [코드 복사]를 누르세요!
