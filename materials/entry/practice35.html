돈 벌기

창의 실습

마우스로 룰렛 화살표를 조준·발사해 화면 위를 뛰어다니는 오백원·백원 동전을 맞추어 돈을 모으는 카운트다운 슈팅 게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 카운트(매개변수) 함수, 마우스 조준 복제 발사, 장면 2 방해꾼(엔트리 동전) 원리를 익힌 뒤 나만의 게임으로 확장해 보세요!

1
카운트다운 함수 & 시작
글상자 안내 후 카운트(3 → 2 → 1) 함수가 커지며 카운트다운을 마치고 시작 신호를 보냅니다.
2
화살표 조준 발사 & 동전 획득
룰렛 화살표가 마우스를 바라보고 클릭 시 복제본을 발사해 오백원동전(+500)·백원동전(+100)을 맞춥니다.
3
제한 시간 & 장면 2 엔트리 동전
와이파이 초시계가 10초가 되면 장면 2(20초)로 넘어가며, 엔트리 동전에 닿으면 -300원 감점됩니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오에서 [룰렛 화살표] 오브젝트를 선택하고, [속성 > 변수(모은돈) / 신호(시작, 끝, 카운트) / 함수(카운트)]를 확인한 뒤 아래 블록들을 조립해 보세요!
⭐ 숫자 버튼 · 글상자 · 와이파이 오브젝트 코딩
함수 [숫자 버튼] 함수 카운트(문자/숫자값 1): 크기 0으로 정하기 → (문자/숫자값 1) 모양 바꾸기 → 50번 반복하며 크기 2만큼 바꾸기 / 카운트 신호 시 3, 2, 1 실행 후 시작 신호 보내고 숨기기
시작 [글상자] 시작 시 "마우스를 클릭하여 10초 동안 벌기" 1초 글쓰기 → 모두 지우기 → 카운트 신호 / 끝 신호 시 "번 돈은 " + 모은돈 + "원 입니다." 글쓰기 → 장면 2 시작
계산 [와이파이] 시작 신호 시 초시계 시작 → 초시계 값 ≥ 10이면 정지하고 끝 신호 보내기 (장면 2에서는 초시계 초기화 추가 후 20초)
⭐ 룰렛 화살표 · 오백원동전 · 백원동전 · 엔트리 동전 코딩
움직임 [룰렛 화살표] 시작 신호 시 보이고 0° → 마우스 포인터 바라보기, 마우스 클릭 시 복제하고 0.3초 대기 → 복제본은 10씩 이동(벽 삭제, 오백원동전 +500 / 백원동전 +100 후 삭제)
흐름 [오백원 · 백원동전] 시작 신호 시 보이고 계속 (-180~180, 30~120) 무작위 위치로 이동 → 0.1~0.5초 무작위 기다리기
생김새 [엔트리 동전 (장면 2)] 5씩 이동 + 벽 튕기기 → 룰렛 화살표에 닿으면 모은돈 -300, (크기 +10, 다음 모양, 0.1초) 4번 반복 → 크기 -40

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기] 버튼을 클릭하고 3, 2, 1 카운트다운을 기다립니다.
  2. 마우스를 움직여 룰렛 화살표를 조준하고, 클릭해서 화살표를 발사해 오백원·백원 동전을 맞추세요.
  3. 10초가 지나 장면 2로 넘어가면 움직이는 엔트리 동전을 피해 20초 동안 최대한 많은 돈을 모아보세요!

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작

  3. 코인 추가 효과음: [소리] 탭에서 동전을 맞출 때 경쾌한 코인추가 효과음을 재생해 보세요.
