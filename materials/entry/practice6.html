실습 06 엔트리 실습

바운스볼

창의 실습
농구공이 막대에 닿을 때마다 위로 통통 튀어 오르고, 좌·우 화살표 키로 발판을 건너다니며 잔상 효과를 남기는 아케이드 바운스볼 게임입니다! 🏀✨
엔트리 실습은 정해진 하나의 정답이 없습니다. 기본 지문으로 중력 가속도와 복제본 잔상 원리를 익히고, 나만의 스테이지로 멋지게 확장해 보세요!
1
변수 숨기기 & 좌우 조종
높이 변수를 숨긴 뒤 ← / → 화살표 키로 농구공을 x축(-5 / +5) 이동합니다.
2
중력 & 막대 반동 점프
y좌표를 높이만큼 바꾸며, 막대에 닿으면 10으로 튀어 오르고 허공에서는 -1씩 감소합니다.
3
복제본 꼬리 잔상 효과
0.01초마다 자신을 복제하고, 복제본은 투명도와 크기를 줄이다가 삭제되어 부드러운 꼬리를 만듭니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오의 [속성 > 변수] 탭에서 높이 변수를 확인하고, [농구공(크기 20)]과 그리기 [막대] 오브젝트가 준비된 상태에서 농구공에 아래 블록을 조립해 보세요! (막대 발판은 모양 탭에서 직접 수정할 수도 있습니다.)
⭐ [농구공] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (변수 숨기기 & 좌우 이동)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
자료 [변수 ( 높이 ▼ ) 숨기기] 블록을 연결합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
흐름 [만일 < ( 왼쪽 화살표 ▼ ) 키가 눌러져 있는가? > (이)라면]을 넣습니다.
움직임 안쪽에 [x 좌표를 ( -5 )만큼 바꾸기]를 넣습니다.
흐름 이어서 [만일 < ( 오른쪽 화살표 ▼ ) 키가 눌러져 있는가? > (이)라면]을 넣습니다.
움직임 안쪽에 [x 좌표를 ( 5 )만큼 바꾸기]를 넣습니다.
(2) 시작하기 버튼을 클릭했을 때 (중력 & 막대 튕기기)
시작 두 번째 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
흐름 [계속 반복하기] 블록을 연결합니다.
움직임 반복 안쪽에 [y 좌표를 ( 높이 ▼ 값 )만큼 바꾸기]를 넣습니다.
흐름 아래에 [만일 < ( 막대 ▼ ) 에 닿았는가? > (이)라면 ~ 아니면 ~] 블록을 넣습니다.
자료 (참) 안쪽에 [( 높이 ▼ ) 를 ( 10 )(으)로 정하기]를 넣습니다.
자료 (아니면) 안쪽에 [( 높이 ▼ ) 에 ( -1 )만큼 더하기]를 넣습니다.
(3) 장면이 시작되었을 때 (잔상 복제본 만들기)
시작 [장면이 시작되었을 때](또는 [시작하기 버튼을 클릭했을 때]) 블록을 배치합니다.
흐름 [계속 반복하기] 블록을 연결합니다.
흐름 반복 안쪽에 [( 0.01 ) 초 기다리기]와 [( 자신 ▼ ) 의 복제본 만들기]를 넣습니다.
(4) 복제본이 처음 생성되었을 때 (서서히 작아지며 사라지기)
흐름 [복제본이 처음 생성되었을 때] 블록을 배치합니다.
흐름 아래에 [( 10 ) 번 반복하기] 블록을 연결합니다.
생김새 반복 안쪽에 [( 투명도 ▼ ) 효과를 ( -3 )만큼 주기]와 [크기를 ( -3 )만큼 바꾸기]를 넣습니다.
흐름 이어서 [( 0.01 ) 초 기다리기]를 넣습니다.
흐름 반복문 바깥 아래에 [이 복제본 삭제하기] 블록을 연결합니다.

🎮 실행 및 조작 방법

조작 가이드
네 개의 블록 묶음을 조립한 뒤 아래 순서대로 점프해 보세요!
1. 오른쪽 화면에서 [▶ 시작하기]를 클릭하면 높이 변수가 숨겨지고 농구공이 아래 막대를 딛고 반복해서 튀어 오릅니다.
2. 키보드의 ← / → (왼쪽·오른쪽 화살표)를 눌러 좌우 발판 위로 공을 옮겨 보세요.
3. 공이 움직이는 경로마다 복제본이 투명해지고 작아지며 사라지는 꼬리 잔상을 확인할 수 있습니다! 🏀✨

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
교재 추가 도전 미션으로 나만의 바운스볼 스테이지를 만들어 보세요!
1. 목표 별 먹기 & 클리어: [+ 오브젝트 추가하기]에서 별 오브젝트를 추가해 가장 높은 발판 위에 올려두고, 농구공이 별에 닿으면 클리어 효과를 주거나 다음 장면으로 넘어가게 확장해 보세요.
2. 위험 함정 & 점프 소리: 바닥 빨간선·가시 장애물 오브젝트를 추가해 닿으면 처음 위치(0, -33)로 돌아가게 만들고, 막대에 닿을 때 통통 튀는 효과음을 넣어 보세요.
3. 직접 스테이지 디자인하기: [막대] 오브젝트의 모양 탭에서 색깔별로 다른 발판(높이 14 슈퍼 점프 발판 등)을 그려 나만의 바운스볼 맵을 설계해 보세요!
