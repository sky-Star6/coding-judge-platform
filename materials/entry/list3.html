3. 사고력 Test - 회원 명단에서 회원 검색하기

사고력 실습

리스트에 보관된 수많은 데이터 중에서 내가 찾는 자료가 들어있는지 빠르게 검색(Search)하는 기능을 만들어 볼까요? 🔍

방문객에게 이름을 물어보고 [회원명단] 리스트에 들어있는지 확인해, 회원이면 반갑게 환영하고 회원이 아니면 안내해 주는 똑똑한 안내 직원을 만들어 봅시다!

🔍 회원 검색 포함 검사 ↓
1
이름 묻고 대답받기
[계속 반복하기] 안에서 [이름을 입력해 보세요.] 묻고 대답을 기다립니다.
2
리스트 포함 여부 검사
[회원명단]에 [대답]이 포함되어 있는가?로 등록 여부를 판별합니다.
3
조건별 결과 말하기
회원이면 환영 인사를, 아니면 안내 문구를 2초 동안 말합니다.

🎯 실습 미션 지시사항

오른쪽 엔트리 스튜디오에서 [직원]을 선택하고, 아래 블록들을 지시사항에 맞게 조립해 보세요!
⭐ [직원] 오브젝트 코딩
(1) 시작하기 버튼을 클릭했을 때 (회원 검색 및 안내)
시작 [시작하기 버튼을 클릭했을 때] 블록을 배치합니다.
흐름 아래에 [계속 반복하기] 블록을 연결합니다.
자료 반복 안쪽에 [( 이름을 입력해 보세요. ) 을(를) 묻고 대답 기다리기] 블록을 넣습니다.
흐름 아래에 [만일 < 참 > 이라면 / 아니면] 블록을 연결합니다.
자료 조건 칸에 [( 회원명단 ▼ ) 에 ( [대답] ) 이(가) 포함되어 있는가?] 블록을 끼워 넣습니다.
생김새 '만일 참' 안쪽에 [( 안녕! ) 을(를) ( 2 ) 초 동안 말하기]를 넣고, [합치기](계산)로 [대답] + ( 님은 회원이 맞습니다. )를 연결합니다.
생김새 '아니면' 안쪽에 [( 안녕! ) 을(를) ( 2 ) 초 동안 말하기]를 넣고, [합치기](계산)로 [대답] + ( 님은 회원이 아닙니다. )를 연결합니다.
💡 TIP : 리스트 포함 여부 블록의 강력함!

데이터가 아무리 많아도 하나씩 비교할 필요 없이 [리스트]에 [값]이 포함되어 있는가? 블록 하나만 쓰면 컴퓨터가 리스트 전체를 순식간에 검색하여 참(True)인지 거짓(False)인지 바로 판단해 줍니다!
