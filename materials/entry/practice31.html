실습 31 엔트리 실습

번개피하기

창의 실습

하늘에서 무작위로 떨어지는 번개를 피해 엔트리봇을 좌우로 움직이는 액션 게임입니다!
엔트리 실습은 정해진 하나의 정답이 없습니다. 신호 보내기, 변수(생명·상태), 인공지능 읽어주기(TTS) 원리를 익힌 뒤 나만의 번개 피하기 게임으로 확장해 보세요!

1
좌우 이동 & 걷기 애니메이션
엔트리봇 변수가 0일 때 왼쪽/오른쪽 화살표 키를 누르면 이동하며 걷기 모양이 바뀝니다.
2
무작위 번개 복제본 낙하
번개(1)이 0.2~0.5초마다 복제본을 만들어 위(y: 130)에서 아래로 떨어집니다.
3
전기충격 신호 & 인공지능 읽어주기
번개에 닿으면 생명이 1 줄고 번개 신호로 전기충격과 "아" 음성이 재생되며, 생명 ≤ 0이면 "그만..."을 말하고 종료됩니다.

🎯 기본 실습 미션 가이드

오른쪽 엔트리 스튜디오에서 [엔트리봇] 오브젝트를 선택하고, [속성 > 변수(엔트리봇, 생명) / 신호(번개)]와 인공지능 [읽어주기] 블록을 확인한 뒤 아래 블록들을 조립해 보세요!
⭐ 엔트리봇 오브젝트 코딩
시작 (1) [시작하기 버튼을 클릭했을 때] → 목소리 설정(읽어주기) → 생명을 3으로 정하기 → [계속 반복하기] 안에서 엔트리봇 = 0이면 좌/우 화살표 키로 x좌표를 -5 / 5만큼 바꾸기 → 생명 ≤ 0이면 0.5초 대기 후 다른 코드 멈추기, "그만..." 읽어주기, 1초 대기 후 모든 코드 멈추기
시작 (2) [시작하기 버튼을 클릭했을 때] → [계속 반복하기] 안에서 엔트리봇 = 0일 때 오른쪽 키면 90°, 왼쪽 키면 270° 방향을 보고 걷는 엔트리봇 1 ↔ (1)엔트리봇_걷기2 모양(0.05초 간격) 반복
시작 (3) [( 번개 ) 신호를 받았을 때] → "아" 읽어주기 → [3번 반복하기] 안에서 전기충격 엔트리봇_1 ↔ 전기충격 엔트리봇_2 모양(0.05초 간격) → 걷는 엔트리봇 1 모양으로 바꾸기 → 엔트리봇을 0으로 정하기
⭐ 번개(1) 오브젝트 코딩
시작 (1) [시작하기 버튼을 클릭했을 때] → 모양 숨기기 → [계속 반복하기] 안에서 자신의 복제본 만들기 → 0.2부터 0.5 사이의 무작위 수 초 기다리기
시작 (2) [복제본이 처음 생성되었을 때] → 모양 보이기 → x: (-230 ~ 230 무작위), y: 130으로 이동 → [( 아래쪽 벽에 닿았는가? ) 이 될 때까지 반복하기] 안에서 y좌표를 -5만큼 바꾸기, 만약 엔트리봇에 닿고 (엔트리봇의 모양 번호 = 1 또는 2)라면 생명에 -1만큼 더하기, 엔트리봇을 1로 정하기, 번개 신호 보내고 기다리기, 이 복제본 삭제하기 → 반복 후 이 복제본 삭제하기

🎮 실행 및 조작 방법

조작 가이드
  1. 오른쪽 실행 화면 상단의 [▶ 시작하기] 버튼을 클릭합니다.
  2. 키보드의 왼쪽/오른쪽 화살표 키(← / →)로 엔트리봇을 움직여 떨어지는 번개를 피하세요.
  3. 번개에 3번 맞아 생명이 0이 되면 엔트리봇이 "그만..."이라고 말하며 게임이 종료됩니다.

🚀 창의 확장 도전 (☆ 추가 프로그램 ☆)

자유 창작
💡 자신만의 번개피하기 게임으로 업그레이드해 보세요!
기본 동작을 완성했다면, 아래 미션 중 1~2가지를 골라 완성도를 높여 보세요.
  1. 점수(버틴 시간) 추가: 점수 변수나 초시계를 추가해 번개를 피하며 버틴 시간을 기록해 보세요.
  2. 난이도 상승: 시간이 지날수록 번개가 떨어지는 속도(y좌표 -5 → -8)가 빨라지게 만들어 보세요.
  3. 배경 음악 & 번개 효과음: [소리] 탭에서 빗소리나 천둥소리를 추가해 실감나는 분위기를 연출해 보세요.
