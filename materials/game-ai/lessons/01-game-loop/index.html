STAGE 03 · 실전 VS CODE + KILO 5대 퀘스트

VS Code에서 내 게임 폴더를 열고 Kilo에게 순서대로 명령해 보세요!

내 컴퓨터에 my-arcade-game 폴더를 만든 뒤 VS Code로 열고, 아래 순서대로 Kilo Code 채팅창에 복사해 실행하세요.

STEP 0. 스타터 템플릿 받기 & VS Code + Kilo 세팅

스타터 템플릿 다운로드 (.zip)
1. 압축 풀고 VS Code로 열기

01-arcade-starter.zip 압축을 풀고, VS Code → File > Open Folder로 엽니다.

2. 확장 2개 설치

좌측 확장(Extensions) 탭에서 Kilo Code와 Live Server를 설치합니다.

3. .kilorules 자동 보호막

폴더 안의 .kilorules 파일 덕분에 Kilo가 한국어 주석을 달고 기존 코드를 안전하게 지켜줍니다.

4. Go Live로 바로 실행

VS Code 우측 하단 Go Live를 눌러 index.html이 브라우저에 뜨는지 확인하세요.

Ask 모드

QUEST 01. 파일 건드리지 않고 먼저 물어보기

Kilo Ask 모드로 준비 상태 점검
[Mode: Ask] [Goal]: 나는 이제부터 HTML5 Canvas와 JavaScript로 나만의 웹 아케이드 게임을 만들 거야. 아직 파일을 생성하지 말고, 아래 두 가지만 초보 개발자 눈높이에서 설명해 줘. [Question]: 1. requestAnimationFrame이 setInterval보다 게임 루프에 더 좋은 이유 2가지 2. 오늘 첫 단계로 index.html 하나에 Canvas(800x450)를 띄우려면 어떤 태그와 JS 코드가 핵심인지 5줄 이내로 요약해 줘.
Kilo의 에이전트 마법

Ask 모드는 파일을 멋대로 수정하지 않고, 내 질문에 대해 안전한 코드 설명과 설계 힌트만 제공합니다.

컴퓨터 과학 비밀

실무 개발자도 코드를 바로 짜지 않고, 읽기 전용 질문으로 원리와 범위를 먼저 확인한 뒤 구현에 들어갑니다.

Code 모드

QUEST 02. 60FPS 네온 볼 아케이드 파일 생성하기

Code 모드로 index.html 첫 파일 자동 생성
[Mode: Code] [Goal]: 스타터 폴더의 @index.html 을 수정해서, 어두운 우주 배경(#0f172a) 위에서 네온 공이 60FPS로 튕겨 다니는 캔버스 데모를 구현해 줘. [Condition]: 1. 기존 800x450 캔버스 크기는 그대로 유지해 줘. 2. requestAnimationFrame을 사용한 gameLoop(update + render 분리 구조)로 작성해 줘. 3. 공이 벽 4면에 닿을 때마다 속도를 반전(-vx, -vy)시키고 벽 충돌 횟수(bounces)를 좌측 상단에 표시해 줘. 4. .kilorules 규칙에 따라 핵심 코드마다 한국어 주석을 달아줘.
Kilo의 에이전트 마법

복사·붙여넣기 없이 Kilo가 내 VS Code 폴더 안에 직접 index.html을 생성하고 저장 승인(Approve)을 요청합니다.

컴퓨터 과학 비밀

상태 계산(update)과 화면 그리기(render)를 분리해 두어야 나중에 캐릭터와 몬스터가 늘어나도 코드가 꼬이지 않습니다.

Code 모드

QUEST 03. 특정 파일(@index.html)만 짚어 기능 추가하기

스페이스바 일시정지 & 클릭 공 추가
[Mode: Code] [Goal]: @index.html 파일을 수정해서 사용자가 직접 조작할 수 있는 인터랙션 2가지를 추가해 줘. [Condition]: 1. 캔버스를 마우스로 클릭하면 클릭한 위치에 무작위 네온 색상의 새 공이 1개씩 추가되게 해줘. 2. 키보드 스페이스바(Space)를 누르면 게임이 일시정지/재개(isPaused)되도록 만들어 줘. 3. 일시정지 상태일 때는 캔버스 중앙에 "PAUSED" 안내 문구를 띄워 줘.
Kilo의 에이전트 마법

@파일명을 명시하면 Kilo가 해당 파일의 현재 구조를 정확히 읽고, 필요한 부분만 Diff(초록/빨강 변경점)로 수정합니다.

컴퓨터 과학 비밀

여러 개의 공을 배열(Array)로 관리하고 반복문으로 돌리는 패턴은 앞으로 적군과 총알을 수십 개 띄울 때 그대로 쓰입니다.

시각화 튜닝

QUEST 04. 잔상 트레일 & 실시간 FPS HUD 달기

clearRect vs rgba 잔상 비교 실험
[Mode: Code] [Goal]: @index.html 의 아케이드 화면을 더 멋지게 업그레이드하기 위해 잔상(Trail) 효과와 FPS 측정기를 추가해 줘. [Condition]: 1. 화면 아래에 '잔상 모드 ON/OFF' 버튼을 만들고, 켜졌을 때는 clearRect 대신 rgba(15, 23, 42, 0.2)로 덮어 공 뒤에 혜성 꼬리가 남게 해줘. 2. performance.now()를 이용해 현재 FPS를 계산하고 화면 우측 상단에 표시해 줘. 3. 기존 클릭 공 추가와 스페이스바 일시정지 기능은 그대로 유지해야 해.
Kilo의 에이전트 마법

"기존 기능은 그대로 유지해"라는 제약 조건을 주면 Kilo가 기존 이벤트 리스너를 지우지 않도록 조심해서 수정합니다.

컴퓨터 과학 비밀

반투명 사각형을 매 프레임 덮어 씌우는 기법은 무거운 파티클 없이도 빠른 속도감을 연출하는 고전 아케이드 트릭입니다.

안전 훈련

QUEST 05. 과감한 실험 후 Checkpoint로 시간 되돌리기

에이전트 실수 복구 & Diff 읽기
[Mode: Code -> Checkpoint 복구 실험] [Goal]: @index.html 에서 공이 벽에 부딪힐 때마다 화면 전체가 무지개색으로 번쩍이게 바꿔 줘. [실습 미션]: 1. Live Server로 확인해 본 뒤, 눈이 너무 아프다면 Kilo 채팅창의 이전 메시지 옆 'Restore Checkpoint' 버튼을 눌러 실험 전 상태로 안전하게 되돌려 보세요!
Kilo의 에이전트 마법

Kilo는 매 작업마다 스냅샷(Checkpoint)을 저장하므로, 실험이 마음에 들지 않으면 클릭 한 번으로 완벽하게 복구할 수 있습니다.

컴퓨터 과학 비밀

언제든 되돌릴 수 있다는 안전망(Checkpoint · Git)이 있어야 두려움 없이 다양한 게임 아이디어를 실험할 수 있습니다.

💓 게임 루프

Game Loop / requestAnimationFrame

🧸 어린이 비유: 1초에 60번씩 "지우고 → 위치 옮기고 → 다시 그리기"를 반복하는 게임의 심장 박동!

🎓 개발자 정의: 입력 처리, 상태 갱신(Update), 화면 렌더링(Render)을 모니터 주사율에 맞춰 무한 반복하는 제어 구조.

🎞️ 초당 프레임 수

FPS (Frames Per Second)

🧸 어린이 비유: 1초 동안 눈앞에 몇 장의 만화책 그림을 넘겨 보여주느냐를 나타내는 부드러움 지수!

🎓 개발자 정의: 1초 동안 화면에 그려지는 정지 화면(프레임)의 개수. 보통 60 FPS일 때 끊김 없는 조작감을 느낍니다.

🤖 AI 코딩 에이전트

AI Coding Agent (Kilo Code)

🧸 어린이 비유: 질문만 답해주는 챗봇을 넘어, 내 작업실 책상에서 직접 파일도 만들고 고쳐주는 AI 팀원!

🎓 개발자 정의: 프로젝트 파일을 읽고 쓰며 터미널 실행과 디버깅까지 수행하는 자율형 개발 보조 소프트웨어.

🔍 변경점 비교와 체크포인트

Diff Review & Checkpoint

🧸 어린이 비유: AI가 고친 줄만 형광펜(초록/빨강)으로 확인하고, 이상하면 게임 세이브 파일처럼 되돌리는 안전장치!

🎓 개발자 정의: 수정 전후 코드 차이를 검토(Diff)하고 특정 시점의 파일 상태로 즉시 복원(Checkpoint)하는 변경 관리 기법.
