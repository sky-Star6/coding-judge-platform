퀘스트 01 · 게임 엔진의 심장

1초에 60장의 스케치북을 넘기는 플립북 마법사

만화책 구석에 그림을 조금씩 다르게 그려놓고 손가락으로 촤르륵 넘기면 캐릭터가 살아 움직였던 기억이 있나요? 컴퓨터 모니터 속 게임 캐릭터도 똑같습니다! 1초에 60번, 도화지를 깨끗이 지우고 위치를 조금씩 바꿔 다시 그리는 게임 루프(Game Loop)의 비밀을 파헤쳐 봅니다.

60 FPS Target requestAnimationFrame
STAGE 01

깜빡임 없는 세상을 만드는 60FPS의 마법

사람의 눈은 1초에 약 24장 이상의 그림이 연속으로 지나가면, 그것이 정지 사진들의 모음이 아니라 ‘부드러운 하나의 움직임’이라고 착각합니다. 현대 2D 게임은 더 부드러운 움직임을 위해 1초에 정확히 60번(60FPS) 화면을 갱신합니다.

1프레임에 주어지는 시간: 단 16.6밀리초 (ms)

1초(1,000ms) 나누기 60은 약 16.6밀리초입니다. 게임 엔진은 눈 깜짝할 새보다 훨씬 빠른 16.6ms 안에 [1. 플레이어 입력 확인] ➡️ [2. 물리 및 위치 계산] ➡️ [3. 캔버스에 그리기] 3단계를 끝내야 렉(Stutter) 없이 부드러운 60FPS를 유지합니다.

STAGE 02

지우개질(clearRect)을 안 하면 무슨 일이 생길까?

스케치북에 공을 그린 뒤 다음 페이지로 안 넘기고 그 위에 덧그리면 어떻게 될까요? 지나간 자리마다 공의 흔적이 뱀처럼 줄줄이 남게 됩니다! 그래서 게임 루프의 시작점에서는 항상 이전 프레임의 그림을 지우개로 깨끗이 닦아내는 코드가 들어갑니다.

// 🎮 60FPS 게임 엔진의 핵심 루프 뼈대
function gameLoop() {
// 1. 이전 화면 깨끗하게 닦아내기 (지우개)
ctx.clearRect(0, 0, canvas.width, canvas.height);
// 2. 공의 물리와 위치 계산 (업데이트)
updatePhysics();
// 3. 새로운 위치에 다시 그리기 (렌더링)
drawNeonBall();
// 4. 다음 16.6ms 뒤에 다시 이 함수를 불러줘!
requestAnimationFrame(gameLoop);
}
STAGE 03

공이 앞으로 나아가는 원리: 위치 + 속도

공의 현재 위치가 가로 x = 100이고, 가로 속도가 vx = 5라면, 1프레임이 지날 때마다 위치는 105 ➡️ 110 ➡️ 115로 늘어납니다.

단 2줄의 등속도 물리 공식

ball.x += ball.vx; // 가로 위치 = 가로 위치 + 가로 속도
ball.y += ball.vy; // 세로 위치 = 세로 위치 + 세로 속도

우측 콘솔의 [속도 배율 슬라이더]를 조절하면 이 vx와 vy 값이 커지면서 공이 더 빠르게 날아가게 됩니다.

STAGE 04

벽과 충돌하면 반대 방향으로 튕겨라!

공이 오른쪽 벽에 닿았을 때 계속 x += 5를 하면 화면 밖으로 탈출해 버립니다! 벽에 닿는 순간 속도 부호를 마이너스로 뒤집어주면(vx = -vx), 공은 감쪽같이 반사각을 그리며 튕겨 나옵니다.

좌우 벽 충돌 판정

공이 좌/우 벽에 닿으면 vx = -vx로 가로 방향만 뒤집습니다.

상하 벽 충돌 판정

공이 천장이나 바닥에 닿으면 vy = -vy로 세로 방향만 뒤집습니다.

주니어 개발자를 위한 전문 용어 돋보기

게임 루프

Game Loop

🧸 어린이 비유: 끝없이 빠르게 회전하며 다음 장면을 준비하는 놀이공원의 회전목마예요.
🎓 개발자 공식 정의: 입력 처리(Input), 게임 상태 업데이트(Update), 화면 출력(Render)을 무한히 반복 실행하여 실시간 인터랙션을 만드는 게임 소프트웨어의 핵심 제어 구조입니다.

프레임 레이트

Frames Per Second (FPS)

🧸 어린이 비유: 1초 동안 눈앞을 촤르륵 지나가는 만화 스케치북 장수예요.
🎓 개발자 공식 정의: 디스플레이 장치가 1초 동안 화면에 출력하는 연속된 정지 이미지(Frame)의 빈도입니다. 60FPS는 1프레임당 약 16.6ms를 소요합니다.

더블 버퍼링

Double Buffering

🧸 어린이 비유: 손님이 보는 앞 도화지 몰래 뒤 도화지에 그림을 미리 다 그려두고 1초 만에 휙 뒤집어 보여주는 마술이에요.
🎓 개발자 공식 정의: 그리는 과정이 사용자 눈에 보여서 생기는 화면 찢김(Tearing)이나 깜빡임을 방지하기 위해, 보이지 않는 메모리 버퍼(Back Buffer)에 먼저 그린 후 완성된 화면을 한 번에 스왑(Swap)하는 렌더링 기술입니다.

완전 탄성 충돌

Elastic Collision

🧸 어린이 비유: 슈퍼 탱탱볼을 바닥에 던졌을 때 에너지를 잃지 않고 원래 높이까지 그대로 튀어 오르는 현상이에요.
🎓 개발자 공식 정의: 물체가 충돌할 때 운동 에너지의 손실이 전혀 없이 운동량이 그대로 보존되어 동일한 크기의 반대 속도로 반사되는 이상적인 물리 충돌 법칙입니다.
